## 摘要
我们研究了寻找ρ-弱凸且G-Lipschitz函数的ε-稳定点的预言机复杂度，其中稳定性由Moreau包络的梯度衡量。我们考虑一个一阶预言机，它在每个查询点返回函数值和完整次微分。我们证明，当Δ≤G^2/ρ时，其中f(bz)-inf f≤Δ，每个确定性一阶算法需要Ω(ρG^2Δ/ε^4)次预言机查询。该下界与已知的最佳确定性和随机一阶上界在通用常数意义下匹配，并确立了最优确定性预言机复杂度。结果揭示了光滑非凸与非光滑弱凸优化之间的基本复杂度分离。光滑非凸最小化具有Θ(ε^{-2})的预言机复杂度，而非光滑弱凸优化则因非光滑几何而非随机性而产生固有的额外ε^{-2}因子。

## Abstract
We study the oracle complexity of finding $ε$-stationary points of $ρ$-weakly convex and $G$-Lipschitz functions, where stationarity is measured by the gradient of the Moreau envelope. We consider a first-order oracle that returns both the function value and the full subdifferential at every query point. We prove that every deterministic first-order algorithm requires $ Ω({ρG^2Δ}/{ε^4})$ oracle queries whenever $Δ\leq {G^2}/ρ$, where $f(\bz)-\inf f \leq Δ$. This lower bound matches the best known deterministic and stochastic first-order upper bounds, up to universal constants, and establishes the optimal deterministic oracle complexity. The result reveals a fundamental complexity separation between smooth nonconvex and nonsmooth weakly convex optimization. While smooth nonconvex minimization admits a $Θ(ε^{-2})$ oracle complexity, nonsmooth weakly convex optimization incurs an intrinsic additional $ε^{-2}$ factor arising from nonsmooth geometry rather than stochasticity.
