## 摘要
联合嵌入预测架构（JEPA）通过在表示空间中进行预测而非重建像素来学习世界模型，使其成为从离线演示日志中进行潜在模型预测控制的自然主干。JEPA式训练优化短时域潜在预测，而规划需要对想象未来的目标进展进行多步排序。先前的JEPA规划器通常从嵌入几何（典型为潜在欧氏距离）继承该排序，而这一几何是表示学习的副产品，而非从日志中挖掘出的进展代价。我们提出时间距离JEPA（TD-JEPA），它保留LeWM编码器-预测器主干，并从无奖励轨迹中挖掘有向时间代价：同轨迹步序提供正目标，跨轨迹对作为启发式负样本，滚动一致性项匹配规划器时域。挖掘得到的监督有两个作用：当进展为拓扑性时作为部署的规划代价，当接触几何占主导时作为提升欧氏规划能力的表示信号。在锁定评估下，部署挖掘代价使Two-Room成功率从LeWM的97.4%提升至100.0%，而在同一时间训练检查点上共享欧氏规划使OGB-Cube较LeWM提升14.2个百分点，并改进Push-T。与LeWM及并行的RC-aux基线在锁定评估下比较，TD-JEPA在每一个环境中均达到或超过两种方法。消融实验表明，有向头、跨轨迹负样本和滚动一致性均有所贡献。TD-JEPA通过发现离线日志中的时间进展结构，并将代价形式与计划时部署协同设计，缩小了JEPA世界模型规划器的训练-规划差距。代码可在https://github.com/HKBU-KnowComp/TD-JEPA获取。

## Abstract
Joint-Embedding Predictive Architectures (JEPAs) learn world models by predicting in representation space rather than reconstructing pixels, making them a natural backbone for latent model predictive control from offline demonstration logs. JEPA-style training optimizes short-horizon latent prediction, whereas planning requires a multi-step ranking of imagined futures by goal progress. Prior JEPA planners often inherit that ranking from embedding geometry, typically latent Euclidean distance, which arises as a byproduct of representation learning rather than as a progress cost mined from the logs. We propose temporal-distance JEPA (TD-JEPA), which retains the LeWM encoder--predictor backbone and mines a directed temporal cost from reward-free trajectories: same-trajectory step order supplies positive targets, cross-trajectory pairs act as heuristic negatives, and a rollout-consistency term matches the planner horizon. The mined supervision serves two roles: as the deployed planning cost when progress is topological, and as a representation signal that improves Euclidean planning when contact geometry dominates. Under locked evaluation, deploying the mined cost raises Two-Room success to 100.0% versus LeWM's 97.4%, while shared Euclidean planning on the same temporally trained checkpoint raises OGB-Cube by 14.2 points over LeWM and improves Push-T. Against LeWM and the concurrent RC-aux baseline under locked evaluation, TD-JEPA matches or exceeds both methods on every environment. Ablations show that the directed head, cross-trajectory negatives, and rollout consistency each contribute. TD-JEPA narrows the train--plan gap for JEPA world-model planners by discovering temporal progress structure in offline logs and co-designing cost form with plan-time deployment. Code is available at https://github.com/HKBU-KnowComp/TD-JEPA.

### 1. 论文的核心问题与整体含义（研究动机与背景）

- **核心问题（"训练—规划差距"）**：JEPA 式训练优化的是短时域潜在预测，而规划需要对想象出的未来轨迹按目标进展进行多步排序。然而，现有 JEPA 规划器（如 LeWM）在排序想象未来时，通常直接使用嵌入空间中的欧氏距离（latent Euclidean distance）作为规划代价。该距离只是表征学习的**副产品**，并未经过训练去反映“到达目标所需步数”、有向可达性或规划排序，导致训练目标与规划需求之间存在结构性错配。
- **关键洞见**：在 Push-T 上，LeWM 的潜在欧氏距离与轨迹时间分离的 Spearman 相关性仅为 ρ=0.65，而从相同日志中挖掘出的代价可达 ρ=0.95。这表明从日志中挖掘时间进展结构可以显著缩小排序差距。
- **整体含义**：论文主张，规划代价的形式（cost form）与计划时的部署方式（deployment）应共同设计——拓扑性任务宜部署显式时间代价，接触性任务宜用时间监督塑造表征、再配合几何代价规划。

### 2. 论文提出的方法论

**核心思想**：TD-JEPA 保留 LeWM 的编码器—预测器骨干与 SIGReg 正则化，从无奖励离线演示轨迹中挖掘一个有向时间代价 dψ，并依据任务属性决定该代价的部署角色（直接作为规划代价或作为表征信号）。

**关键技术细节**：

- **(1) 有向代价头（Directed cost head）**：采用 Metric-Residual Network (MRN) 参数化，使代价具有非对称性（从 A 到 B 的代价不必等于从 B 到 A）：
  ```
  dψ(zs, zg) = ||φ_sym(zs) − φ_sym(zg)||² + Σ_k ReLU(φ_asym,k(zs) − φ_asym,k(zg))
  ```
  其中对称项捕捉共享结构，非对称残差编码有向可达性。该形式非负、有向、满足拟度量（quasimetric）结构，与最优目标到达代价 D★ 的理论性质一致。

- **(2) 时间距离监督（Temporal-distance supervision）**：从离线轨迹中挖掘监督信号：
  - **正样本**：同一条轨迹上的有序对（i<j），以步数差 τ(i,j)=j−i 作为回归目标，使用 Smooth L1 损失；
  - **负样本**：跨轨迹同时间索引的启发式负样本对，以 hinge 损失（ReLU(m − dψ)）推高非轨迹上的代价，防止虚假低能量。
  - 总损失记为 L_td。

- **(3) 滚动一致性损失（Rollout-consistency loss）**：在专家动作上施加 H 步教师强制多步预测损失，与规划器使用的开环滚动算子一致，减少累积误差：
  ```
  L_roll = (1/H) Σ_{h=1..H} ||ẑ_{t+h} − sg(z_{t+h})||²
  ```
  H=5，与规划时域匹配。

- **(4) 完整训练目标**：
  ```
  L = L_pred + λ_roll·L_roll + λ_td·L_td + λ_sig·SIGReg(z)
  ```
  其中 λ_roll=0.5、λ_td=1.0、λ_sig=0.09。

- **(5) 规划与部署**：使用 CEM/iCEM 在潜在空间做开环 H 步滚动，以最小化终端能量选择动作序列。默认部署纯 dψ；接触型操纵任务改用同一时间训练检查点上的潜在 ℓ2 规划（或 ℓ2 与 dψ 的混合）。
