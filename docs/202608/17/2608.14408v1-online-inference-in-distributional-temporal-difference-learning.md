## 摘要
我们研究了固定策略下回报分布泛函的在线统计推断。回报分布通过非参数分布式时序差分学习从单条马尔可夫轨迹中估计。对于Polyak--Ruppert平均估计量，我们证明其根号T误差在Cramér空间中弱收敛到一个中心化的高斯随机元。我们还证明，在给定观测轨迹的条件下，自助法均值与原均值之间的根号T差也弱收敛到同样的高斯极限。这些结果为光滑统计泛函（包括方差、CVaR、预期亏损和期望分位数）的自助推断提供了理论依据。对于非光滑统计泛函，我们发展了在有限多个阈值处的T^{-1/2}邻域内估计回报CDF的局部渐近理论，并给出了其自助法对应版本。该理论使我们能够对由CDF方程刻画的非光滑统计泛函（包括回报分位数）进行推断。

## Abstract
We study online statistical inference for functionals of the return distribution under a fixed policy. The return distribution is estimated by nonparametric distributional temporal-difference learning from a single Markov trajectory. For the Polyak--Ruppert averaged estimator, we prove that its root-$T$ error converges weakly to a centered Gaussian random element in Cramér space. We also prove that, conditionally on the observed trajectory, the root-$T$ difference between the bootstrap and original averages converges weakly to the same Gaussian limit. These results justify bootstrap inference for smooth statistical functionals, including variance, CVaR, expected shortfall, and expectiles. For nonsmooth statistical functionals, we develop a local asymptotic theory for the estimated return CDF over $T^{-1/2}$-neighborhoods of finitely many thresholds, together with its bootstrap analogue. This theory allows us to conduct inference for nonsmooth statistical functionals characterized by CDF equations, including return quantiles.

## 2. 论文提出的方法论

### 2.1 核心思想

- 使用**非参数分布 TD 学习**从单条马尔可夫轨迹在线估计回报分布向量 ηπ。
- 采用 **Polyak–Ruppert 平均**（即迭代估计的时间平均）作为最终估计量，以获得渐近正态性。
- 采用**在线乘子 bootstrap**：对每个 bootstrap 复制，用相同的观测轨迹，但将步长乘以独立随机权重 W*（取 0 或 2，各 1/2 概率），从而不重采样轨迹，也不显式估计协方差算子。

### 2.2 模型与符号

- 有限状态、有限动作的折扣表格 MDP，折扣因子 γ∈(0,1)，奖励有界于 [0,1]。
- 固定策略 π 诱导的马尔可夫链不可约、非周期，存在唯一平稳分布 μπ。
- 回报分布向量 ηπ = (ηπ(s))_{s∈S}，其 CDF 记为 Fs。
- 分布 Bellman 算子 Tπ 是 √γ-压缩的。

### 2.3 在线分布 TD 更新

给定转移 (St, At, Rt, St+1)，更新访问状态的分布估计：

```
ηt(St) = (1 - αt) ηt-1(St) + αt (b_{Rt,γ})# ηt-1(St+1)
```

其中 αt = a(t+t0)^{-κ}，κ∈(1/2,1)，b_{r,γ}(x)=r+γx 为仿射变换。未访问状态保持不变。最终估计量为平均：

```
η̄T = T^{-1} Σ_{t=1}^T ηt
```

### 2.4 在线乘子 bootstrap

每个 bootstrap 复制使用相同的轨迹和相同的迭代格式，但步长乘以独立权重 W*_t：

```
η*_t = (I - αt W*_t Λt) η*_{t-1} + αt W*_t Λt Tπt η*_{t-1}
```

其平均为 η̄*_T。条件于观测轨迹，bootstrap 误差 √T(η̄*_T - η̄T) 的分布用于逼近抽样分布 √T(η̄T - ηπ)。

### 2.5 平滑泛函推断

- 将误差 et = ηt - ηπ 视为 Cramér 空间中的**零质量符号测度**，建立 Hilbert 空间结构 H = M^S。
- 误差递归：

```
et = et-1 - αt At et-1 + αt mt
```

其中 At = Λt(I - Tπt)，mt = Λt(Tπt ηπ - ηπ) 是鞅差序列。

- 定义算子 A = Dμπ(I - Tπ)，它是可逆且强制的。
- **定理 1（Cramér 空间中心极限定理）**：

```
ZT = √T(η̄T - ηπ) = A^{-1} T^{-1/2} Σ_{t=1}^T mt + op(1)
⇒ G ~ 中心高斯随机元，协方差 A^{-1}Σ(A^{-1})*
```

- **定理 2（bootstrap 有效性）**：条件于轨迹，√T(η̄*_T - η̄T) ⇒* 同一高斯极限 G（在 P 概率意义下）。
- **定理 3（平滑泛函）**：若 Φ 是 Hadamard 可微的，则：

```
√T(Φ(η̄T) - Φ(ηπ)) ⇒ Φ̇ηπ(G)
√T(Φ(η̄*_T) - Φ(η̄T)) ⇒* Φ̇ηπ(G)
```

由此可构造基本 bootstrap 置信区间。

- 给出具体例子：均值、方差、CVaR、预期亏损、期望分位数的导数表达式。

### 2.6 非平滑泛函推断

- 针对分位数等由 CDF 方程刻画的非平滑泛函，标准 delta 方法失效。
- 在假设回报分布绝对连续且密度有界连续（Assumption 1）的前提下，对有限个阈值 x_j 建立**局部 CDF 过程**：

```
FT,x(h) = [√T( F̄T,s(x_j + h_{s,j}/√T) - Fs(x_j) )]_{s,j}
```

- **定理 4**：当 κ∈(3/5, 3/4) 时，

```
FT,x ⇒ [ h ↦ G^x + f^x ⊙ h ]
```

其中 G^x 是均值为零、协方差为 Ω^x 的高斯向量，f^x 为密度在阈值处的值。

- **定理 5**：bootstrap 局部 CDF 过程也收敛到同一极限。
- **定理 6**：对于形如 H(θ) = M(θ, Fs1(g1(θ)), …) = 0 定义的参数，给出：

```
√T(θ̂T - θ0) ⇒ -B^{-1}M_u G_x
√T(θ̂*_T - θ̂T) ⇒* -B^{-1}M_u G_x
```

其中 B 为导数矩阵，M_u 为对 CDF 参数的偏导。

- 应用示例：中位绝对偏差（MAD）、回报分位数（包括广义逆估计）。

### 2.7 理论证明技巧

- 使用**算子 Poisson 方程**处理马尔可夫依赖性。
- 构造 **Lyapunov 函数** Vt = ||et||² - 2αt⟨et, Q(St+1)et⟩ 证明 E||et||² ≤ Cαt。
- 利用 **Abel 求和**、**Hilbert 空间鞅 CLT**、**有限秩投影近似**等处理余项。
- 对于局部 CDF 过程，采用**Neumann 级数展开**、**局部小球估计**、**dyadic 网格 + 鞅 Bernstein 不等式**证明随机等度连续。
