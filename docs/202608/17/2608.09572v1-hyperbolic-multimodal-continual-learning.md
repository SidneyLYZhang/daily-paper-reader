## 摘要
双曲几何近来已成为多模态学习中一种强大的表示空间，因为它自然地捕捉跨模态的层级语义结构。尽管取得了这些进展，此类表示在持续学习下的行为方式却提出了根本不同的挑战，而这些挑战仍未得到充分探索。本研究从几何角度审视这一问题，并为双曲空间中的表示保持奠定理论基础，表明防止遗忘需要共享双曲等距变换下的跨模态不变性。我们进一步表明，双曲持续学习中的遗忘涉及语义关系漂移和层级相关失真，这促使我们同时保持跨模态关系结构和层级几何。在这些见解的指导下，我们推导出一个原则性的持续学习框架，该框架在保留必要几何结构的同时，允许对新任务进行有效适应。在持续多模态基准上的实验证实了所提出方法的有效性。

## Abstract
Hyperbolic geometry has recently emerged as a powerful representation space for multimodal learning, as it naturally captures hierarchical semantic structure across modalities. Despite this progress, how such representations behave under continual learning poses fundamentally different challenges that remain underexplored. This work provides a geometric perspective on this problem and establishes a theoretical foundation for representation preservation in hyperbolic space, showing that preventing forgetting requires cross-modal invariance under a shared hyperbolic isometry. We further show that forgetting in hyperbolic continual learning involves both semantic relation drift and hierarchy-related distortion, motivating preservation of both cross-modal relational structure and hierarchical geometry. Guided by these insights, a principled continual learning framework is derived that preserves essential geometric structure while allowing effective adaptation to new tasks. Experiments on continual multimodal benchmarks corroborate the effectiveness of the proposed approach.

## 2. 论文提出的方法论（核心思想、关键技术、公式与算法）

### 2.1 核心思想
双曲空间中的语义通过两个几何量编码：
- **测地距离** → 语义相似性
- **到原点的距离（径向范数）** → 语义层级/抽象程度

因此持续更新必须保持**三种几何性质**（P1–P3）：
- **(P1) 模态内保持**：`Zm,t_{t-1} G (Zm,t_{t-1})ᵀ = Zm,t-1_{t-1} G (Zm,t-1_{t-1})ᵀ`（保持同模态内结构）
- **(P2) 模态间保持**：`Zm,t_{t-1} G (Zm',t_{t-1})ᵀ = Zm,t-1_{t-1} G (Zm',t-1_{t-1})ᵀ`（保持跨模态关联）
- **(P3) 层级保持**：`‖(zm,t_{t-1})[1:d]‖ = ‖(zm,t-1_{t-1})[1:d]‖`（保持空间范数/层级）

### 2.2 关键定理与推导
- **定理 1（几何保持的特征化）**：在非退化条件下，(P1)–(P3) 成立当且仅当存在共享的纯空间旋转矩阵
  `R = [[1, 0ᵀ], [0, R̃]]`，其中 `R̃ ∈ SO(d)`，对所有模态有 `Zm,t_{t-1} = Zm,t-1_{t-1} Rᵀ`。即：**所有模态必须经历同一个共享等距变换**。
- **推论 1（层级保持的一阶条件）**：若时间分量一阶不变，则空间更新必须满足 `zᵀ[1:d] · Δz[1:d] = 0`，即更新须落在当前嵌入空间方向的**正交补空间**中。
- **命题 1（可容许参数更新）**：无穷小更新 `Wm,t = Wm,t-1 − ηΔWm` 中，`ΔWm_s` 可容许当且仅当存在反对称矩阵 `Ωᵀ = −Ω` 使得
  `Zm,*_{t-1}[1:d] (ΔWm_s)ᵀ = Zm,t-1_{t-1}[1:d] Ωᵀ`，
  且块约束 `Δwm_0 = 0`。
- **推论 2（块式规范更新）**：在最小旋转机制下，`Ω⋆ = 0`，可容许更新简化为零空间投影：
  `ΔWm_s = δm_s (I − Pt-1)`，
  其中 `Pt-1 = (Zm,*_{t-1,s})ᵀ (Zm,*_{t-1,s}(Zm,*_{t-1,s})ᵀ)† Zm,*_{t-1,s}` 是投影矩阵。

### 2.3 算法流程（HMCL）
1. 对旧任务空间表示 `Zm,*_{t-1,s}` 通过 SVD/PCA 计算低秩正交基 `V`。
2. 将无约束更新 `δm_s` 投影到正交补空间：`ΔWm_s = δm_s (I − VVᵀ)`。
3. 时间分量更新设零：`Δwm_0 = 0`。
4. 更新参数 `Wm,t_s = Wm,t-1_s − ηΔWm_s`，`wm,t_0 = wm,t-1_0`。
5. 使用 AdamW 优化器结合 step-pullback（`W ← (1−β)W + βWt,0`）稳定有限步优化。

**方法特点**：无新增可学习参数，投影矩阵可预先计算，记忆开销与任务数无关（仅存储 d×d 协方差摘要），可无缝集成到现有训练流程。

## 6. 论文的主要结论与发现

1. **理论层面**：防止双曲多模态表示遗忘的充要条件是在**共享双曲等距**（纯空间旋转）下保持跨模态不变性，该等距对所有模态一致。
2. **遗忘机制**：双曲持续学习中的遗忘同时包含**语义关系漂移**和**层级相关失真**（不仅仅是单一因素）。
3. **方法有效性**：HMCL 在三个双曲骨干上一致提升分类精度与检索召回率，并大幅降低 BWT：
   - MERU-L：分类 BWT 从 −6.46 提升至 −0.74（相对减少 **88.5%**）
   - HyCoCLIP-B：检索 R@1 提升 **+26.9%**，BWT 减少 87.2%
4. **几何漂移显著降低**：径向漂移减少 61.0%，角度漂移减少 57.8%，跨模态漂移减少 73.8%，配对距离漂移减少 59.5%。
5. **基线局限性**：传统欧氏持续学习方法（EWC、GEM、C-FLAT）在双曲设置下效果有限，表明几何感知的更新规则是关键。

## 8. 不足与局限

- **未使用回放机制**：作者本人指出，HMCL 是纯几何约束路线，未结合 exemplar/generative replay，而回放可能与几何约束互补。
- **仅微调轻量变换层**：未探索全骨干（full-backbone）适应场景，在骨干也更新时的效果未知。
- **骨干多样性有限**：三个骨干均属于“CLIP 风格”的双曲视觉–语言模型，未覆盖其他模态组合（如音频–文本、视频–文本等）。
- **基线适配问题**：EWC/GEM/C-FLAT 是在欧氏假设下发展的方法，虽然被改造到双曲目标上，但其更新规则本质上是几何无关（geometry-agnostic）的，可能未充分发挥这些方法在双曲空间中的潜在变体。
- **理论假设限制**：定理 1 依赖非退化条件（rank = d+1），在表示坍塌或低秩场景下，兼容等距可能不唯一，理论保证的“锐利性”会下降。
- **计算资源细节缺失**：未报告总训练时间、能耗、显存峰值等工程可复现性指标。
- **案例研究的主观性**：图像遍历结果受候选集构建方式（名词/形容词提取）影响，存在一定选择性偏差。
