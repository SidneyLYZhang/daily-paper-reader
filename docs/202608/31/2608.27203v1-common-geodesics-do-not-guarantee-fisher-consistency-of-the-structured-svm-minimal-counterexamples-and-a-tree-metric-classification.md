## 摘要
已知的 Fisher 一致性必要条件要求任务损失是一个度量，且每个输出三元组都有一个公共测地点。我们证明该条件对于标准的坐标式 argmax 解码器并不充分。一个四输出的单位星形允许一个精确最优的得分向量，其所有最大化器都严格非贝叶斯，且在满足该条件的度量中，四输出是最小的。然后我们对顶点集为输出空间的正加权树度量进行了完全分类：argmax 一致性成立当且仅当该树是一条路径。在分支树上的失败仅限于边界分布；每棵树在完整支撑分布上都保持 argmax 性质。在满足公共测地线条件的度量中，五个输出对完整支撑反例是必要且充分的；$K_{2,3}$ 是无限 $K_{m,n}$ 族中最小的成员。我们还给出了三维汉明立方体的完整支撑反例。所有最优性断言都具有精确的原-对偶证书。这些反例揭示了一个具体的解码器缺口：在这个多面体设置中，嵌入可以保证校准链接的存在，而无需在每个代理风险最小化器上验证指定的 argmax 链接。

## Abstract
A known necessary condition for Fisher consistency of the structured support vector machine requires the task loss to be a metric for which every output triple has a common geodesic point. We show that this condition is not sufficient for the canonical coordinate-wise argmax decoder. A four-output unit star admits an exactly optimal score vector whose maximizers are all strictly non-Bayes, and four outputs are minimal among metrics satisfying the condition. We then completely classify positively weighted tree metrics whose vertex set is the output space: argmax consistency holds if and only if the tree is a path. The failure on branching trees is confined to boundary distributions; every tree retains the argmax property at every full-support distribution. Among metrics satisfying the common-geodesic condition, five outputs are necessary and sufficient for a full-support counterexample; $K_{2,3}$ is the smallest member of an infinite $K_{m,n}$ family. We additionally give a full-support counterexample for the three-dimensional Hamming cube. All optimality claims have exact primal-dual certificates. The counterexamples expose a concrete decoder gap: in this polyhedral setting, an embedding can guarantee the existence of a calibrated link without validating a prescribed argmax link on every surrogate-risk minimizer.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：结构化支持向量机（SSVM）是二元 hinge loss 扩展到有限结构化输出空间的一种方法，其 margin-rescaling 代理损失定义为  
  \(S_M(v,y) = \max_{y' \in \mathcal{Y}} \{L(y,y') + v_{y'} - v_y\}\)。  
  虽然计算高效，但该代理损失在二元分类之外的 Fisher 一致性（Fisher consistency）并不被保证。
- **已知必要条件**：Nowak-Vila、Rudi 和 Bach 在 2022 年的研究中证明了一个重要几何必要条件：当 \(|\mathcal{Y}| > 2\) 时，损失函数 \(L\) 必须是度量，且每个输出三元组都必须存在一个点，同时位于三对输出之间的测地线上，即所谓的 **公共测地线条件**（等价于度量空间的 **模性** / modularity）。  
  他们当时未能判定该条件是否充分，并提出了树度量作为正面案例。
- **核心问题**：本文直接回应了这一开放性疑问——**公共测地线条件是否足以保证 SSVM 的 Fisher 一致性？**  
  结论是否定的：该条件不足以支撑标准的坐标式 argmax 解码器，并给出了精确的最小反例、完整的树度量分类、以及满支撑（full-support）约束下的最小势反例。

- **核心思想**：通过精确的反例构造和完整分类来揭示一个关键“解码器缺口”：  
  即使 SSVM 的 Bayes 风险恒等和嵌入性质（Canonical Embedded Reports）成立，**坐标式 argmax 解码器在所有代理风险最小化器上的表现仍未得到验证**。  
  反例中的核心问题是：条件代理风险存在嵌入图像之外的最小化器，位于多面体退化产生的非嵌入面上。
- **关键数学工具**：
  - **自耦合对偶（Self-coupling Dual, Proposition 2.1）**：  
    将最小化条件代理风险 \(R_q(v)\) 的问题等价为一个线性规划，其对偶形式为最大权重自耦合问题：  
    \(\min_v R_q(v) = \max_{\Pi \ge 0, \Pi \mathbf{1} = q, \Pi^\top \mathbf{1} = q} \sum_{i,j} \Pi_{ij} L(i,j)\)。  
    当原-对偶达到最优时，互补松弛条件（complementary slackness）为 \(\Pi_{ij} > 0 \Rightarrow \xi_i = L(i,j) + v_j - v_i\)，其中 \(\xi_i\) 是每个观测输出的代理商风险。
  - **有限支撑耦合准则（Lemma 2.3）**：利用 Hall 定理 / 最大流-最小割，将“存在具有给定边际和支撑的耦合”等价转换为对任意行子集 \(A\) 的容量不等式 \(\mu(A) \le \nu(N(A))\)。
  - **Tripod 障碍（Theorem 3.1）**：四元构型 \(\{z, y_1, y_2, y_3\}\)，满足 \(L(y_i, y_j) = r_i + r_j\)（其中 \(r_i = L(z, y_i)\)），即三叶星形结构。在该构型下，可以构造一个条件代理风险的最小化器，其 argmax 集与 Bayes 集不相交。
- **构造反例的思路**：给定一个分数向量 \(v\) 和概率分布 \(q\)，先用公式算得或通过三角不等式证明其上界（得到代理风险的上界），再利用循环不等式或显式对偶耦合证得其下界，从而精确判定最优性。最终利用互补松弛条件导出 argmax 偏差。
- **树度量分类的技术细节**：
  - **路径一致性（Theorem 3.3）**：对加权路径，利用相邻顶点间的风险差公式 \(ℓ_q(x_{t+1}) - ℓ_q(x_t) = w_t(2Q_t - 1)\) 来划定 Bayes 集 \(B(q)\)（可为单个顶点或中位平台）。随后构造一个显式的自耦合对偶解，利用互补松弛条件证明最优分数向量的 argmax 一定落入 Bayes 集。
  - **分支树的内部一致性（Theorem 3.5）**：对任意树度量，在满支撑分布下，树中位数（唯一顶点或相邻双顶点）即为 Bayes 集；利用支撑耦合准则构造对偶可行解，并由互补松弛条件推出唯一最优 argmax。
  - **分类结论（Corollary 3.4）**：任意非路径树都存在星形分支点，满足 Tripod 障碍结构，因此不一致；路径树一致。故**精确分类：树度量若为路径则一致，否则不一致**。

### 6. 论文的主要结论与发现

1. **公共测地线条件并非充分条件**：存在满足该条件的最小四输出度量（单位星形），其中 argmax 集 \(\{a,b,c\}\) 与唯一 Bayes 输出 \(\{o\}\) 互不相交，且不存在 tie-breaking 的规避余地（所有最大化器均非 Bayes）。
2. **无三输出反例**：任意满足公共测地线条件的三点度量必为加权路径，路径度量始终一致，故**最小不受限反例势为 4**。
3. **树度量的精确分类**：SSVM 的 argmax Fisher 一致性成立当且仅当树是一条路径；所有分支（非路径）树都可归约为四元 Tripod 结构，从而不一致。
4. **分支树的失败仅出现在边界分布（simplex boundary）**：在任意满支撑分布（每点概率严格为正）下，所有树度量（包括分支树）均保持 argmax 一致性，且该结果覆盖 Bayes 平局情形。
5. **满支撑反例的最小势为 5**：在满足公共测地线条件的所有度量中，存在满支撑反例所需的最小输出数为 5；\(K_{2,3}\) 是最小成员，且 \(K_{m,n}\)（\(2 \le m < n\)）给出无限族。
6. **汉明立方体反例**：三维汉明立方体上存在满支撑分布，使得 argmax 集（偶校验类）与唯一 Bayes 输出（100）完全不相交。
7. **一致性失败的本质是“解码器缺口”**：即使 Bayes 风险恒等 \(H_M = 2H_L\) 和按缩放损失 \(2L\) 的嵌入都成立，指定坐标式 argmax 链接（decoder）并不自动在代理风险的全部最小化器上有效。支持该论断的关键水平集条件为
