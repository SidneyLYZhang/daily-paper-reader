## 摘要
在部分可观测下行动的智能体必须保留一个可递归更新的历史统计量，以恢复马尔可夫性质，但通常这样的最小统计量是未知的。我们刻画了和乐覆盖决策过程的最小马尔可夫充分统计量，这是一类结构化的POMDP，其中可见动态是马尔可夫的，并且每个已实现的可见转移都对隐藏模式应用一个固定置换。特别地，我们构造了稳定商，即保留一步奖励和商后继的最粗的逐观测抽象，并证明了当前观测与稳定类构成的组合形成了一个精确的有限马尔可夫状态。当当前类被正确初始化时，精确的类追踪恰好需要最小记忆符号，其意义在于：在可达性和在最大化观测处的成对决策分离条件下，任何任意有限记忆控制器都不能使用更少的符号。在可重置诊断下，最近原型类推断具有指数衰减误差，并且“校准后重启”约简将有限MDP保证转移到恢复的状态。这些结果实现了“和乐记忆强化学习”。它通过当前稳定类表示记忆，通过有序边运输更新记忆，在诊断可用时识别局部类坐标，并在同步后应用标准有限MDP强化学习主干。实验从原始状态到商状态恢复了精确压缩，并以三个决策时记忆状态实现了完美的配对顺序准确性，匹配商预言机并优于非预言机基线。

## Abstract
An agent acting under partial observability must retain a recursively updateable statistic of history that restores the Markov property, but the smallest such statistic is generally unknown. We characterize this minimal Markov sufficient statistic for holonomy-cover decision processes, a structured POMDP class in which the visible dynamics are Markov and every realized visible transition applies a fixed permutation to a hidden mode. In particular, we construct the stable quotient, the coarsest observation-wise abstraction preserving one-step rewards and quotient successors, and prove that the pair of the current observation and stable class forms an exact finite Markov state. When the current class is correctly initialized, exact class tracking requires exactly the minimal memory symbols, in the sense that under reachability and pairwise decision separation at a maximizing observation, no arbitrary finite-memory controller can use fewer. Under resettable diagnostics, nearest-prototype class inference has exponentially decaying error, and a calibrate-then-restart reduction transfers finite-MDP guarantees to the recovered state. The results enable \emph{Holonomy Memory Reinforcement Learning}. It represents memory by the current stable class, updates it through ordered edge transports, identifies local class coordinates when diagnostics are available, and applies a standard finite-MDP RL backbone after synchronization. Experiments recover an exact compression from raw states to quotient states and achieve perfect paired-order accuracy with three decision-time memory states, matching the quotient oracle and outperforming the non-oracle baselines.

## 2. 论文提出的方法论

### 2.1 核心思想
- **HCDP 模型**：隐状态为 S = O × [n]（观测 × 隐藏层），观测函数为 h(o,i)=o。可见转移核 PO(o′|o,a) 与隐藏层无关（马尔可夫），但每次已实现的可见转移会对隐藏模式施加一个固定置换 σ_{o,a,o′}。因此可见动态是马尔可夫的，但奖励与最优决策可能依赖历史累积的传输。
- **稳定商（Stable Quotient）**：在每个观测纤维内细化隐藏模式。两个模式归入同一类，当且仅当它们对所有即时行动奖励一致，且每条可行边将它们传输到相同的后继类。通过单调有限细化算子 T（从奖励分区出发迭代），最终稳定在不动点 Π*，即最粗的稳定族。
- **核心定理链**：
  - 引理 3.5：T 单调且有限步稳定，得到最粗稳定族 Π*（至多 |O|(n−1) 次严格细化）。
  - 命题 3.7：精确性判据——商映射精确当且仅当 Π ⪯ T(Π)。
  - 定理 3.8：所有精确逐观测抽象都细化稳定商，即稳定商是最粗的精确抽象。
  - 定理 3.9（精确马尔可夫化）：(o, c) 对构成价值保持的有限 MDP，原始 HCDP 的最优值与商 MDP 的最优值在每一点一致。
  - 推论 3.12：已知类追踪所需最小记忆字母数为 m*_exact = max_o |C_o|。
- **诊断识别**：定理 4.2 证明被动日志无法一致恢复商结构；在可重置、校准的诊断接口下，最近原型推断的类误差指数衰减（定理 4.6），锚定边诊断最终恢复逐行边传输（定理 4.9），并保证最终精确类追踪（命题 4.12）。
- **非交换记忆障碍**：定理 6.4 证明任何通过阿贝尔化（交换循环计数）的记忆在决策分离的循环历史处必然产生最优性损失；推论 6.6 证明成对决策分离迫使任意有限记忆控制器必须以至少 |C_o| 个符号区分可达类。而有序稳定类追踪（命题 6.8）仅用当前有限类即可精确跟踪，避免此损失。

### 2.2 技术细节与算法流程
- **HMRL（Holonomy Memory Reinforcement Learning）算法**：
  1. 用当前稳定类 c 表示记忆；
  2. 通过有序边传输 τ_{o,a,o′}(c) 递归更新类坐标；
  3. 在诊断可用时，利用局部标签集和原型做最近原型类推断；
  4. 校准后冻结边传输表，重启 RL 主干（Q-learning），仅用后校准数据训练（满足推论 5.4 的迁移条件）。
- **商 MDP 构造**：传输律 \bar{P}((o′,c′)|(o,c),a) = P_O(o′|o,a)·1{c′ = τ_{o,a,o′}(c)}，奖励 \bar{R}(o,c,a) 代表无关。
- **校准流程（HMRL-D）**：先用重置诊断接口估计局部类原型和边传输矩阵，再重新初始化 Q 表与优化器状态，然后进行在线 Q-learning，每幕初始类由诊断获得。

## 6. 论文的主要结论与发现

- **稳定商是最小马尔可夫充分统计量**：在所有精确逐观测抽象中，稳定商是最粗的；(o, c) 对构成价值保持的有限 MDP，最优值在原始和商之间逐点相等。

- **被动不可识别 vs 诊断可恢复**：无约束被动日志无法一致估计商结构；在可重置校准诊断下，类误差指数衰减，边传输可最终恢复（至逐观测重标定等价），并可实现永久同步。
- **非交换屏障**：交换循环计数记忆在非交换传输下必然失败（定理 6.4、推论 6.5），而有序稳定类追踪以有限当前类即可精确区分不同传输类（命题 6.8）；任何精确有限记忆控制器在成对决策分离下至少要记忆 |C_o| 个符号。
