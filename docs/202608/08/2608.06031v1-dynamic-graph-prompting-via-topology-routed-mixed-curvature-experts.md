## 摘要
动态图提示冻结预训练的时间骨干网络，并使用轻量级提示将其适配到标签稀缺的下游任务。然而，现有方法在单一、固定的嵌入空间中运行。在本工作中，我们揭示局部聚类和时间度异质性的时间变化主动重组了边曲率谱——这表明最优表示几何随时间随局部拓扑动态演化。我们将这种未解决的错配形式化为几何欠适应。为克服此限制，我们提出CurvPrompt，一种用于动态图的拓扑路由几何提示框架。CurvPrompt不是依赖单一空间，而是维护一个曲率多样的黎曼专家库，每个专家与一个可学习的提示配对。一个拓扑感知的门控将每个节点-时间实例动态路由到专家的稀疏子集，构建个性化的混合曲率表示。为确保在极端标签稀缺下的参数效率和训练稳定性，CurvPrompt在预训练期间使用软路由以构建连续的拓扑-几何映射，并在下游适应期间过渡到具有均匀权重的硬Top-K路由。在四个基准数据集上的广泛实验表明，CurvPrompt显著推进了少样本链接预测，同时在节点分类任务上提供了强大、一致的性能，验证了几何自适应提示的必要性。

## Abstract
Dynamic graph prompting freezes a pre-trained temporal backbone and adapts it to label-scarce downstream tasks using lightweight prompts. However, existing methods operate within a single, fixed embedding space. In this work, we reveal that temporal shifts in local clustering and degree heterogeneity actively reorganize the edge curvature spectrum---indicating that the optimal representation geometry dynamically evolves with local topology over time. We formalize this unaddressed mismatch as geometry under-adaptation. To overcome this limitation, we propose CurvPrompt, a topology-routed geometry prompting framework for dynamic graphs. Instead of relying on a single space, CurvPrompt maintains a bank of curvature-diverse Riemannian experts, each paired with a learnable prompt. A topology-aware gate dynamically routes each node--time instance to a sparse subset of experts, constructing a personalized mixed-curvature representation. To ensure parameter efficiency and training stability under extreme label scarcity, CurvPrompt employs soft routing during pre-training to build a continuous topology--geometry mapping, and transitions to hard Top-K routing with uniform weights during downstream adaptation. Extensive experiments across four benchmark datasets show that CurvPrompt significantly advances few-shot link prediction while delivering strong, consistent performance on node classification tasks, validating the necessity of geometry-adaptive prompting.

- **动态图提示学习的现状**：动态图提示（Dynamic Graph Prompting）通过冻结预训练的时间骨干网络（如TGN），仅更新轻量级提示参数来适配标签稀缺的下游任务。现有方法（如TIGPrompt、DyGPrompt）虽能实现高效迁移，但均在一个**固定的嵌入空间**中进行操作。
- **关键观察（几何欠适应问题）**：论文通过MOOC数据集上的实证观察发现，动态图中局部聚类系数随时间下降、度方差上升（拓扑漂移），同时边的Ollivier–Ricci曲率谱向负值方向重组（负曲率边占比从17%升至56%，近零曲率边从75%降至39%）。这表明最优表示几何应随局部拓扑演化而动态调整，而现有方法忽略了这一时间演化的几何需求。
- **形式化定义**：论文将这一不匹配正式定义为“几何欠适应”（Geometry Under-Adaptation），即任务级提示可以更新，但表征几何保持时不变，无法追踪拓扑诱发的曲率漂移。
- **核心研究问题**：如何在保持参数高效的前提下，让提示引导每个演化中的邻域朝向其最优表示几何？

## 2. 方法论：核心思想、关键技术细节与算法流程

### 核心思想
提出**CurvPrompt**——一个拓扑路由的黎曼混合专家提示框架。用一组曲率多样的黎曼专家替代单一空间编码器，通过拓扑感知门控为每个节点-时间实例动态选择稀疏专家子集，构建个性化混合曲率表征。

### 关键技术细节

**（1）曲率多样黎曼专家库**
- 专家库由双曲（κ<0）、欧氏（κ=0）、球面（κ>0）专家构成，同一几何类型内初始化不同曲率值以捕捉不同弯曲程度。
- 每个专家在TGN骨干上执行轻量级单层黎曼更新：
  `z = exp_κ( σ( W_s log_κ(s) + W_n log_κ(exp_κ(m)) + c + p ) )`
  其中p为专家专属可学习提示，c为共享节点-时间条件偏置。

**（2）提示与条件机制**
- 专家专属提示：每个专家配备独立提示向量，促进专家分工。
- 时间提示：对时间编码进行重缩放。
- 节点-时间条件偏置：由时间条件网络（TCN）和节点条件网络（NCN）双瓶颈网络生成，同时注入专家更新与路由输入，使专家计算与选择共享同一上下文。

**（3）拓扑感知时间门控**
- 多分辨率拓扑编码：对检索到的时序邻居按不同邻域规模（r∈{2,5,10}）求均值池化，与骨干状态融合。
- 条件Top-K路由：使用软Top-K路由进行预训练（保留连续拓扑-几何映射），下游切换为均匀权重硬Top-K路由以稳定复用预训练几何选择。
- 辅助损失：包含负载均衡损失（避免专家使用不足）和专家提示正交性约束（促进专家专化）。

**（4）混合与对齐**
- 在κ-立体模型共享环境坐标中加权聚合选中专家输出，再经线性对齐骨干状态。
- 评分阶段使用路由加权曲率κ̄和对应测地距离，实现嵌入与评分几何联合自适应。

### 训练流程
- **预训练**：时序链接预测（BCE）+ 嵌入失真损失 + 负载均衡 + 提示正交性。
- **下游适应**：冻结黎曼专家、曲率、拓扑编码器、路由、TCN/NCN和时间编码器，仅更新提示参数与任务头，用于节点分类或链接预测。

## 6. 主要结论与发现

- **CurvPrompt在全部8个链接预测设置（4数据集 × 传导/归纳）上取得最佳结果**，相比TGN-DyGPrompt增益从+0.5%（Reddit传导）到+13.9%（MOOC传导）不等。

- **消融结果**：移除专家混合导致LP大幅下降（如MOOC LP从84.05降至56.32），说明曲率专化专家混合是主要贡献者；负载均衡损失重要性次之。
- **几何归因**：欧氏MoE优于无专家版本（确认MoE本身有效），单曲率优于欧氏MoE（确认非欧几何的贡献），混合曲率优于单曲率（确认多曲率专化的必要性）。
- **专家动态行为**：Reddit上门控使用显示路由质量随时间从高曲率球面专家（κ=1）向温和球面专家（κ=0.2）迁移，门控未塌缩到固定混合，验证了时间演化下多曲率路由的必要性。
- **总体判断**：混合曲率专家的曲率组成比具体Top-K设置更影响性能，多样性优于任何单一几何。
