## 摘要
基于学习的记忆系统在自进化LLM智能体面临两个紧密耦合的挑战。首先，轨迹索引的效用随交互历史增长，从而将有限的反馈分散到不断扩大的状态空间中。其次，由于轨迹级奖励被联合分配给共同检索的记忆，无关的经验可能获得误导性的效用更新，进而陷入记忆-奖励陷阱。为解决这些问题，我们引入了降阶记忆强化学习（RoMeRL），该方法使用由结果极性和记忆动态因子化的固定维度每任务记忆状态来表示不断增长的轨迹索引效用空间。RoMeRL通过一组固定的语义坐标整合新经验，这些坐标的内容随时间更新或替换，从而将反馈集中在有界的效用支持上。理论上，我们证明了这种降阶参数化增加了每个效用坐标接收的平均反馈，并描述了在通用坐标转移模型下错误坐标的稳态占用。实证上，在ALFWorld和LifelongAgentBench上，RoMeRL提高了任务性能，将Cold-Q比率降低了80.0%，反馈密度提高了约6.0倍，维护的记忆大小减少了84.4%，LLM调用减少了21.1%。这些结果表明，降阶效用状态支持高效的自进化智能体记忆，同时限制了持续的奖励污染。代码可在以下网址获取：https://github.com/YOUNG-fnxm/RoMeRL

## Abstract
Learning-based memory systems for self-evolving LLM agents face two tightly coupled challenges. First, trajectory-indexed utilities grow with the interaction history, thereby dispersing limited feedback over an ever-expanding state space. Second, because trajectory-level rewards are jointly assigned to co-retrieved memories, irrelevant experiences may receive misleading utility updates and consequently enter the memory-reward trap. To address these challenges, we introduce Reduced-Order Memory Reinforcement Learning (RoMeRL), which represents the growing trajectory-indexed utility space using a fixed-dimensional per-task memory state factorized by outcome polarity and memory dynamics. RoMeRL incorporates new experiences through a fixed set of semantic coordinates whose contents are updated or replaced over time, thereby concentrating feedback over a bounded utility support. Theoretically, we show that this reduced-order parameterization increases the average feedback received by each utility coordinate and characterize the steady-state occupancy of erroneous coordinates under a generic coordinate-transition model. Empirically, across ALFWorld and LifelongAgentBench, RoMeRL improves task performance, reduces the Cold-Q ratio by 80.0%, increases feedback density by approximately 6.0 times, reduces the maintained memory size by 84.4%, and cuts LLM calls by 21.1%. These results show that reduced-order utility states support efficient self-evolving agent memory while limiting persistent reward contamination. ## 1. 论文的核心问题与整体含义

- **研究背景**：大语言模型（LLM）本身是无状态的，难以跨交互累积经验；记忆系统通过存储和检索历史经验弥补这一缺陷。早期方法依赖手工流程/规则管理记忆，近期方法则用强化学习对记忆的生成、检索、效用进行端到端优化。
- **核心问题**：现有学习型记忆系统采用“轨迹索引”式效用表示，即每条新轨迹新增一个效用变量。这导致两个耦合挑战：
  1. **反馈分散**：轨迹数量随交互历史增长，有限的任务级反馈被稀释到不断扩张的效用空间中，大量记忆几乎得不到更新（冷启动）。
  2. **记忆-奖励陷阱（MRT）** ：由于轨迹级奖励被整体地赋给所有共同检索出的记忆，弱相关/无关/过时/失败记忆可能因偶然出现于成功情节而获得正向效用更新，造成奖励误归属。
- **整体含义**：作者指出，更强的探索（如 UCB）虽可扩大反馈覆盖，但会同时加剧奖励污染；因此核心矛盾是“如何在不扩大受错误奖励传播影响的支持集的前提下，提高记忆反馈覆盖”。该问题被抽象为探索–污染两难。

## 2. 论文提出的方法论

- **核心思想**：放弃连续增长的全量轨迹索引效用空间，改用**固定维度的每任务记忆状态**，由“结果极性”（成功/失败）与“记忆动态”（固化/自适应）的笛卡尔积构成 **2×2=4 个语义坐标**，实现“降阶效用状态”（Reduced-Order Utility States）。
- **四个坐标**：
  - **PCC（正向固化坐标）** ：保留全局效率最高的成功轨迹（`arg min 时长`），替换时继承旧效用值；
  - **PAC（正向自适应坐标）** ：保留失败后第一条成功恢复轨迹，捕捉从失败到成功的转换信号；
  - **NCC（负向固化坐标）** ：保留积累了正向效用证据的高效用失败轨迹（效用超过负初始化阈值者），可重复利用诊断性失败经验；
  - **NAC（负向自适应坐标）** ：保留最近一次失败轨迹，快速响应当前错误状态但避免存储所有失败。
- **检索与更新流程**：
  - 将当前查询嵌入与坐标代表记忆做加权余弦相似度（相似度 + Q 值加权），取 Top-k 作为检索集；
  - 任务完成后用标准 Q 更新：`Q ← Q + α·1[被检索]·(r_t − Q)`；
  - 新经验根据角色规则更新/替换对应坐标内容，坐标语义固定但内容可变，从而把反馈集中在有界支持上。
- **理论分析**：
  - **定理1（方差-偏差分解）**：观测效用 `Q̂` 估计的是原始回报均值 μ，而非边际贡献 θ；误差中包含观测归因偏差 a 和任务基线 v0，增加反馈只减方差不消除偏差；
  - **定理2（充分反馈预算）**：全池估计所有记忆的原始回报需反馈 `O(N_t/ε²·log(N_t/δ))`，随记忆数线性增长；
  - **定理3（反馈集中）**：降阶到 d 维后，每个坐标平均反馈为 `kT/d`，方差从 `O(σ²N_t/(kT))` 降为 `O(4σ²/(kT))`；
  - **命题1（稳态错误占用）**：在清洁↔错误两状态转移模型下，错误坐标稳态占比 ≤ γ/(γ+λ)，当 `d·γ/(γ+λ) < N_t·ρ_full` 时，降阶状态的持久污染暴露严格小于全池。

## 3. 实验设计

- **数据集/场景**：
  - **ALFWorld**：文本交互式具身家庭环境，含 6 类任务（pick-and-place、examine、clean、heat、cool、pick-two），原有 3553 训练、140/134 验证；
  - **LifelongAgentBench（LAB）** ：操作系统（OS，500 任务，Bash 技能）与数据库（DB，500 任务，SQL 技能），采用 7:3 随机划分（种子 42）。
- **对比方法**：
  - 无记忆、Pass@k、RAG、Mem0、MemP（过程记忆）、MemRL（运行时记忆强化学习，最接近的基线）；
  - 额外做了 **MemRL+UCB** 的受控 MRT 压力测试，以及跨模型记忆转移实验（GPT-5.4-mini、Gemini-3.5-flash）。
- **评价指标**：Success Rate（SR）、Cumulative Success Rate（CSR）、Cold-Q 比例、反馈密度、记忆池大小、LLM 调用数、平均步骤数。

## 6. 论文的主要结论与发现

- **降阶效用状态有效**：固定 4 个语义坐标代替不断增长的全量轨迹效用，能显著提高每个效用坐标的反馈强度（约 6 倍），同时减少 Cold-Q（未更新记忆）比例（降 80%）。
- **抑制记忆-奖励陷阱**：由于受污染坐标数量被限制在常数维，噪声记忆的存活比例和误正向更新均大幅下降，任务成功率反而提升；证明“更广探索”并非解决覆盖与污染矛盾的唯一途径。
- **效率提升**：固定支持集和角色化替换减少了冗余记忆保留、缩短了任务步骤，从而降低 LLM 调用和存储开销，且不损失（甚至提升）性能。
- **失败经验具有价值**：NCC 保留了高 Q 值得失败记忆，其高占用率（OS 27.14%，DB 42.78%）与消融结果共同说明，诊断性失败证据对当前性能与累积覆盖均有益；PAC 虽占用率低，却提供关键的成功恢复信号。
- **可迁移性**：冻结的记忆状态可跨模型转移，提升不同推理骨干的性能并减少步骤数。

## 8. 不足与局限

- **因果归因仍未解决**：作者明言方法仍基于包级（bundle-level）奖励，Q 更新共享于共同检索的记忆，无法从根本区分“纯粹因检索集合而受益”与“真正贡献”的记忆；MRT 只是被抑制而非被消除。
- **理论假设较强**：如反馈“近似均衡分配”、坐标转移的 γ 与 λ 需从配对反事实中估计，现实中很难精确获得，命题 1 的实际可操作性有限。
- **实验覆盖有限**：未在超长时域、开放式任务（如知识图谱或真实生产环境）上验证；只做了 10 轮训练，冷启动/长尾行为需要更长期评估。
- **探索策略不足**：RoMeRL 的检索主要依赖相似度 + Q 值加权，缺少显式探索机制；在弱监督奖励或奖励稀疏场景下，固定支持可能收敛到次优局部解。
- **可扩展性依赖语义嵌入质量**：坐标替换依赖文本嵌入的语义相似度，嵌入模型偏差可能造成跨任务误替换或检索噪声。
- **统计严谨性**：缺少多次运行的标准差/置信区间；跨模型转移实验中只报告 4 个组合（2 模型 × 2 任务），样本量小。
