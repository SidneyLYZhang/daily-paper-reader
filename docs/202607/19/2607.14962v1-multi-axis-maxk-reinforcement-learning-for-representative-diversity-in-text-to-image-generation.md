## 摘要
文本到图像（T2I）模型能够合成逼真、与提示对齐的图像，然而，针对同一提示生成的样本通常仅覆盖视觉上不同模式的少量子集。这限制了图像的多样性，并且对于以人为中心的提示，可能会反映或放大人口统计学偏差。我们将此问题形式化为对一组预定义的语义指定模式的覆盖，称为目标模式覆盖。然后，我们提出多轴max@K，一种基于群体的强化学习目标，用于改善基于扩散的T2I模型中的这种覆盖。给定一组样本和每个目标类别的一个分数，多轴max@K首先对每个类别取样本间的最大分数，然后将这些类别维度上的最大值求和。由此产生的信用分配仅在样本提升该类别的组内最大值时给予其该类别上的正权重，从而允许不同样本贡献于不同类别。我们首先在合成混合数据及使用确定性基于像素的颜色奖励的SD3.5-M上验证了信用分配机制。然后，我们在感知外观公平性上评估了相同目标。在三个自动评估器对保留提示的测试中，多轴max@K相对于基础模型将公平性得分提高了0.23-0.36，同时保持了图像质量和文本对齐。

## Abstract
Text-to-image (T2I) models can synthesize realistic, prompt-aligned images, yet samples generated for the same prompt often cover only a small subset of visually distinct modes. This limits the diversity of images, and for person-centric prompts, can reflect or amplify demographic skew. We formalize this problem as coverage of a predefined set of semantically specified modes, which we call target-mode coverage. We then propose multi-axis max@K, a group-based reinforcement learning objective for improving such coverage in diffusion-based T2I models. Given a group of samples and one score per target category, multi-axis max@K first takes the maximum score across samples for each category and then sums these category-wise maxima. The resulting credit assignment gives a sample positive weight on a category only when it increases that category's group-wise maximum, allowing different samples to contribute to different categories. We first validate the credit-assignment mechanism on a synthetic mixture and on SD3.5-M using deterministic pixel-based color rewards. We then evaluate the same objective on perceived-appearance fairness. Across three automatic evaluators on held-out prompts, multi-axis max@K improves the Fairness Score by 0.23-0.36 relative to the base model, while maintaining image quality and text alignment.

# 论文详细中文总结

## 1. 论文的核心问题与整体含义（研究动机和背景）
- **问题**：文本到图像（T2I）模型（如 Stable Diffusion 3.5）能为同一提示生成高质量、对齐的图像，但多次采样得到的图像往往只覆盖少量视觉上截然不同的模式（mode），缺乏多样性。对于人物类提示，这种限制会反映或放大人口统计学偏见（如种族、性别分布不均）。
- **背景**：现有扩散模型的强化学习后训练方法（如 DDPO、Flow-GRPO）使用标量奖励优化单张图像，无法处理互斥类别（如一种肤色无法同时代表多种种族）下的组级多样性。而去偏方法（如 FairImagen、Weak Guidance）常以图像质量为代价。本文旨在通过组级目标实现代表性多样性（representative diversity）——即在一个样本集中，不同样本分别成为不同目标模式的最佳代表。

## 2. 论文提出的方法论
- **核心思想**：将多样性定义为对预定义目标模式（target mode）的覆盖。对于一组样本，每个类别先独立选取该组中的最大得分（max@K），然后将这些类别最大值求和。这种“轴先选代表再聚合”的顺序允许不同样本贡献于不同模式，而标量先聚合会丢失类别信息。
- **关键技术细节**：
  - 对每个提示 \(c\)，生成 \(m\) 个候选样本，由固定评估器为每个样本输出 \(D\) 个目标类别的软得分 \(r_d(x_i, c)\)。
  - 组级目标：\(G_k(S_k, c) = \sum_{d=1}^{D} w_d(c) \max_{x_i \in S_k} r_d(x_i, c)\)，其中 \(k\) 是训练窗口大小。
  - 信用分配：对每个样本 \(x_i\) 在轴 \(d\) 上的优势 \(A_d^i = [r_d(x_i, c) - \max_{j\neq i} r_d(x_j, c)]_{+}\)，采用期望改进（EI）+ 留二出（L2O）估计器计算，然后标准化后跨轴求和得到单样本策略权重 \(\hat{A}_i\)。
  - 训练算法：基于 Flow-GRPO 框架，将标量优势替换为上述多轴代表信用，保持 SDE 采样、重要性比率裁剪和 KL 正则化不变。
- **公式/算法流程**（文字说明）：
  1. 对每个提示，从当前策略采样 \(m\) 个候选图像。
  2. 使用固定评估器计算 \(D \times m\) 奖励矩阵 \(R\)。
  3. 对每个轴 \(d\)，用 EI+L2O 计算样本 \(i\) 的原始优势 \(\tilde{A}^d_i\)，然后组内标准化得到 \(\bar{A}^d_i\)。
  4. 将所有轴的 \(\bar{A}^d_i\) 按权重 \(w_d\) 求和得到最终优势 \(\hat{A}_i\)。
  5. 用 GRPO 更新 LoRA 适配器。

## 6. 论文的主要结论与发现
- 多轴 max@K 在三个自动评估器上将公平性分数提升 **0.23–0.36**（相对于基础模型），同时保持 PickScore、Aesthetic Score 和 CLIP-T 不变（甚至略有提升）。
- 最接近的匹配基线（GRPO (count)）只能小幅改进，而单图像基线 (\(k=1\)) 几乎无变化。说明代表性信用分配（不同样本代表不同模式）是关键。
- 消融表明窗口 \(k\) 接近类别数 \(D\) 时效果饱和；\(k < D\) 时覆盖不足，\(k > D\) 时额外增益微弱。
- 对于十种联合类别（种族×性别），方法同样有效，最小类别的出现概率从 13.5% 提升至 23.8%。
- 非人物提示的 OOD 分析显示，方法未增加无意的人物出现率（表 11）。

## 7. 优点
- **方法论简洁有效**：直接在组级上定义多样性目标，信用分配可解释（仅当样本提升某类别组内最大值时才获得信用），无需修改模型结构或推理步骤。
- **通用性强**：适用于任何具有可评分维度的场景（颜色、感知属性等），不限于公平性。
- **实验设计严谨**：从合成到真实、从像素规则到分类器、多评估器交叉验证，有效隔离了信用机制与评估器偏差。
- **保持质量**：与现有的推理时去偏方法相比，在提升多样性的同时不牺牲图像质量和文本对齐。

## 8. 不足与局限
- **需要每个目标模式的评分器**：方法依赖固定、可得的软评分器，对于缺失评分器的模式无法优化。评分器本身的质量（如 CLIP 对某些种族的偏差）会间接影响结果。
- **仅能提升已有模式**：方法只能重新分配概率质量给生成器已经支持的模式，不能创造新语义模式。对于模型从未见过的模式无效。
- **自动评估器风险**：尽管使用了三个自动评估器，但仍可能过拟合于特定 CLIP 表示或 VLM 模式。缺乏人工标注验证是主要局限。
- **固定目标模式集**：论文假设目标模式集是预定义的、固定不变的，且权重均匀。非均匀权重虽支持但未深入探索。对于不同应用，选择哪些模式、如何定义权重是一个开放问题。
- **窗口 \(k\) 随模式数增长**：\(k=D\) 需要足够大的组大小，当模式数很大时（例如几十种）会带来采样和计算压力。
- **身份定义简化**：感知种族和性别是自动标签，基于简化的五分类和二分类，无法覆盖多族裔、跨性别等复杂现实身份。论文只优化这些定义下的偏差，可能忽略其他维度。
