## 摘要
一个获得高奖励的强化学习代理是否代表了其任务的潜在状态，或者仅代表一个与奖励相关的捷径？这个问题通常无法回答：“真实状态”是未定义的。我们通过一个白盒工具使其可精确回答：将任务表示为一个隐蔽的确定性有限自动机（DFA），让代理观察符号流并在部分控制下间歇性地选择下一个符号，并为接受授予一个稀疏的终端奖励。知道自动机可以免费获得两样东西：最优回报（因此奖励成为可解释的归一化分数）和每一步的精确潜在状态（因此我们可以在不显示状态的情况下探测代理的表示）。因此，奖励成功和潜在状态学习成为可分别测量的量，它们的耦合由三个可控轴控制。优化器强度：在弱的在策略RL下，代理获得奖励，而每种架构的状态探测都是随机的，这诱使人们得出稀疏RL无法安装潜在状态的结论；预先注册的控制推翻了这一点——PPO+GAE恢复了状态，但仅部分恢复且种子方差高。任务结构：置换（群语言）结构是一个警告信号，可以在任何训练之前从转移函数中计算出来，并在153个容量控制的新自动机上保留，它以0.86的精度（103中的89）仅在一个方向上标记感知差距。观察信息量：当观察不携带状态时，无标签辅助是空洞的，并且根据观察揭示状态的比例恢复状态。其回报是仅奖励评估无法做出的区分：感知差距（潜在状态不可线性恢复，尽管可表示）与规划差距（状态可恢复但未使用）。因此，高奖励并不是任务理解的证据；代理是否恢复潜在状态可以提前预测。

## Abstract
Does a reinforcement-learning agent that earns high reward represent its task's latent state, or only a reward-correlated shortcut? The question is usually unanswerable: the "true state" is undefined. We make it exactly answerable with a white-box instrument: express the task as a hidden deterministic finite automaton (DFA), let the agent observe a symbol stream and intermittently choose the next symbol under partial control, and grant one sparse terminal reward for acceptance. Knowing the automaton gives two things for free: the optimal return (so reward becomes an interpretable normalized score) and the exact latent state at every step (so we can probe the agent's representation without ever showing it). Reward success and latent-state learning thus become separately measured quantities whose coupling is governed by three controllable axes. Optimizer strength: under weak on-policy RL the agent earns reward with the state probe at chance for every architecture, tempting the conclusion that sparse RL cannot install latent state; a pre-registered control overturns it -- PPO+GAE recovers the state, but only partially and with high seed variance. Task structure: permutation (group-language) structure is a warning sign computable from the transition function before any training, and held out on 153 capacity-controlled fresh automata it flags perception gaps at precision 0.86 (89 of 103), in one direction only. Observation informativeness: a label-free auxiliary is vacuous when observations carry no state and recovers it in proportion to how much they reveal. The payoff is a distinction reward-only evaluation cannot make: a perception gap (latent state not linearly recoverable, though representable) versus a planning gap (state recoverable but unused). High reward is thus not evidence of task understanding; whether an agent recovers latent state is predictable in advance.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：一个获得高奖励的强化学习（RL）代理是否真正学习了任务的潜在状态（隐藏的状态机），还是仅仅学习了与奖励相关的捷径（shortcut）？传统的奖励评估无法区分这两种情况。
- **研究动机**：许多实际任务（如工作流、API调用、多步骤表单修复）本质上是有限状态机（FSM）。代理可能表面上表现良好，但在任务变长、噪声增大或分布变化时失败，原因是它学习的是奖励捷径而非底层状态机。这种“目标误泛化”（goal-misgeneralization）问题之前只能通过行为观察来推测，缺乏精确测量工具。
- **整体含义**：本文提供了一个白盒仪器——将任务表示为隐藏的确定性有限自动机（DFA），从而能够精确测量奖励成功与状态学习之间的耦合关系。结论是：高奖励不等于任务理解；代理是否恢复潜在状态可以从自动机的结构提前预测。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：将任何有限状态近似任务表达为一个隐藏的DFA，让代理观测符号流并间歇性地（部分控制）选择下一个符号，仅在最终接受时获得一个稀疏的终端奖励。实验者完全知道DFA的结构，因此可以：
  - (a) 精确计算最优可达回报（oracle），从而将原始奖励归一化为可解释的分数；
  - (b) 每一步读出真实隐藏状态，用于线性探测（linear probing）代理的表示（但从不展示给代理）。
- **关键技术细节**：
  - **部分控制DFA环境（PartialControlDFAEnv）**：每个时间步，以概率p_control由代理选择动作，否则由环境均匀采样。代理观测整个符号历史、是否可控步、剩余时间，但从不观测隐藏状态。奖励为稀疏终端奖励（1表示接受，0表示拒绝）。
  - **精确最优返回计算**：通过向后归纳计算状态-步数的价值函数，得到最优接受概率，用于归一化代理的实际奖励。
  - **线性探测**：在策略rollout中，从代理的（策略网络头部之前的）特征中拟合线性分类器预测真实隐藏状态，报告相对于多数类基线的差距（probe gap），并执行控制任务和选择性检查。
  - **干预性探测**：编辑激活值沿解码状态方向，检查贪婪动作是否按转移函数改变，以区分表示是否被策略实际使用。
  - **监督容量上限**：在离线随机玩法上训练每个编码器完全监督地预测状态，评估架构的容量（与优化器解耦）。
- **三大可控轴**：
  1. **优化器强度**：弱在策略RL（A2C）导致探测随机，强优化器（PPO+GAE）可部分恢复状态。
  2. **任务结构**：置换（群语言）自动机是感知差距的高精度警告信号，可通过转移函数提前计算，并在153个未见过的新自动机上验证了精度0.86。
  3. **观测信息量**：无标签辅助（预测下一符号）在观测无状态时无效，随观测信息量增加而恢复状态。

## 3. 实验设计：数据集、场景、基准、对比方法

- **数据集/场景**：
  - **合成DFA任务**：设计并分类了多种自动机，包括parity (mod_2)、mod_k计数器 (k=3,5,7,9,11)、ends_with_1000、mined_ean、workflow_api、workflow_reconcile、no_three_zeros等，共计15个精心设计的任务。

## 6. 主要结论与发现

1. **奖励与状态学习是可分离的**：高奖励不一定意味着状态学习；弱优化器下奖励高但状态探测随机。
2. **优化器强度主导耦合**：A2C→PPO显著提升状态探测，但PPO恢复仍然是部分的（仅达到监督容量上限的一部分）。
3. **任务结构提供预警信号**：
   - 置换（群语言）结构是一个高精度（0.86）的单向警告信号：若自动机是置换自动机，则感知差距的概率很高（89/109个感知差距是置换自动机）。
   - 但非置换自动机情况复杂（20感知、14规划、16解决），不能简单反推。
   - 控制杠杆率（L）在样本内有效但外推失败，降级为类内严重性代理。
4. **观测信息量轴**：无标签辅助信号在观测无状态时完全无效，一旦观测携带少量状态信息（β≥0.1）即饱和恢复。
5. **区分感知差距与规划差距**：行为诊断（奖励差距）无法区分两者，而精确探测可以。感知差距需要修改状态可观测性或可栓定性，规划差距需改进策略利用。
6. **因果修复有效**：使潜在状态可观测（β≥0.1）或可栓定（添加可控保持动作）可消除差距。
7. **真实世界**：真实checksum（二进制整除）属于硬类，真实工作流属于非置换类且可学习。
8. **LLM代理初步结果**：结构轴和优化器强度轴复现，但未能在大模型上产生干净的感知差距（优化器无法在预算内提升mod_5上的奖励），作者将其归因于优化瓶颈而非表示瓶颈。

## 7. 方法学与实验设计上的亮点

- **白盒精确仪器**：将隐藏DFA作为已知对象，首次允许精确测量奖励与状态学习的关系，而不是通过行为推测。
- **三大可控轴的系统研究**：优化器强度、任务结构、观测信息量，每个轴独立控制，揭示了耦合的条件。
- **预注册控制**：§5.2的优化器vs奖励通道控制实验是在看到结果前注册的，增加可信度。
- **容量控制**：通过监督容量上限确保所有架构都能表示任务，避免归因错误。
- **外推验证**：在153个新颖随机自动机上验证结构信号的泛化性，且控制了容量。
- **因果干预验证**：不仅相关观察，还通过添加可栓定动作或信息观测通道因果地消除感知差距。
- **多维度探测**：线性探测（在策略）、干预探测、容量上限（离策略），分层验证。
- **真实世界迁移**：将仪器应用于真实代码和日志，展示实际相关性。
- **LLM代理端口**：将完整仪器迁移到LLM，尽管未完全成功，但提供了基准工具。

## 8. 不足与局限

- **规模限制**：合成套件状态数≤11，大部分为二进制符号。真实挖掘自动机达到20状态/10符号，但整体规模仍小。更大自动机是未来工作。
- **优化器效应量不确定**：PPO恢复是部分且种子方差大，虽然优化器强度阶梯表明趋势，但精确幅度不明确。
- **结构信号局限性**：
  - 单向性：置换结构是高精度警告信号，但非置换自动机情况复杂（20/50有感知差距），无法安全保证。
  - 控制杠杆率阈值无法外推，仅作为类内严重性代理。
  - 非置换感知差距未被清洁结构属性解释，是“真正的开放问题”。
  - 只验证了GRU和LSTM（原套件），但架构非独特性尚未测试大量其他架构。
- **真实日志代表性不足**：仅7个流程日志，且多数为2状态可学习，不足以代表真实世界广度。
- **β=0的真空细胞仅有3种子**，而过渡点有5种子，细粒度统计稍弱。
- **LLM代理部分**：未产生干净的感知差距，优化器强度轴仅复制了弱优化器结果，无法证明大模型上也能完全复现主要发现。作者将其作为初步工具发布，并邀请更强优化器实验。
- **无时间效率讨论**：论文未讨论训练时间、计算成本或实际部署可行性。
- **假设前提**：部分控制环境p_control固定（0.5），每步动作环境随机采样均匀，可能不覆盖所有实际分布。
