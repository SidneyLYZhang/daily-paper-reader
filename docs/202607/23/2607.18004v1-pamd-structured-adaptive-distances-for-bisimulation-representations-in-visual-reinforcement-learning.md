## 摘要
许多视觉强化学习算法通过将潜在距离匹配到由奖励和转移相似性驱动的行为距离来学习表示。在实践中，潜在距离的选择会强烈影响性能：使用固定的、预先指定的全局范数（例如，$\ell_p$范数或其他手工设计的度量）可能过于严格，无法捕获行为距离。相反，无约束的成对距离可能会允许退化解，即在没有改善表示的情况下降低度量损失。为了解决这一差距，我们引入了**PAMD：成对自适应马氏距离**，它参数化了一个正定的、成对条件化的度量，用于测量潜在状态相似性。PAMD是现有基于双模拟方法的简单插件，为固定的、预先指定的潜在距离提供了更具表现力但结构化的替代方案。我们在视觉MuJoCo连续控制任务上实证验证了我们的方法，当使用我们提出的距离时，几种最新的基于双模拟的强化学习算法的最终性能得到了显著提升。

## Abstract
Many visual reinforcement learning (RL) algorithms learn representations by matching latent distances to a behavioral distance induced by reward and transition similarity. In practice, the choice of the latent distance can strongly affect performance: using a fixed, pre-specified global norms (e.g., $\ell_p$ norms or other hand-designed metrics) may be overly restrictive to capture the behavioral distance. In contrast, unconstrained pairwise distances may admit degenerate solutions that drive the metric loss down without improving the representation. To address this gap, we introduce **PAMD: Pairwise Adaptive Mahalanobis Distance**, which parameterizes a positive-definite, pair-conditioned metric for measuring latent state similarity.   PAMD is a simple plug-in for existing bisimulation-based methods, offering a more expressive yet structured alternative to fixed, pre-specified latent distances. We empirically validate our method on visual MuJoCo continuous-control tasks, where final performance of several recent bisimulation-based RL algorithms is substantially improved when equipped with the distance we propose.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：在视觉强化学习中，双模拟（bisimulation）类方法通过学习一个行为距离（behavioral distance）来量化状态间的行为相似性，其定义基于奖励和转移相似性的不动点。现有方法通常采用固定的潜在距离度量（如 $\ell_p$ 范数、余弦距离或 MICo 距离）来匹配该目标距离。
- **核心矛盾**：固定范数过于刚性，无法适应不同区域和方向的变化；而完全可学习的无约束成对距离（如 MLP 直接输出标量）虽灵活，但容易导致退化解——距离模块直接拟合目标而编码器未得到有效训练，从而无法形成有结构的表示。
- **研究动机**：在固定范数与无约束学习之间寻找一种既具表达能力又有结构约束的距离度量，以改善双模拟表示的嵌入质量，进而提升下游控制性能。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：提出**PAMD（Pairwise Adaptive Mahalanobis Distance）**，即一种成对条件的正定二次型距离。它将潜在距离参数化为依赖于具体状态对的马氏距离，能够捕获上下文依赖的各向异性，同时保留基于位移的几何结构。

- **关键技术细节**：
  - 给定潜在表示 $z, z' \in \mathbb{R}^p$，定义位移 $\Delta = z - z'$。
  - 通过一个轻量级 MLP（称为 MetricNet）以 $[z; z']$ 为输入，输出 $p(p+1)/2$ 个标量，填充下三角矩阵 $L_\theta(z,z')$。
  - 通过 Cholesky 分解构造正定矩阵：$G_0(z,z') = L_\theta L_\theta^\top$，再对称化：$G_\theta(z,z') = G_0(z,z') + G_0(z',z)$。
  - 添加 ridge 项 $\bar G_\theta = G_\theta + \lambda I$，然后进行迹归一化以消除尺度自由度：$\tilde G_\theta = \bar G_\theta / (\mathrm{tr}(\bar G_\theta) + \varepsilon)$。
  - 最终距离：$d_\theta(z,z') = \sqrt{\Delta^\top \tilde G_\theta(z,z') \Delta + \varepsilon}$。
  - 该距离可直接替换现有双模拟目标中的潜在比较器，成为“即插即用”模块。

- **算法流程（文字说明）**：
  1. 从回放缓冲区采样状态对 $(s,s')$ 及其奖励、下一状态。
  2. 通过编码器 $\phi$ 获得潜在 $z=\phi(s)$。
  3. 使用 MetricNet 和上述公式计算 PAMD 距离 $d_\theta(z,z')$。
  4. 按基线方法（如 MICo、SimSR、DBC）计算目标距离（基于奖励差异和下一状态距离的 Bellman 算子）。
  5. 最小化均方误差损失 $\mathcal{L}_{\text{metric}} = \mathbb{E}[(d_\theta - \text{target})^2]$，联合训练编码器 $\phi$ 和 MetricNet 参数 $\theta$。

- **理论保障**：Lemma 4.1 给出了 PAMD 相对于欧几里得距离的谱界：$d_\theta(z,z') \lesssim \|\Delta\|_2$ 且在一定迹界下 $d_\theta(z,z') \gtrsim \|\Delta\|_2$。同时，由于目标行为距离的不动点性质未改变，相关理论保证仍然成立。

## 6. 主要结论与发现

- PAMD 作为结构化距离插件，在 DBC 和 MICo/SimSR 两个双模拟算子族中均显著提升最终控制性能（表 1、图 2）。
- 全参数化的正定二次型优于对角变体，说明跨坐标的成对交互是必要的。
- 迹归一化防止尺度退化，是必要的稳定机制。
- 残差诊断表明：无约束 MLP 距离可在冻结编码器下大幅降低残差，而 PAMD 主要依赖编码器联合适应来降低残差，从而迫使编码器学习有意义的表示，这与更好的控制性能一致。
- 在自然视频干扰物下，PAMD 仍保持鲁棒性。

## 7. 优点

- **方法创新**：在固定范数和完全可学习距离之间找到了一个良好的平衡点，既具有表达力又保持结构约束，防止退化解。
- **即插即用**：可作为轻量模块直接替换现有双模拟方法的潜在距离，无需修改目标定义。
- **理论与实验双重验证**：通过 Lemma 4.1 提供理论界，通过残差诊断直接证明结构化设计阻止编码器欠训练，解释性能提升原因。

## 8. 不足与局限

- **计算开销**：当前实现采用稠密的成对正定矩阵，通过 Cholesky 分解构建，当潜在维度较大时（d>50）会带来 $O(d^3)$ 的矩阵运算开销，影响了向更高维表示的扩展性。
- **实验覆盖不全面**：
  - 只评估了 DMC 上的部分任务，未在更广泛的机器人操纵任务（如 Meta-World）或复杂 3D 场景（如 DMControl Suite 的更多环境）中进行测试。
  - 与 TACO、DrQ-v2 等先进方法的对比为非完全公平（不同训练配方），作者也指出需要更严格的对照实验。
- **缺乏对其他相似性目标的研究**：PAMD 目前仅用于行为距离（奖励+转移相似性），未探索是否适用于值函数距离或优势距离等其他目标。
- **未讨论全局度量性质**：PAMD 的成对条件化并不保证三角不等式等全局度量性质，但作者明确表示不要求这些性质。
