## 摘要
概念如何在神经网络中被表示是机器学习中的一个基本问题。主流观点将概念表示视为静止的几何对象。然而概念出现在上下文中，并且上下文会转换它们。借鉴神经群体几何学，我们将概念表示形式化为点云流形，将上下文转换形式化为向量场，并在大型语言模型中实例化这一框架。在六个不同规模的模型族中，我们发现上下文对每个概念的移动方式不同。这些位移的方差在语义上是有组织的，与词汇的具体性和密集度相关。重要的是，被转换的概念以及这种方差结构在不同模型之间是共享的：从一个模型迁移的位移结构能够显著高于随机水平预测其他模型中未见的位移。综上所述，这些发现表明模型不仅共享概念表示的共同几何，更重要的是共享上下文如何转换它们的共同几何，这种结构的组织比先前工作所认识到的更为丰富。

## Abstract
How concepts are represented in neural networks is a fundamental question in machine learning. The dominant view treats concept representations as stationary geometric objects. Yet concepts appear in context, and context transforms them. Drawing from neural population geometry, we formalize concept representations as point-cloud manifolds and contextual transformations as vector fields, and instantiate this framework in large language models. Across six model families of varying scales, we find that context moves each concept differently. The variance in these displacements is semantically organized, correlating with lexical concreteness and density. Importantly, both the concepts being transformed and this variance structure are shared across models: displacement structure transported from one model predicts held-out displacements in others significantly above chance. Together, these findings show that models share a common geometry not only in how concepts are represented, but more importantly in how context transforms them, a structure with richer organization than prior work has recognized.

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：打破“概念=静态向量”假设，将每个概念在不同上下文中的表示视为一个点云（point-cloud manifold），上下文变换定义为从源上下文到目标上下文的位移向量场。跨模型比较时关注**关系几何**而非绝对坐标。
- **关键技术细节**：
  - **表示提取**：对于词 \(w\) 在上下文 \(c\) 中，取最后一个token（或子词均值）的隐藏状态作为表示 \(r^{(m)}(w,c)\)。
  - **点云流形**：同一概念在 \(N\) 个不同上下文下的表示构成点云 \(X_w^{(m)}\)，通过核矩阵（如线性核）刻画内部结构。
  - **上下文变换向量场**：定义源上下文 \(\tau_0\) 和目标上下文 \(\tau\) 的位移 \(\phi^{(m)}(w,\tau) = r^{(m)}(w,\tau) - r^{(m)}(w,\tau_0)\)，所有词的位移构成向量场 \(\Phi_\tau^{(m)}\)。
  - **跨模型对齐度量**：
    - **Centered Kernel Alignment (CKA)**：基于无偏HSIC估计，衡量核矩阵间的相似性，对缩放、旋转不变。
    - **Grassmann 距离**：比较向量场主子空间的方向一致性，通过主角度计算。
    - **置换校准**：通过200次随机置换生成零分布，校准观测相似度，避免有限样本膨胀。
  - **关系迁移（Relational Transport）**：在源模型上基于余弦相似度对训练词语的位移加权，预测目标模型中测试词的位移，评估预测与真实位移的秩相关和残差余弦相似度。

## 6. 主要结论与发现

1. **上下文变换场非均匀且方差有语义结构**：无单一主方向（PCA第一主成分解释方差仅7.3%-14.6%）。**词汇密度越大的词位移幅度越小**（ρ≈-0.22至-0.32，p<0.001）；**具体性越高的词方向离散度越小**（ρ≈-0.21至-0.41，p<0.001）。该关系在所有5种语义上下文中成立。
2. **变换场的跨模型对齐随能力而非规模增加**：MMLU分数与CKA/Grassmann对齐的相关系数（r≈0.78-0.81，p<0.001）显著强于参数量对齐。
3. **关系结构可迁移**：从一个模型（Qwen2.5-7B）的位移关系结构可显著预测另一模型中的位移幅值排序和方向残差，远优于随机基线。
4. **概念空间几何（内在与概念间）跨模型共享**：CKA在中间层普遍>0.7，且真实上下文下的跨模型对齐远高于打乱上下文或静态嵌入（p<0.0001，r>0.82）。
5. **跨模型共享的并非表面统计而是深层语义组织**：打乱上下文后跨模型对齐接近随机，静态嵌入（Word2Vec/GloVe）对齐度显著更低。
