## 摘要
预训练的生成式机器人策略能够从演示中学习富有表现力的动作先验。然而，现有强化学习方法仅引导噪声空间，却无法在生成过程中调节中间动作表示，导致性能下降和效率低下。为解决这一局限，我们提出了一种新颖的双潜在空间强化学习（DLSRL）框架，通过在冻结生成器内部进行表示级控制，补充初始噪声引导。具体而言，我们的演员网络预测两个不同的潜在变量：一个用于引导行为生成的初始噪声潜在变量，以及一个用于中间特征调制的动作表示潜在变量。此外，该表示潜在变量被映射为适配器特征，并通过残差连接巧妙地注入到中间动作 token 的隐藏状态中。我们的双控制设计能够在不更新基础策略的情况下直接调整动作表示。在生成式策略架构和机器人操作任务上的实验表明，DLSRL 有效加速了在线机器人策略自适应，并取得了有竞争力的性能。我们的代码可在 https://github.com/xianchaoxiu/DLSRL 获取。

## Abstract
Pretrained generative robot policies learn expressive action priors from demonstrations. However, existing reinforcement learning methods only steer the noisy space but fail to modulate intermediate action representations during the generation process, resulting in performance degradation and inefficiency. To address this limitation, we propose a novel Dual-Latent Space Reinforcement Learning (DLSRL) framework, which complements initial-noise steering with representation-level control inside the frozen generator. Specifically, our actor network predicts two distinct latent variables: an initial-noise latent variable that steers behavior generation, and an action-representation latent variable for intermediate feature modulation. Moreover, this representation latent variable is mapped to adapter features and ingeniously injected into the hidden states of intermediate action tokens via residual connections. Our dual-control design enables direct adjustment of action representations without updating the base policy. Experiments across generative policy architectures and robotic manipulation tasks show that DLSRL effectively accelerates online robot policy adaptation and achieves competitive performance. Our code is available at \href{https://github.com/xianchaoxiu/DLSRL}{https://github.com/xianchaoxiu/DLSRL}.

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型与生成式策略（如 Diffusion Policy、RDT-1B、π0）通过从大规模演示中学习表达性强的动作先验，为通用机器人操作提供了可扩展路径。
- **核心痛点**：当下游环境与预训练分布存在偏差时，策略需要在线自适应。然而现有强化学习方法存在两类局限：
  - **初始噪声引导类**（如 DSRL）：仅调节生成过程的起始噪声，对后续中间表示的影响是间接的。
  - **残差策略类**（如 Residual RL、Policy Decorator）：在动作生成之后施加修正，无法塑造生成过程中内部动作表示的演化。
- **关键缺口**：缺乏一种能够在**冻结生成器内部**同时进行全局行为选择与中间动作表示直接调制的强化学习机制。当任务需要精确修正接触位置、动作幅度或局部轨迹时，这一缺陷尤为突出。
- **整体含义**：论文提出 DLSRL，首次将初始噪声引导与动作 token 隐藏状态调制相结合，在不更新基策略参数的前提下实现更高效的在线自适应。

## 2. 方法论

### 核心思想

- 将传统噪声空间 actor 扩展为**双潜在空间 actor**，同时预测：
  - 初始噪声潜变量 $z_t$：控制生成起点，影响整体行为模式。
  - 动作表示潜变量 $u_t$：通过适配器特征 $f_t$ 调制中间动作表示，提供表示级控制。
- 基策略 $G_\phi$ 全程冻结，仅优化 actor 参数 $\theta$ 与适配器映射参数 $\omega$。

### 关键技术细节

- **问题建模**：机器人操作为 MDP，策略接收观测 $o_t=(I_t, q_t, \ell)$，生成动作块 $a_t \in \mathbb{R}^{H \times d_a}$。生成过程为 $a_t = G_\phi(o_t, z_t)$，目标是最大化折扣回报 $J = \mathbb{E}[\sum \gamma^t r_t]$。
- **双潜在 actor**：$(z_t, u_t) \sim \pi_\theta(\cdot \mid o_t)$，适配器特征 $f_t = A_\omega(u_t)$，最终生成 $a_t = G_\phi(o_t, z_t, f_t)$。
- **动作 token 隐藏状态调制**：
  - 第 $l$ 个冻结 Transformer 块输出 $H^{(l)}_{t,k} \in \mathbb{R}^{N_a \times d_h}$。
  - 适配器特征 $f_t$ 与隐藏状态同形状，经注入强度 $\lambda_{\text{inj}}$ 缩放后残差注入：$\tilde{H}^{(l)}_{t,k} = H^{(l)}_{t,k} + \delta_t$，其中 $\delta_t = \lambda_{\text{inj}} f_t$。
  - 同一 $f_t$ 在选定块与所有生成更新步间共享；仅作用于动作 token 位置，不修改视觉、语言、本体感知等上下文 token；**无需额外投影层或可训练参数**。

### 算法流程（Dual-Latent Policy Optimization）

- 训练包含两个仅用于训练的 critic：
  - **动作空间 critic** $Q^{\text{act}}_\psi(o_t, a_t)$：用标准 off-policy TD 学习。
  - **潜在空间 critic** $Q^{\text{lat}}_\nu(o_t, z_t, f_t)$：通过价值蒸馏目标学习：
    $$\mathcal{L}_{\text{distill}} = \mathbb{E}\left[\left(Q^{\text{lat}}_\nu(o_t, \hat{z}_t, \hat{f}_t) - \text{sg}[Q^{\text{act}}_\psi(o_t, \hat{a}_t)]\right)^2\right]$$
    梯度仅作用于 $\nu$，不穿过冻结生成过程。
- **Actor 更新**（熵正则化目标）：
  $$\mathcal{L}_{\text{actor}} = \mathbb{E}\left[\alpha \log \pi^z_\theta(z_t \mid o_t) - Q^{\text{lat}}_\nu(o_t, z_t, f_t)\right]$$
  熵正则化仅施加于噪声分支，但潜空间价值对 $z_t$ 和 $f_t$ 的梯度会传播至两个 actor 分支及适配器映射器。
- **交替更新**：动作 critic、潜在 critic、双潜在 actor 与适配器映射器交替更新；基策略参数 $\phi$ 始终保持冻结。部署时仅保留 actor 与适配器映射器，丢弃两个 critic。

## 6. 主要结论与发现

- **加速在线自适应**：DLSRL 在 RoboMimic 与 LIBERO 上普遍比 DSRL 更快达到饱和性能，优势在需要高动作精度的 Can 和 Square 任务上更明显。
- **最终性能有竞争力**：Can 任务上 DLSRL 后期成功率约 99%，DSRL 约 90%；Lift 任务上 DSRL 后期逐渐缩小差距。
- **执行效率提升**：LIBERO 六个任务上平均 episode 长度均缩短，降幅 15.27%–25.40%。
- **表示调制独立有效**：DLSRL-Rep 仅靠中间表示调制即可将成功率从约 27% 提升至 52%，说明该机制本身即可改善基策略，也解释了双控制接口组合加速自适应的原因。
- **注入强度存在最优值**：$\lambda_{\text{inj}}=0.09$ 初期提升最快但后期波动大；$0.03$ 更平稳；$0.06$ 在速度与稳定性间取得最佳平衡，最终达到 100% 成功率。有效表示控制需要足够强度但避免过度扰动预训练动作表示。
- **架构通用性**：双潜在控制的收益不限于 diffusion 策略，在 flow-matching VLA 策略上同样可观测。

## 7. 优点

- **方法创新性**：首次将初始噪声引导与动作 token 隐藏状态调制统一到一个 RL 框架中，将策略引导从采样初始化阶段扩展到中间表示阶段。
- **参数高效**：基策略完全冻结，仅训练轻量 actor 与适配器映射器；适配器特征与隐藏状态同形状，无需额外投影层，不改变基网络架构。
- **注入设计巧妙**：残差注入仅作用于动作 token 位置，不干扰视觉、语言、本体感知等上下文 token；同一特征跨块、跨生成步共享，实现简洁。
- **训练稳定性设计**：采用动作空间 critic + 潜在空间 critic 的双 critic 价值蒸馏机制，避免梯度穿过冻结生成过程，训练更稳定。
- **实验覆盖两类生成范式**：同时在 Diffusion Policy 与 π0 flow-matching 策略上验证，增强结论的通用性。
- **消融实验针对性强**：DLSRL-Rep 与注入强度分析直接回应了“表示调制是否独立有效”与“调制强度如何选择”两个关键问题。
