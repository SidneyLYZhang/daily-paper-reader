## 摘要
在大规模电子商务检索中，双编码器检索器针对对比相似性进行优化，而下游重排序器捕捉更细粒度的相关性偏好；这种目标不匹配限制了端到端的检索质量。强化学习提供了一种利用奖励模型反馈来调整检索器的方法，但我们观察到，标准的策略梯度更新可能会破坏嵌入几何结构，尤其是在工业约束下文档索引必须保持冻结时。为解决这一问题，我们提出了PAO（仅正优势），一种选择性强化学习优化方法。我们的分析表明，在冻结的高维空间中对负样本进行无差别惩罚（推开）会破坏预训练语义流形。PAO仅对具有正优势的检索项选择性地应用梯度更新，有效地将查询嵌入拉向高奖励区域，同时保持全局拓扑稳定性。在大型工业数据集和公开基准上的实验表明，PAO显著优于标准强化学习和蒸馏基线。

## Abstract
In large-scale e-commerce retrieval, dual-encoder retrievers are op- timized for contrastive similarity, whereas downstream rerankers capture finer-grained relevance preferences; this objective mis- match limits end-to-end retrieval quality. Reinforcement Learning offers a way to use reward-model feedback for retriever adaptation, but we observe that standard policy-gradient updates can degrade embedding geometry, especially when the document index must remain frozen due to industrial constraints. To address this, we propose PAO (Positive-Advantage-Only), a selective RL optimization method. Our analysis reveals that in- discriminate penalization of negative samples (pushing away) in a frozen high-dimensional space disrupts pre-trained semantic man- ifolds. PAO selectively applies gradient updates only to retrieved items with positive advantages, effectively pulling query embed- dings toward high-reward regions while preserving global topo- logical stability. Experiments on both a massive industrial dataset and public benchmarks demonstrate that PAO significantly outper- forms standard RL and distillation baselines.

### **一、论文核心问题与整体含义**

**研究背景：** 在大规模电商搜索/检索场景中，普遍采用"召回（Retrieval）+ 精排（Reranking）"的两阶段架构。第一阶段的**双编码器（Dual-Encoder）检索器**使用对比学习优化余弦相似度，追求高效召回；第二阶段的**重排序模型**则捕捉更精细的相关性信号。两者的优化目标存在天然的**不一致（Objective Mismatch）**：检索器学到的相似度分布与下游重排器所需的细粒度相关性偏好存在差距，从而限制了端到端的检索质量。

**核心问题：** 在工业检索环境中存在一个硬性约束——**文档索引（Document Index）必须冻结**。对数十亿商品向量频繁重建索引在算力上不可行，因此在线场景下只能微调查询编码器。论文尝试用强化学习（RL）将下游重排模型的奖励信号回传给检索器，以实现检索与排名的对齐。

**关键发现（失效模式）：** 标准的策略梯度（Policy Gradient, PG）算法在这种约束下会导致严重的性能退化，作者将其命名为**"几何塌缩"（Geometry Collapse）**。其机理是：在冻结的高维文档空间中，RL 对低奖励负样本的"推开"（pushing away）操作是一种盲目、无结构信息的操作——与对比学习中负样本配对约束不同，纯 RL 的推开会让查询嵌入漂移到**语义空洞（semantic voids）**区域，破坏预训练阶段形成的语义聚类流形，最终严重损害召回效果。

### **二、方法论：PAO（Positive-Advantage-Only）**

#### 2.1 核心思想

PAO 的核心洞察是：**在冻结索引场景下，只做"拉近"（pull），不做"推开"（push）**。具体而言，仅对**正优势（Positive Advantage）**的检索项施加梯度更新，将查询嵌入拉向"比平均更好"的候选文档区域；同时通过 **KL 散度约束**锚定预训练参考策略，防止策略漂移过大。这种选择性更新本质上是**建设性的局部微调**，而非破坏性的全局重构。

#### 2.2 RL 形式化

- **策略（πθ）**：由查询编码器 EQ(·; θ) 定义，给定查询 q 生成嵌入 e_q。
- **动作（Action）**：通过 MIPS（最大内积搜索）从冻结索引 D 中检索 Top-K 列表 L_q = {d₁, …, d_k}，视为从策略中采样的宏动作。
- **采样概率**：列表内文档的采样概率通过 Softmax 定义：

  \[
  P(d_i|q;\theta) = \frac{\exp(s_i / \tau)}{\sum_{j \in L_q} \exp(s_j / \tau)}
  \]

  其中 sᵢ = e_q^⊤ e_dᵢ 为相似度，τ 为温度系数。

#### 2.3 标准 RL 的缺陷

奖励由下游重排模型提供：rᵢ = M_rank(q, dᵢ)。使用标准化优势 Aᵢ = (rᵢ − r̄)/σᵣ 以降低方差。标准 REINFORCE 目标为：

  \[
  \mathcal{L}_{all} = -\sum_{i=1}^{k} A_i \log P(d_i|q;\theta)
  \]

  **问题所在：** 当 Aᵢ < 0 时，梯度将 e_q 推离 e_dᵢ。在冻结的高维空间中，这种"推开"拥有无限自由度，容易使查询嵌入落入语义真空区，导致聚类结构破坏、召回率急剧下降。

#### 2.4 PAO 策略

PAO 的目标函数为：

  \[
  \mathcal{L}_{pos}(\theta) = -\sum_{i=1}^{k} \mathbb{I}(A_i > 0) \cdot A_i \cdot \log P(d_i|q;\theta) + \beta \cdot \text{KL}(\pi_\theta \| \pi_{ref})
  \]

其中 I(·) 为指示函数，仅有正优势样本参与梯度回传；βKL 项作为全局锚点防止策略漂移。**逻辑闭环：** 查询向量始终朝向"已知的、存在于语义流形上的有效文档向量"移动，隐式保持了查询表示的有效性。由于正优势样本本身来自当前检索结果，这种拉近操作也是一种对检索边界的局部微调——让查询朝向高奖励子区域收缩，而非无差别推开导致的全局流形坍塌。

### **六、主要结论与发现**

1. **假设得到验证**：在冻结索引约束下，标准 RL 将所有样本无差别地纳入训练（含负优势"推开"）会导致严重的性能退化，在工业数据集上 NDCG@5 出现了 13.6 个百分点的灾难性下跌。t-SNE 可视化直观地证实了嵌入空间的聚类结构被破坏。
2. **PAO 显著优于对比方法**：在工业数据集上，相较于 Baseline，PAO 在 NDCG@5 提升 9.0 个百分点（0.7000 → 0.7896），在 Recall@5 提升 6.9 个百分点（0.7929 → 0.8618），表明选择性正向更新策略能有效提升端到端检索质量。
3. **跨场景泛化成立**：在 MS MARCO 上 PAO 均全面超越 Baseline 和 KL-Distill——与 KL-Distill 相比在深召回（Recall@50 +2.31pt）上尤为突出，体现出通过 RL 对正优势样本过滤比直接蒸馏软分布更稳定的优势。
4. **语义一致性提升**：LLM-Judge 评估确认 PAO 能在深召回（Hits@20 +2.1pt）和需求匹配度（Matchment +1.4pt）上提升检索结果的语义质量，而非表面指标的虚高。
5. **超参选择经验**：β = 0.3 与 τ = 1.0 为最优配置，表明需要适度的 KL 锚定与充分的探索能力。

### **八、不足与局限**

- **假设前提较强**：PAO 假设冻结的索引已经覆盖了召回目标；如果相关文档不在索引中，则 RL 微调无法"创造"新知识。在文档覆盖不完整的冷启动场景下，方法价值有限。
- **奖励模型偏差风险——奖励作弊（Reward Hacking）**：若下游重排模型本身有偏差（如偏好标题党），PAO 的高效"拉近"机制会将这些偏差放大并快速传播进检索阶段。以单一奖励模型为监督的闭环缺乏防御机制。
- **实验细节透明度欠佳**：未披露工业数据集文档库的具体规模、类别与难度分布；RL 训练推理时使用的 GPU 资源未说明；没有提供统计显著性测试的信息。
- **基线覆盖不够全面**：没有与更进阶的对比学习变体、更好的负采样策略、或多目标 RL 方法（如 Similar 领域的 Retrieval-GRPO）对比；建议补上更多 SOTA 参照系以闭环验证有效性。
- **缺少对"负样本推开"假说的隔离验证**：虽然"RL-All 对比 RL-Pos"试了验证这一点，但并未单独验证"冻结索引 vs. 可更新索引"对于几何塌缩的作用关系（若文档索引可更新，RL-All 是否仍会退化？），这一点将更彻底地确认因果边界。
- **局限性文本已自我承认**：论文承认未验证检索器-重排器交替迭代更新的闭环——即未来检索器更新后，重排器若能重新训练，将如何进一步扩大这种收益，该方向尚待深入验证。
