## 摘要
针对大型预训练模型的参数高效微调，已有多种几何感知的低秩自适应方法。这些方法旨在充分利用低秩流形的几何结构，通过在优化过程中施加正交约束来提高子空间利用效率并减少冗余。这些技术的强实证结果促使进一步研究此类基于几何的自适应方法的预测是否可能过于自信。在本文中，我们基于适配器的奇异值分解因式分解，开发了一个基于Stein变分梯度下降（SVGD）的框架。在该公式中，低秩矩阵沿着Stiefel流形传输，以匹配目标分布，同时保留其关键的几何结构。由于这种几何感知的SVGD方法在推断过程中提供多个解，它支持不确定性量化，并在Stiefel流形上产生校准更好的适配器。大量实验表明，我们的方法提供了强模型校准，并比在欧几里得空间中表述的SVGD和相关不确定性估计方法获得了更高的预测精度。

## Abstract
Several geometry-aware approaches to low-rank adaptation have emerged for parameter-efficient fine-tuning of large pre-trained models. These methods aim to take full advantage of the geometric structure of low-rank manifolds for improving the efficiency in subspace utilization and reducing redundancy by enforcing orthogonality constraints during optimization. The strong empirical results of these techniques have motivated further study into whether predictions from such geometry-based adaptation methods could be overconfident. In this paper, we build on the singular value decomposition factorization of adapters to develop a framework based on Stein variational gradient descent (SVGD). In this formulation, the low-rank matrices are transported along the Stiefel manifold to match the targeted distributions while retaining their crucial geometric structure. Since this geometry-aware SVGD approach provides multiple solutions during inference, it supports uncertainty quantification and produces better-calibrated adapters on the Stiefel manifold. Extensive experiments show that our method delivers strong model calibration and attains higher prediction accuracy than SVGD and related uncertainty estimation methods that are formulated in Euclidean space.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：大型语言模型（LLMs）在安全关键场景中广泛使用，但直接全量微调成本高昂。LoRA（低秩适配）已成为参数高效微调（PEFT）的主流方法之一，通过 `ΔW := (α/r)·BA` 的分解方式以远少于全量参数的代价完成对预训练权重的更新。
- **现有方法的局限之一**：常规 LoRA 将低秩因子视作无约束欧氏空间参数，忽略了低秩矩阵本身含有的几何结构；为克服该问题，近年来出现了 Stiefel-LoRA、StelLA 等几何感知方法，通过在**Stiefel 流形**上施加正交性约束，使得低秩适配器能够更充分地利用子空间维度。
- **现有方法的局限之二**：这些几何感知方法虽然带来了精度提升，但**缺乏不确定性量化与校准评估**，且微调本身可能导致模型产生“过度自信”的预测，尤其在面向安全关键领域时隐患明显。
- **本文目标**：将贝叶斯推断引入几何感知的低秩 PEFT，在 Stiefel 流形上执行**斯坦变分梯度下降（SVGD）**，使得推断过程保持低秩矩阵的正交结构，同时利用多个粒子（particles）提供后验近似，从而同时实现：
  1. 更可靠的不确定性估计（校准能力提升）；
  2. 保持甚至提升几何感知适配器的预测精度。

## 2. 方法论：StePS（Riemannian Stein Variational Gradient Descent for Bayesian PEFT on Stiefel Manifold）

### 2.1 核心思想

- 适配器采用基于截断 SVD 的三因子形式（同 StelLA）：
  ```
  ΔW := (α/r)·U·S·Vᵀ
  ```
  其中 `U ∈ R^{m×r}`, `V ∈ R^{n×r}` 为正交矩阵（位于 Stiefel 流形上），`S` 为对角矩阵，仅含奇异值。
- 在给定训练数据 D 下，将目标后验分布视为使如下能量泛函最优的分布：
  ```
  min_{ρ ∈ P(M)} F(ρ) = ∫ β·Ψ dρ + ∫ log ρ dρ
  ```
  其中 `Ψ` 为经验损失（如交叉熵），`β` 为逆温度。
- 通过 SVGD 的思想，在 Stiefel 流形上迭代传输一组“粒子”`{Ui, Si, Vi}`，使粒子分布逐步逼近目标分布，最终用多个粒子的预测平均来估计后验预测分布，从而量化认知不确定性。

### 2.2 关键理论推导

- **流形上的传输映射**：给定点 θ ∈ M（这里为 Stiefel 流形），映射形式为：
  ```
  T(θ) = Retr_θ( η · Proj_θ(φ(θ)) )
  ```
  其中 `Proj` 为到切空间的投影算子，`Retr` 为从切空间回到流形的回缩操作（re-traction）。
- **核心定理（Theorem 3，Stiefel 流形上的最速下降方向）**：通过 Wasserstein 梯度流的推导，最优速度场 φ* 为：
  ```
  φ*(θ) = ∫ [ −βκ(θ′,θ)·Proj_{θ′}(∇_{θ′}Ψ(θ′)) + Proj_{θ′}(∇_{θ′}κ(θ′,θ)) ] dρ_t(θ′)
  ```
  该公式与欧氏 SVGD 的差别在于：梯度项和核梯度项都经过**切空间投影（Proj）**，从而确保速度方向始终位于流形的切空间。
- **核函数选择**：使用 RBF 核 `κ(θ′,θ)=exp(−‖θ′−θ‖²_F/h)`，其在 Stiefel 流形上等价于常用的 von-Mises-Fisher（vMF）核，带宽 h 按照 SVGD 原论文的自适应中位数规则选取。
- **算法实现**（Algorithm 1）：
  1. 随机初始化 M 组粒子 `(U_{i,0}, V_{i,0}, S_{i,0})`，其中 U、V 在 Stiefel 流形上；
  2. 对每个粒子依次：计算完整权重并求损失；计算 U、V 的**欧氏梯度后再转为黎曼梯度**；
  3. 用公式 (20) 计算每个粒子的 SVGD 更新方向；对 U、V 做切空间投影与回缩（保证仍在流形上），对 S 按欧氏 SVGD 更新；
  4. 反复迭代直至收敛，返回最终粒子集用于后续贝叶斯预测。

## 6. 主要结论与发现

- **几何感知 + 粒子变分推断是可行的**：将 SVGD 从欧氏空间推广到 Stiefel 流形后，能得到闭式最速下降方向，并有效保留低秩适配器的正交结构。
- **显著改善校准**：相比 StelLA-MLE/MAP、LoRA-DE、欧氏 SVGD 等，StePS 在几乎全部数据集的 ECE 与 NLL 上都明显更优，这证实几何感知 PEFT 同样可被贝叶斯框架有效校准以抑制“过度自信”。
- **保持甚至提升精度**：StePS 在多数 in-distribution 与 out-of-distribution 数据上可同时取得最优/次优精度；尤其在大分布偏移（MMLU）下更能体现鲁棒性。
- **理论延展性**：论文推导的流形 SVGD 通过 Stiefel 流形上的切空间投影与回缩来实现，未来可推广至更一般矩阵流形或替换为 model-based（而非粒子式）变分推断以提升计算效率。

## 7. 优点与亮点

- **首个将贝叶斯推断引入 Stiefel 流形的 PEFT 联合框架**：在问题上具有较强新颖性。
- **理论推导完整**：从 Wasserstein 梯度流出发，将 SVGD 推广到 Stiefel 流形，给出了 Theorem 3 的形式化证明（见附录），而非简单套用现成方法。

- **实验基准丰富**：在 10+ 种基线上、跨 in-dist 与 OOD 设定进行对比，并有消融与耗时研究，验证了方法在“精度-校准-耗时”之间的整体平衡。

## 10. 总体评价

StePS 在“几何感知低秩适配 + 贝叶斯推断”的交叉点上提出了一个完整、理论自洽且工程可实现的方案。相比传统 LoRA、StelLA 和欧氏空间 SVGD，它在多数常识推理任务和 OOD 场景下都展现出更好的精度-校准折中，说明低秩流形上的后验近似确实比点在估计或欧氏后验传播更具表达力。

尽管其实验覆盖面仍局限在单一模型、固定秩和单任务类型上，其理论推导、公开代码与较充分的基线对比依然使其成为贝叶斯 PEFT 领域一个有价值的参照方法。对于安全关键应用中的 LLM 微调场景，StePS 提供了一个在可控开销下同时获得高精度与较可靠置信度的实用选择。
