## 摘要
贝叶斯神经网络无需完全随机即可成为通用条件密度近似器，但哪些参数应当随机仍是一个未决问题。我们通过对先验尺度（即参数先验的标准差）应用深度权重分解来学习这一划分，同时以最大均值差异为目标将函数先验拟合到高斯过程。当某个参数的先验尺度低于截断值时，该参数变为确定性参数，并在推断过程中进行优化，因此该正则化项稀疏化的是随机性而非容量。我们给出了一个可在在线性时间内检查的通用条件密度逼近证书，以及当该证书失效时的最小修复方案。我们进一步表明，对部分参数采样、对其余参数优化的常见混合方案，是针对第二类最大后验目标的随机逼近；并且耦合步长会留下一种即使步长缩小也不会消失的跟踪误差。在双峰目标上，学习得到的划分在所有预算下都接近无约束参考，并且对截断值不敏感；而将相同先验尺度分布到各层的随机掩码则最多差两个数量级。在 UCI 基准上，我们的方法与完全随机网络性能相当，同时使约一半参数保持确定性。

## Abstract
Bayesian neural networks need not be fully stochastic to be universal conditional density approximators, but it remains open which parameters should be stochastic. We learn this split by applying deep weight factorization to the prior scales, which are the standard deviations of the parameter priors, while fitting the functional prior to a Gaussian process with a maximum mean discrepancy objective. A parameter whose prior scale falls below a cutoff becomes deterministic and is optimized during inference, so the regularizer sparsifies stochasticity rather than capacity. We give a certificate for universal conditional density approximation that is checkable in linear time, together with a minimal repair when it fails. We further show that the common hybrid scheme of sampling some parameters and optimizing the others is stochastic approximation for a type-II maximum a posteriori objective, and that coupled step sizes can leave a tracking error that does not vanish as the step size shrinks. On a bimodal target, the learned split stays close to an unconstrained reference across all budgets and is insensitive to the cutoff, while random masks that distribute the same prior scales across layers are worse by up to two orders of magnitude. On UCI benchmarks, our method performs on par with a fully stochastic network while keeping about half of its parameters deterministic.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：贝叶斯神经网络（BNN）通过将参数视为随机变量，将神经网络灵活性与原则化不确定性估计结合，广泛用于需要可靠不确定性量化的场景。但完全随机化 BNN 计算成本高、参数量大。
- **关键前置结果**：Sharma et al. (2023) 从理论与实验上证明，**并非所有参数都需要随机**——只要随机参数数量与目标维度匹配、随机性置于早期层、且下游网络具备通用函数逼近能力，即可成为通用条件密度近似器（UCDA）。这为部分随机神经网络（PSNN）提供了理论依据。
- **核心未决问题**：理论上未说明**哪些参数应当随机**。由于参数分组方式组合爆炸，暴力搜索不可行；同时如何为随机参数选择合理先验也是难点。
- **本文立场与含义**：提出用**深度权重分解（DWF）作用于先验尺度**（参数先验的标准差），从而学习确定性/随机性的划分。与剪枝、spike-and-slab 不同，本文被"剪掉"的参数（先验尺度坍缩为零者）转为**确定性参数并在推断中继续优化**，因此正则化**稀疏化的是随机性而非容量**。此外，本文还厘清了部分随机网络常用的"部分采样、部分优化"混合推断方案究竟在优化什么目标。

## 2. 方法论

### 2.1 核心思想
- 将 DWF（Kolb et al., 2025）从网络权重迁移到**先验标准差（先验尺度 σ_θ）**上；σ_θ 坍缩为 0 的参数变为确定性参数。
- 通过最小化网络函数先验与目标高斯过程之间的 **MMD** 来拟合函数先验，从而在**不使用任何已训练模型**的情况下学习划分。

### 2.2 关键技术细节

**先验尺度参数化**
- 对每个 θ ∈ Θ^(l) 引入 D 个因子 (ω_i)_i=1^D，其乘积 u_θ = ∏_{i=1}^D ω_i（Hadamard 积）。
- 先验尺度 σ_θ := H(u_θ)，其中 H(u) = (h(u) − h(0))²，h(u) = log(1 + exp(u))（softplus），保证非负且 H(u)=0 ⟺ u=0。
- 先验 θ ~ N(μ_θ, σ_θ²)，均值 μ 与尺度 σ 均为可训练参数；μ 初始化为 0。

**优化目标**
- min_{μ,ω} L(μ, ω) = L_k(μ, H(u)) + Σ_{l=1}^L λ_l Σ_{θ∈Θ^(l)} Σ_{i=1}^D (ω_i_θ)²
- 其中 L_k 为函数先验与目标 GP 之间的 MMD 期望（在随机测量位置上取期望）。
- 优化中，先验尺度低于截断值 c 的参数被置为确定性，不再接收梯度；优化结束后若证书失效则执行最小修复。

**测量位置生成器**
- G = ρ_M · P̂_Xtrain + (1 − ρ_M) · U(x_min, x_max)，即每个位置以 ρ_M 概率为训练输入、否则均匀采样；实验取 ρ_M = 0.7。均匀分量迫使匹配在训练数据之外也成立，这正是 OOD 不确定性评估的区域。

**核心理论结果**
- **定理 4.1（无小的非零尺度）**：D ≥ 3 时，在精确驻点处要么所有因子为零（σ_θ = 0），要么 |u_θ| ≥ t_l := (2λ_l / (D·G_l))^{D/(D−2)}，且 σ_θ ≥ H(−t_l) > 0。即存在尺度上的"间隙"，若 c 落在该间隙内则结果对 c 不敏感（实践中驻点是近似的，间隙不保证，故对 c 仍有依赖）。
- **命题 4.3（MMD 退化为矩匹配）**：对二次多项式核 k(x,y) = (1+⟨x,y⟩)²，MMD²₂(P,Q) = 2‖μ_P − μ_Q‖²₂ + ‖M_P − M_Q‖²_F，即匹配均值与二阶矩，权重由核固定无需调参。
- **引理 A.3（勾股分解）**：KL(P‖Q) = KL(P‖P̃)（非高斯性）+ KL(P̃‖Q)（矩差异）。当随机参数少于测量点时，网络输出无密度，两个散度均为无穷，只有矩差异可控——这解释了为何用矩匹配目标。
- **命题 4.7（确定性证书）**：若偏置覆盖 U(S) ≥ d_L 且完全确定性单元数 |T| ≥ d_0，则掩码网络为 UCDA；可在 O(|Θ^(1)|) 时间检查。定义 4.4 特意计数**偏置**而非权重，因为随机输入权重项 σ·ε·x 在 x=0 处消失，无法保证尺度有下界。
- **推论 A.9（最小修复）**：证书失效时，最多改变 d_L 个第一层偏置、并（如有需要）将最"便宜"的 d_0 − |T| 个单元完全确定性化；该修复在给定约束下参数改动数最少（基于线性拟阵的贪心最小权基）。
- **定理 4.9（混合推断 = 第二类 MAP 的随机逼近）**：对近退化近似 q_ε ⊗ q_s，KL(q_ε ⊗ q_s ‖ Π_τ) = −(k/2)log(2πeε²) + F(θ_d, q_s) + R_ε，其中 F = KL(q_s‖p(·|D,θ_d)) − J_τ(θ_d) + c。最小化 F 等价于采样后验并最大化第二类 MAP 目标 J_τ。由 Fisher 恒等式，混合方案即随机逼近 EM，采样器充当蒙特卡洛 E 步。
- **推论 4.10（耦合步长导致不消失的跟踪误差）**：若采样步长 h 与优化步长 η 耦合（h = η），平稳性误差趋于 L_π·G/c > 0 而非 0；解耦（h → 0 且 η/h → 0）则误差消失。该界在 Gaussian 例子中被证明是紧的（命题 A.14）。因此实现中让优化器步长衰减快于采样器步长。
- **命题 A.12 / 推论 A.16**：超参数 γ（τ = γ log 2）在"冻结确定性参数"（γ↓0）、"第二类 MAP"（有限 γ）、"第二类极大似然"（γ↑∞）之间插值；漂移半径满足 τ²‖g₀‖/(1+τ²L_g) ≤ ‖θ*_d − μ̂_d‖ ≤ τ²‖g₀‖/(1−τ²L_g)。

**推断流程**
- 确定性块用 Adam 在 N(μ̂_d, τ²I_k) 下优化，随机块用 SGHMC 在 ∏ N(μ̂_θ, σ̂_θ²) 下采样。
