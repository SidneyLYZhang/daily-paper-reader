# Anchor Divergence for Semantic Geometry in Contrastive Learning 

## Akash Kannan 1, Kiho Park 1, and Victor Veitch 11University of Chicago 

Abstract 

This paper concerns how semantic context determines geometry in learned vector representations. Similarity is typically measured using cosine similarity, which provides a single fixed geometry. Semantic similarity, however, is inherently context dependent: two images may be similar because they depict the same object, share a visual style, or are relevant to the same clinical finding. We show that contrastive representations naturally encompass a family of geometries that can be specialized to particular semantic structure. The key idea is to use an interplay between contrastive learning, exponential families, and information geometry to establish a correspondence between probability distributions over “anchors” and Bregman geometries on the representation space. We use this correspondence to define Anchor Divergences , a method for specifying context-specific semantic geometries on fixed representations. Under this correspondence, modeling the anchor distribution models the geometry itself. Experiments on retrieval show that anchor divergences provide an effective and efficient way to specify context-specific semantic similarity. Code is available at github.com /sky1712 /Anchor-Divergence. 

# 1 Introduction 

Modern AI systems encode semantic structure in dense vector representations. This pa-per asks how similarity between such representations should be measured. We focus on contrastive models such as CLIP and its successors [Rad +21 ], which are trained to score matched query–key pairs above mismatched ones using cosine-based softmax objectives. It is therefore natural to use cosine similarity as the geometry of the learned space. But this creates a basic mismatch: cosine provides a single fixed notion of similarity, while semantic similarity is inherently context dependent. For concreteness, we focus on image similarity in vision–language models, and study how semantic similarity should be defined between pairs of images. Figure 1 illustrates the fundamental limitation of cosine similarity in this setting. A query image may share different semantic attributes with different database images, while cosine implicitly fixes how these sources of variation contribute to similarity. The relevant notion, however, depends on context: we may care about the same dog breed, background, or outfit. Understanding how to specify such context-specific similarity is important both foundationally—the question of how dense representations encode semantics is the heart of (mechanistic) interpretability— and practically. For example, when retrieving chest X-rays similar to a query image, we may want similarity to reflect specific pathologies rather than unrelated patient characteristics or acquisition artifacts; see Figure 2. A fixed cosine geometry has no reason to privilege the semantic aspect relevant to the task. The main contribution of this paper is to show that the contrastive structure naturally defines a family of semantic geometries on the image representation space, each induced by a probability distribution over semantically relevant “anchors.” This correspondence leads 1arXiv:2610.06919v1 [cs.AI] 2 Oct 2026 Figure 1: Anchor divergences induce context-specific neighborhoods for the same query. Informally, the starting idea is to specify the semantics of interest using a set of text anchors. For example, in the chest X-ray setting, the anchors might consist of clinical descriptions of pathologies—the variation in the text includes only the aspects we care about. Relative to any such anchor set, the contrastive model uses the same softmax structure that appears during training to map each image to a distribution over the anchors, based on their image– text similarities. We can then compare two images through the distributions they induce over the anchors. In this way, the chosen anchors determine which semantic differences are emphasized by the comparison. In principle, we could define context-specific similarity directly using a finite anchor set. However, this ties the geometry to a particular collection of anchors: it may reflect idiosyn-crasies of that finite set, and the cost of representing the geometry grows with the number of anchors. The main technical insight is to move from identifying the geometry with a finite set of text anchors to identifying it with a probability distribution from which the anchors are drawn i.i.d. Using ideas from information geometry, we show that each such distribution corresponds to a Bregman divergence defined on the original image embeddings. This shifts the object specifying semantic geometry from a finite anchor set to an underlying semantic distribution, which can in turn be modeled efficiently. The development of the paper is: 1. First, we show that the KL divergence between softmax distributions over a finite set of semantic anchors has a natural limit as a Bregman divergence on image represen-tations. This reveals a direct role of information geometry in organizing semantic similarity in contrastive representations, and leads to anchor divergences —a principled method for specifying context-specific semantic geometries. 2. A key consequence of the Anchor Divergence construction is that the anchor distribu-tion determines the induced Bregman geometry. Drawing on classical connections between exponential families and Bregman geometry [Efr78; Ama82; WJ08; AC10 ],we use the observed anchors to fit a parametric model of the underlying population anchor distribution, whose fitted distribution induces an explicit Bregman divergence. This has two practical benefits: once the model is fit, the cost of representing and 2evaluating the geometry need not scale with the number of observed anchors, and the parametric structure can provide useful approximations when only a limited number of anchors are available. 3. As a further consequence of modeling the anchor distribution, we show how broad semantic structure can be adapted to a specific target using an empirical-Bayes-type construction. The idea is to first learn a broad anchor distribution—and hence a broad semantic geometry—from a large collection of anchors that are loosely related to the target, e.g., all text about diseases, and then refine it using a small set of targeted anchors. Empirically, we find that this can reduce task-specific anchor requirements by a full order of magnitude. 4. Finally, experiments test the consequences of the framework. We show that the anchor distribution controls which semantic factors govern similarity; parametric models are useful when anchors are limited, while the non-parametric softmax improves as anchor coverage grows; and broad semantic structure can be adapted using few target anchors. Across these settings, the resulting geometries improve over task-agnostic cosine similarity and task-specific heuristic approaches. 

# 2 Anchor Divergence 

We begin with a finite set of text anchors Γ = {γ1, . . . , γN } chosen to describe the semantics of interest. For example, in a pathology-specific geometry, the anchors may be clinical descriptions of different findings. Given an image embedding λ, the contrastive softmax induces a distribution over these anchors, PΓ (γk | λ) ∝ exp (λ⊤γk/τ ), where τ > 0 is the temperature. A natural way to compare two image embeddings is then by the KL divergence between the distributions they induce:

However, we may worry that the procedure may be overly sensitive to the specific choice of anchors. # 3 Modeling Structured Semantic Geometries 

We have arrived at anchor divergences as Bregman divergences induced by an anchor 

distribution q that represents the semantics of interest. In practice, however, we observe only a finite set of anchors. We therefore turn to modeling the underlying distribution from these observations, and hence the induced semantic geometry. The simplest approach is to use the empirical measure on the anchor set. It is straightforward to verify that the anchor divergence associated with this empirical distribution is exactly the softmax anchor divergence defined earlier. As established by Theorem 3 this will converge to the target population geometry as we get more and more anchors. With limited anchors, however, the finite anchor set may poorly represent the underlying semantics. Since q determines the induced geometry, we can impose structure on the geometry by modeling q. The idea is to specify a parametric model qθ for the anchor distribution. For example, we may take qθ to be a multivariate Gaussian distribution with θ its mean and covariance. We then fit ˆθ to the specified anchors, say by maximum likelihood. The fitted distribution q ˆθ then induces the corresponding anchor divergence through Definition 4. Thus, different anchor-distribution assumptions induce different structured geometries in image embedding space. This reflects the usual tradeoff of parametric modeling. Simpler models impose stronger assumptions, which can help when anchors only partially specify the target semantics, but may miss the target geometry if those assumptions are too restrictive, even with many anchors. Moreover, once fit, the divergence is evaluated through the fitted distribution rather than all N observed anchors, so its evaluation cost need not scale with the anchor-set size; we examine this empirically in Appendix F.4. Bregman divergence in a projected anchor space. We also consider mildly generalizing from Bregman divergences on the contrastive embedding space to Bregman divergences on a subspace of the embedding space. This is motivated by evidence that semantic structure is often encoded in low-dimensional subspaces [Old +23; Bha +24; Eng +25; Par +25 ]. We learn a projection, optionally followed by normalization, onto a semantically relevant subspace from the anchor set and define the Anchor Divergence on the projected space. In Appendix B, we show that this corresponds to a latent-variable model of the anchor distribution and yields a procedure for estimating the projector. We refer to the resulting divergences as 

latent Gaussian and latent spherical anchor divergences. Operationally, both project onto the top-k eigenvectors of the empirical anchor covariance; the latent Gaussian divergence then uses Euclidean distance, while the latent spherical divergence uses cosine distance.

For example, in pathology-specific retrieval, we may have abundant general clinical text but only a few precise descriptions of the target pathology. The goal is to specialize broad semantic structure using a small number of pathology-specific anchors. Let Γbroad and Γtarget denote the broad and target anchor sets, respectively. Let {qθ : θ ∈ Θ}

be a parametric anchor model with prior p(θ | Ω). We adapt the anchor distribution in three steps: 1. fit qθ to Γbroad and use the fit to set the prior hyperparameters Ω;2. update this prior using Γtarget via a model-specific posterior or posterior-like update; 3. summarize the update by ˆθ , such as a posterior mean or MAP estimate. The adapted distribution q ˆθ induces the corresponding semantic geometry through its anchor divergence, giving the following definition. 

Definition 5. Given Γbroad and Γtarget , let q ˆθ denote the adapted anchor distribution obtained by using Γbroad to define prior information and updating it with Γtarget . The posterior anchor divergence is the anchor divergence induced by q ˆθ .All methods target the same object: a Bregman geometry induced by an anchor distribution. They differ only in how that distribution is estimated. Softmax anchor divergence uses the empirical distribution over target anchors; parametric anchor divergence fits a structured model to those anchors; posterior anchor divergence further regularizes this structured estimate using broad, related anchors as prior information. When |Γtarget | is small, broad anchors stabilize the geometry; as |Γtarget | grows, target anchors increasingly determine it. Model-specific updates are in Appendix D. 

# 5 Experiments 

Our experiments are designed to test the geometric and statistical predictions of the frame-work. We organize the experiments around the following questions: 1. Can Anchor Divergences effectively specialize geometry to different semantic factors? 2. With limited anchors, can parametric models usefully approximate the target geome-try? 3. Does posterior anchor modeling enable semantic adaptation using few target anchors?

## 5.2 Anchor distributions select the semantic coordinate 

We first isolate the effect of the anchor distribution with the embeddings fixed. Figure 1 gives a qualitative illustration. We test this systematically: if the anchor distribution determines the semantic geometry, then changing it should change which semantic coordinate is preserved by retrieval. 

Clinical coordinate control. For each CheXpert finding, we independently generate 10 sets of report-style clinical text anchors from a fixed LLM prompt; see Appendix E.6. We evaluate retrieval using the corresponding pathology label and average over anchor generations and the 10 released CheXzero checkpoints. Table 2 reports AUPRC differences relative to cosine similarity and ITI, with 95% intervals accounting for anchor-generation and bootstrapping. Anchor divergence improves over the reference geometries for most findings. The largest gains occur for pleural effusion, cardiomegaly, edema, and support devices. These results indicate that pathology-specific anchors can shift retrieval toward the intended clinical coordinate beyond generic image-space similarity. 

Object–style control. We next test whether varying the anchor distribution can interpolate between two semantic coordinates. ImageNet-R contains ImageNet object classes rendered in diverse styles, allowing retrieval to be evaluated by either object identity or style. Let

## 5.3 Parametric modeling is useful with limited anchors 

We next test whether parametric models of the anchor distribution provide useful approx-imations to the target geometry when only limited anchors are available. Softmax uses the empirical anchor distribution directly, whereas parametric models impose additional structure. We therefore expect parametric models to be most useful when anchors are limited, while the empirical construction should improve as anchor coverage grows. We first vary the number of ImageNet class anchors and evaluate retrieval on ImageNet. Figure 4 left shows the intuitive sample-efficiency pattern: structured geometries recover useful semantic neighborhoods at moderate anchor budgets, while softmax improves with anchor coverage and eventually becomes strongest. Similar trends hold across the other datasets; see Appendix F. We then consider the high-coverage regime using full dataset-matched anchor sets on ImageNet-R, CUB-200, and Sketchy. Figure 4 right shows that softmax anchor divergence is strongest in this setting, while parametric anchor divergences retain much of its gain over cosine similarity. Together with the ImageNet results, this illustrates the modeling tradeoff from Section 3: parametric structure can be useful with limited anchors, while the empirical anchor distribution becomes increasingly effective as anchor coverage grows. 

## 5.4 Posterior modeling adapts broad geometry with few target an-chors 

Finally, we test whether broad semantic structure can be adapted toward a target geometry using only a few task-specific anchors. This setting exposes a limitation of softmax anchor divergence: as a nonparametric estimator, it places mass only on observed target anchors, so with few anchors it can yield a poor approximation of the target geometry. Posterior anchor models instead use broad, semantically related anchors as prior information and specialize this structure using target anchors. We evaluate this on ImageNet, using WordNet anchors as broad semantic structure and ImageNet class names as target-specific anchors. Summary. The experiments support the main consequences of the framework. Changing the anchor distribution changes which semantic factors govern similarity; parametric models provide useful approximations when anchors are limited, while the empirical softmax geometry improves with anchor coverage; and posterior anchor models adapt broad semantic structure using few task-specific anchors. Together, these results support anchor divergences as a flexible framework for specifying, modeling, and adapting context-dependent semantic geometry in contrastive representation spaces. 

# 6 Discussion and Related Work 

Semantic geometry in contrastive representations. Prior work has shown that learned representations often encode semantic structure geometrically, from word-embedding analo-gies and latent-variable accounts of embeddings to linear structure in neural representations 

[Mik +13; Aro +16; SMG19; PCV24; Par +25 ]. In vision–language models, related work has studied how CLIP-like representations organize concepts through directions, parts, subspaces, and interpretable coordinates [Rad +21; Chu +25; Old +23; Bha +24; GES24; Mer +23 ]. Our question is complementary: given that a representation may encode many semantic factors simultaneously, which of them should determine similarity in a particular context? Anchor divergences answer this by representing the semantic context through an anchor distribution, which induces a corresponding Bregman geometry on the fixed representation space. 

Image–image comparison in CLIP-like models. CLIP-style image embeddings are com-monly compared using cosine similarity across applications [Abb +25; Zhe +25; Den +25; Tiu +22 ]. Several works have proposed alternatives to raw image–image cosine comparison, 9Figure 5: Posterior anchor modeling adapts broad geometries using few target anchors. Dotted curves use only target-specific ImageNet anchors, while solid curves use posterior anchor models adapted from WordNet with the same target anchors. Posterior models are strongest at small and moderate target-anchor budgets, with the advantage narrowing as coverage grows. 

including cache-based adaptation, cross-modal aggregation, text-based inversion, and meth-ods addressing image–text or intra-modal mismatch [Zha +22; UGA23; Yi +24; Mis +25; Bal +23; HW26 ]. These works motivate alternatives to the fixed cosine geometry, but do not generally ask how semantic context itself should determine the geometry on a fixed representation space. 

Relation to TIP-X. TIP-X uses text as a bridge for image–image comparison: each image is mapped to a softmax affinity profile over downstream class-text prompts, and images are compared by the KL divergence between these profiles [UGA23 ]. This is the same finite-anchor construction as our softmax anchor divergence when the anchors are the downstream class-text prompts. Our contribution begins from this finite construction and studies the geometry determined by an underlying distribution over anchors. We show that an anchor distribution induces a population Bregman geometry and use this perspective to model and adapt semantic geometry. 

Information geometry and metric learning. Our construction builds on classical connec-tions between exponential families, KL divergence, and Bregman geometry [Efr78; Ama82; Ban +05; WJ08; AC10 ]. It is also related to metric learning, which learns task-specific distances from supervised constraints on the representation space [Xin +02; WS09; SKP15; MA +17; MBL20; Rot +20 ]. Anchor divergences instead specify the semantic context through a distribution over semantic text anchors, without requiring labeled image pairs or repre-sentation fine-tuning. Because this anchor distribution determines the induced geometry, parametric modeling imposes corresponding geometric structure, while Bayesian updating provides a mechanism for semantic adaptation. 

Future directions. Although our experiments focus on image–image retrieval in vision– language models, the construction is not intrinsically tied to images. The key ingredient is that a representation in one space defines a softmax distribution over anchors in another space through query–key scores. The theoretical structure developed here follows from this softmax, or equivalently exponential-family, form rather than from any image-specific property. In this view, a distribution over keys induces a geometry on the query space. This suggests that anchor divergences extend naturally to other contrastive and multimodal settings with the same structure. More broadly, this points to the importance of under-standing the geometry of softmax-based models as a general problem in AI: recent work 10 argues that representations defining softmax distributions are naturally studied through information geometry, with implications for probing and steering [Par +26 ]. Progress on anchor divergences may therefore be of independent interest beyond retrieval, contributing to a broader theory of semantic geometry in softmax models.

The population anchor divergence is determined by the anchor distribution through its cumulant generating function. To obtain tractable estimators of this geometry, we consider structured parametric approximations to the anchor distribution. These models should be understood as pragmatic structured surrogates for the population anchor geometry, not as literal distributional models of normalized contrastive embeddings. The Gaussian and Gaussian-mixture models place mass off the unit sphere, while the latent low-rank models additionally idealize the semantically relevant variation as concentrated in a lower-dimensional subspace. We use these models because they yield tractable geometries with useful statistical tradeoffs in fidelity, robustness, and sample efficiency.

## D.6 Discussion 

These model-specific updates instantiate the same principle: posterior anchor modeling updates a parametric anchor model using broad anchors as prior semantic structure and precise anchors as task-specific evidence, which in turn updates the induced Bregman geometry in image space. The models differ in the semantic structure they can transfer: a single global covariance in the Gaussian case, a shared low-dimensional semantic subspace in the low-rank case, and multiple reweighted semantic modes in the mixture case. This is precisely why richer models such as the GMM can support forms of semantic transfer that would not arise from simple projection heuristics. 

# E Implementation details 

## E.1 Datasets 

We evaluate on ImageNet, ImageNet-R, CUB-200, Sketchy, and CheXpert. 27 ImageNet. We use the standard training split as the retrieval gallery /keys and the valida-tion split as queries. Relevance is defined by class agreement. ImageNet class-name anchors are formed from the class labels using the template “a photo of a {x}”. 

ImageNet-R. Queries and keys are both drawn from ImageNet-R, with each query removed from its own key set. Object relevance is defined by ImageNet class agreement, while style labels for the style-control experiments are parsed from the ImageNet-R filenames. Object-name anchors use the template “a photo of a {x}”, and style anchors use “a {s} rendition of an object”. For style retrieval we discard images that have “misc” style labels, since these are not well-defined styles and do not have corresponding anchors. 

CUB-200. We use the standard train /test split, with training images as the keys and test images as queries. Relevance is defined by bird-class agreement. CUB anchors are formed from the class names using the same class-name template. 

Sketchy. We use the Sketchy Extended Split 2 protocol for zero-shot sketch-based image retrieval, following Yelamarthi et al. [Yel +18 ]. The test set consists of 21 classes chosen to be absent from ImageNet-1K. We use sketches from these unseen classes as queries and photos from the same classes as the retrieval gallery; no training-class images are used. Relevance is defined by class agreement, and anchors are formed from the class names using the template “a photo of a {x}”. 

CheXpert. We evaluate multi-label retrieval on CheXpert using pathology labels as rele-vance targets. The official training split is used as keys and the validation split as queries. We discard the training images with uncertain labels. For each target pathology, we con-struct report-style text anchors describing that pathology. The exact LLM prompt is given in Appendix E.6. 

Synthetic collection for Figure 1. Figure 1 uses a synthetic image collection in which dog breed, background, and clothing are systematically varied. Images were generated using OpenAI’s gpt-image-2 model. The displayed neighbors are obtained directly by retrieval under cosine similarity and the corresponding anchor divergences.

Gaussian model. We fit the Gaussian anchor model by maximum likelihood on the anchor embeddings.

## F.3 Exploratory model-complexity diagnostic 

We include an exploratory diagnostic on how mixture complexity interacts with anchor-distribution structure. In the anchor-distribution view, parametric models are structured approximations to q: increasing flexibility can reduce approximation bias when the anchor distribution is heterogeneous, but can also introduce unnecessary complexity or estimation noise when simpler structure is sufficient. We compare ImageNet and CUB-200 as illustrative regimes. ImageNet class-name anchors span many coarse semantic groups, while CUB-200 anchors are narrower and concentrated around fine-grained bird categories. On ImageNet, increasing the number of GMM components generally improves retrieval, consistent with a heterogeneous class-name anchor distribution. ## F.4 Computational scaling with anchor-set size 

Parametric anchor models also provide a computational advantage when the number of observed anchors is large. Let Q denote the number of queries, G the number of gallery items, N the number of anchors, and d the embedding dimension.
