## Abstract 

Unsupervised skill discovery has emerged as a promising approach for leveraging reward-free datasets to pretrain general-purpose policies. However, current skill discovery methods either require access to expert data or exhibit limited generaliza-tion, failing to transfer effectively to previously unseen layouts. A key challenge is to learn representations that capture the temporal structure of the environment while remaining robust to variations across layouts. To address this issue, we present an objective for learning action-aware temporal representations that satisfy the functional equivariance property while preserving the local temporal structure of the environment. Building upon this embedding, we further propose unsupervised skill discovery using bisimulation , which learns transferable skills by conditioning the behavior of skills exclusively on the subset of state features that directly affect their execution. This enforces invariant behavior across different layouts, enabling skills to transfer effectively to other configurations. Finally, through comprehensive empirical evaluations, we show that skills learned in a given environment can be effectively applied to solve downstream tasks in various environment layouts, demonstrating strong out-of-distribution generalization. 1

## 1 Introduction 

Leveraging large unlabeled datasets has substantially contributed to the advancement of deep learning in recent years. Unsupervised and self-supervised techniques such as masked language modeling in natural language processing (Devlin et al., 2019) and contrastive losses in computer vision (Chen et al., 2020) have enabled deep neural networks to benefit from vast and low-cost unlabeled data. Numerous attempts have been made to apply the same strategy in the context of reinforcement learning (RL), where the goal is to pretrain the agent’s policy using only pre-collected offline datasets (Chebotar et al., 2021; Reed et al., 2022; Park et al., 2023a, 2024a; O. X.-E. Collaboration et al., 2024). Unsupervised skill discovery has been recognized as a promising approach for pretraining such policies. These methods aim to learn a versatile set of latent-conditioned policies, each demonstrating a distinct behavior, such that together they cover the state space. Prior work has proposed various objectives to train such skill policies, either via behavioral cloning (Pertsch et al., 2021; Ajay et al., 2021) or by diversifying their state visitation distribution (Eysenbach et al., 2019; Park et al., 2023b, 2024a). These skills can then be used to perform downstream tasks in a zero-shot manner, or harnessed as low-level policies within a hierarchical approach (Eysenbach et al., 2019; Sharma et al., 2020). Many applications of reinforcement learning in locomotion and robotic manipulation involve fre-quently occurring temporally-extended actions that appear during the accomplishment of a wide

For instance, in the AntMaze environment (Fu et al., 2020; Park et al., 2025), where a quadruped agent must navigate to different goals within a maze, the ability to move in the four cardinal directions constitutes a sufficient set of skills for performing any task, regardless of maze layout. Similarly, in the Kitchen environment (Gupta et al., 2019), which consists of several long-horizon manipulation tasks, a temporally-extended action such as placing the kettle from the cupboard onto the oven top should be performed independently of other environmental features, such as whether the microwave door is open or closed. In such structured environments, learning reusable skills is essential for generalizing to previously unseen configurations. Despite the importance of such reusable behaviors in structured domains, existing skill discovery methods are not explicitly designed to account for this structure. For instance, the Hilbert foundation policy (HILP) (Park et al., 2024a), which is a state-of-the-art distance-maximizing skill discovery method, learns skills that span the state space reasonably well. However, it struggles to generalize to out-of-distribution layouts (Sobal et al., 2025). To illustrate, suppose HILP learns to move a kettle only when the microwave door is closed. In a scenario where the microwave door is open, despite being irrelevant to the task, the behavior of the kettle-moving skill may change drastically, making it incapable of completing the task. In contrast to distance-maximizing skill discovery methods, behavioral cloning-based methods offer better out-of-distribution generalization (Pertsch et al., 2021). Nevertheless, they fall short when using suboptimal datasets, as they tend to replicate the exact action sequences that exist in the dataset. Motivated by this, we aim to extract skills that are transferable to out-of-distribution layouts, even when only a single training layout and low-quality datasets are available during training. Our method consists of two components. First, we introduce an objective for training an action-aware temporal representation (ATR) that aims to learn a structured state embedding with functional equivariance 

(Hansen-Estruch et al., 2022) property, while preserving local temporal distances. This allows us to enforce each skill to show monotonic behavior while retaining the benefits of temporal representations when learning from suboptimal data. To train such representations, we employ bisimulation metrics (Ferns and Precup, 2014), which have demonstrated well-established capabilities for improving generalization (Zhang et al., 2021; Agarwal et al., 2021). In particular, we use goal-conditioned bisimulation (Hansen-Estruch et al., 2022) to enforce this property for state-goal pairs that share similar underlying action sequences. Second, we build upon this representation to propose unsupervised skill discovery using bisimulation 

(USB), a modification of HILP in which the behavior of skills is conditioned only on the state features that are relevant to their execution, rather than on the full state. To achieve this, we again employ bisimulation metrics to learn a state representation in which states with similar transition dynamics are embedded close to one another. Conditioning each skill on this representation encourages the learned skills to exhibit consistent behavior across dynamically similar states, even when the corresponding action sequences are not present in the dataset for all such states. In this way, we encourage skills to disregard layout-specific features of the environment and to acquire generic behaviors that improve their transferability. These generic skills can then be equipped with a planning approach or composed by a high-level controller to accomplish downstream tasks across diverse layouts.

## 2 Related Work 

Offline goal-conditioned RL. Goal-conditioned objectives have been widely used in unsupervised RL to learn latent representations for states that preserve temporal distances (i.e., the minimum number of steps required to reach a goal from a given state under an optimal policy). Under certain assumptions, the optimal goal-conditioned value function is equivalent to the discounted temporal distance between pairs of states (Kaelbling, 1993). Inspired by this, prior work has explored learning universal value functions as a proxy for learning temporal representations (Ghosh et al., 2023; Park et al., 2023a). Another line of work has sought to learn such representations by incorporating contrastive losses (Eysenbach et al., 2022; Ma et al., 2023; Myers et al., 2024). Since optimal goal-conditioned value functions satisfy the triangle inequality (Liu et al., 2023; Pitis et al., 2020), several model architectures (Wang and Isola, 2022; Liu et al., 2023) and objective functions (Wang et al., 2023; Myers et al., 2025) have been proposed to leverage this inductive bias in order to learn temporal embeddings more efficiently. 

Unsupervised skill discovery. Skill discovery is a powerful approach in unsupervised RL aiming to pretrain a latent-conditioned policy that encodes a diverse set of behaviors. These skills are often trained by behavioral cloning (Pertsch et al., 2021; Ajay et al., 2021), maximizing mutual information between skills and their future state distributions (Gregor et al., 2017; Eysenbach et al., 2019; Sharma et al., 2020), or maximizing the distance between these distributions (Park et al., 2022, 2023b, 2024b,a). The closest to our work is HILP (Park et al., 2024a), which incorporates a temporal representation to train each skill by encouraging movement along a random unit vector in that representation. This is achieved by defining directional rewards for each skill, computed as the inner product between the temporal displacement caused by executing this skill and its corresponding target vector. 

Bisimulation. Many approaches have been proposed for clustering states in general Markov decision processes (MDPs) to make a form of state abstraction. Bisimulation (Larsen and Skou, 1991) is the strictest approach, which groups only states that are indistinguishable and behaviorally equivalent under the optimal value function. Bisimulation metrics (Ferns et al., 2011; Ferns and Precup, 2014) relax this assumption by defining a notion of behavioral similarity between states. Castro (2020) introduces on-policy bisimulation, which is a scalable and computationally efficient approach for approximating bisimulation metrics by using the similarity between on-policy behaviors of states, for deterministic MDPs. Zhang et al. (2021) propose a gradient-based method for learning a latent representation for high-dimensional state spaces in general MDPs with stochastic transitions. Finally, our action-aware temporal representation is based on the goal-conditioned extension of bisimulation metrics (Hansen-Estruch et al., 2022), where an embedding of state-goal pairs is learned to cluster such pairs with similar underlying reward or action sequences.

## 4 Learning Transferable Skills using Bisimulation 

4.1 Motivation 

Current unsupervised skill discovery methods that are based on temporal representations, such as HILP, tend to generalize poorly to unseen layouts (Sobal et al., 2025). In the absence of structural 4constraints, temporal embeddings are shaped by the specific layout of the environment and its corresponding temporal distances. Because the temporal relationships among states vary across layouts, skill discovery methods that rely solely on covering the temporal structure of a particular layout often fail to transfer to new environment configurations. To achieve better transferability, it is necessary to learn more primitive yet frequently occurring action sequences that remain invariant across different layouts (Figure 1). Inspired by this observation, we argue that a generalizable skill discovery method must satisfy two desiderata. First, each skill should be capable of executing one or more temporally extended actions, and collectively cover the entire state space. Second, the behavior of each skill should be conditioned only on those state features that are necessary for its execution. The first property ensures the versatility and effectiveness of the learned skills within the training layout, while the second enforces behavioral consistency across dynamically similar states, thereby enabling transfer even to previously unseen layouts. 

4.2 Action-Aware Temporal Representation 

To train a skill policy with the properties described in the previous section, we first learn an action-aware temporal representation that preserves local temporal relationships while respecting functional equivariance. By definition, a universal temporal representation must (1) maximally spread out states while (2) preserving their local temporal distance constraints (Wang et al., 2023). However, freely maximizing the distances between states can eventually lead the representation to overfit to the specific layout, as the representation is encouraged to spread states according to layout-dependent features. Therefore, rather than freely maximizing distances between states, we aim to spread states while simultaneously enforcing functional equivariance when learning temporal distances. Although this design sacrifices some properties of a temporal representation, as our representation is no longer a universal temporal representation, it provides the additional benefit of generalizing across different layouts. To enforce functional equivariance in the representation, we adopt goal-conditioned bisimulation (Hansen-Estruch et al., 2022). Goal-conditioned bisimulation extends the classical notion of bisim-ulation metrics to goal-conditioned settings by grouping together state-goal pairs that correspond to analogous tasks. Inspired by Agarwal et al. (2021), and in contrast to the typical practice in the bisimulation literature, we define our bisimilarity metric as the ℓ1 distance between actions rather than rewards. However, unlike Agarwal et al. (2021), who measure distances using optimal actions, we sample actions from our dataset for which we do not have optimality assumptions. Instead, the goal-conditioned formulation allows us to exploit such potentially suboptimal actions, since similarity is defined with respect to achieving the specified goals rather than relying on optimal behavior. (2022) and similar to Equation (2), we define an embedding ψ(s, g ) 3 such that the ℓ1 distance between embeddings of state-goal pairs reflects their bisimilarity. 4.3 Unsupervised Skill Discovery using Bisimulation 

Using ATRs instead of universal temporal representations reduces the variance in the action sequences encoded along each direction because of their functional equivariance property. As a result, when skills are trained with directional reward functions, they tend to exhibit more monotonic behavior. However, because each skill greedily maximizes its cumulative reward, it still may exploit the environment’s layout-specific structure by deviating from its target direction to obtain distant rewards. Such deviations conflict with the intended monotonic behavior of the skills. To prevent skills from memorizing the environment layout, we condition the skill policy only on the subset of state features that determine their dynamics, as these provide the information necessary for executing the skill. This constraint enforces skills to behave consistently across dynamically similar states and improves generalization to out-of-distribution states by reducing the influence of irrelevant state features. To this end, once again we employ bisimulation metrics to learn a representation β(s)

in which states with similar transition dynamics are embedded spatially close to each other (Figure 2c). To define a metric that captures this relationship between states, we leverage the emergent characteristic of ATRs discussed in Section 4.2. ATRs maintain functional equivariance as long as it does not disrupt the temporal dependencies among neighboring states. Therefore, any variation in how a specific action sequence affects the temporal embedding must arise from differences in the underlying state dynamics. Based on this property, we define our metric as the dissimilarity between the temporal displacement resulting from executing the same action from two distinct states. 5.2 Layout Generalization with Hierarchical RL 

In the first experiment, we evaluate each method in a hierarchical setup. To this end, we freeze the low-level skill policy and train a high-level controller πh(z|s) to solve a downstream task with sparse rewards using online interaction. The high-level policy is invoked every H steps, where H

denotes the horizon hyperparameter. During each H-step interval, the low-level policy takes actions conditioned on the current state and the skill selected by the high-level controller. For training the high-level policy, we employ Soft Actor-Critic (SAC) (Haarnoja et al., 2018). In this experiment, we compare our method against three baselines: OPAL (Ajay et al., 2021), a strong behavioral cloning-based skill discovery method; HILP, a state-of-the-art method for distance-maximizing skill discovery; and a flat policy. For the flat baseline, we train a high-level SAC agent to output primitive actions directly rather than skills, allowing us to evaluate whether the learned skills accelerate learning on downstream tasks. (See Appendix E for implementation details). Table 1 reports the overall results for each environment. USB+ATR either outperforms or performs competitively with the other baselines across most environments in this setup. Although OPAL per-forms well on the navigate and stitch datasets in antmaze , it completely fails on the low-quality 

explore dataset. This strong sensitivity to dataset quality is expected from a behavioral cloning-based method, which limits its applicability in many scenarios. In contrast, HILP exhibits weaker generalization when trained on near-optimal trajectories but benefits from suboptimal, high-coverage datasets. Consequently, its performance improves significantly when provided with more diverse state coverage. The average performance on unseen layouts demonstrates that USB+ATR generalizes effectively to novel layouts, outperforming existing state-of-the-art skill discovery methods. 

5.3 Layout Generalization with Test-Time Planning 

Next, we evaluate the transferability of our method without any policy optimization in the test environment. Specifically, each method is trained on a single training layout, and the resulting policy is then transferred to an unseen layout to perform a downstream task. To provide the policy with information about the target layout, we additionally make a set of sampled states from the target layout available at test time. We compare our approach against several baselines: GCIQL (Park et al., 2023a), QRL (Wang et al., 2023), CRL (Eysenbach et al., 2022), HIQL (Park et al., 2023a), and HILP. GCIQL is the goal-conditioned variant of Implicit Q-Learning (Kostrikov et al., 2022), a widely adopted method in offline RL. QRL learns a quasimetric value function by optimizing a dual objective. CRL leverages contrastive learning to estimate the value function and subsequently improve the policy. HIQL is a hierarchical approach that learns a two-level policy. Since evaluating downstream tasks in previously unseen layouts without further policy optimization requires test-time planning, we equip each method with a planning procedure. HILP uses the planning 8approach introduced in its original framework. For USB+ATR, we perform graph-search-based planning over the ϕ-embeddings of sampled states provided for each environment. For the remaining methods, we perform a similar graph-search-based planning procedure over the raw sampled states. Further details on graph construction and the planning approaches are provided in Appendix E. The results in Table 2 indicate that USB+ATR outperforms the other methods across most environ-ments. Although GCIQL and QRL perform well in the pointmaze environment, this is primarily because its 2D state space provides sufficient information for planning directly over the raw state space. In contrast, all baselines fail when evaluated in the more challenging antmaze environment. However, USB+ATR maintains consistently strong performance regardless of the quality of the training dataset.

## 6 Conclusion 

In this work, we proposed ATR, a structured temporal representation with the functional equivariance property. We also introduced USB, which trains skills that span ATR by conditioning skill behavior on only a subset of relevant state features. Over a set of experiments on an offline goal-conditioned benchmark, we demonstrated that our method offers strong generalization to previously unseen tasks and layouts. 

Limitations and future work. One limitation of our work is that we model ATR using a symmetric space. Extending the goal-conditioned representation by enforcing the triangle inequality with more general spaces, such as quasimetric architectures (Wang and Isola, 2022; Liu et al., 2023), is a promising direction for future research. Moreover, although our focus in this work is on deterministic environments, extending ATR to stochastic settings remains an open problem. Finally, although we only considered locomotion maze tasks in our evaluations, our method does not make any task-specific assumptions that inherently limit its applicability to this setting. Defining new benchmarks for layout generalization in other tasks, such as robotic manipulation, and evaluating existing methods on these benchmarks could be an interesting direction for future work. 9References

A.1 Visualization of ATR 

To illustrate how ATR enables directional skills to show monotonic behavior, we visualize a trained 32-dimensional ATR on {pointmaze, antmaze}-large-navigate datasets and compare it with its counterpart learned by HILP. For visualization, we apply principal component analysis (PCA) to project the 32-dimensional representations into two dimensions. This allows the sequence of states visited by each skill to be visualized as movements along an arbitrary vector. Figure 3 shows that the functional equivariance property of ATR allows it to accurately capture the layout of the environment, rather than overfitting to its global temporal structure. Since similar action sequences lie on approximately parallel directions in the latent space, ATR enables USB to learn monotonic and transferable skills. In contrast, HILP learns global temporal distances between all pairs of states, which disrupts the underlying structure of the environment. As a result, it learns skills whose behaviors change consistently over time rather than following recurring action sequences.

## C Additional Ablation Studies 

C.1 Ablation Study of Method Components 

In this section, we provide a deeper analysis of the results presented in Section 5.4. The results show that HILP+ATR performs worse than HILP+UTR on unseen layouts, indicating that ATR alone does not improve layout generalization. USB+UTR fails completely because the universal temporal representation does not satisfy functional equivariance. Consequently, even for two states with identical dynamics, the same action sequence may correspond to completely different directions in UTR, making it impossible to learn a β representation with the desired properties. USB+GCB exhibits similar behavior, as the equivariance proposed by Hansen-Estruch et al. (2022) is defined with respect to consistency in goal-conditioned rewards rather than action consistency and therefore does not provide the functional equivariance required by USB. In contrast, USB+Raw performs substantially better than USB+UTR and USB+GCB because the raw state representation in the OGBench maze environment partially satisfies the functional equivariance property. However, because it lacks the temporal information required for learning effective skills, it is unable to achieve performance competitive with USB+ATR. Finally, USB+ATR significantly outperforms the other variants. Taken together, these results provide strong empirical evidence that ATR and USB are synergistic: functional equivariance enables consistent β-conditioned skills, while temporal embedding makes these skills effective, and only their combination yields the observed improvements in out-of-distribution layout generalization.

## D Environment Details 

Our experiments are conducted on antmaze and pointmaze environments, along with datasets provided by OGBench. Each environment contains an agent (with 2 degrees of freedom for point and 8 degrees of freedom for ant) with the task of reaching a specified goal. We consider two environment scales: medium and large . For each environment, OGBench provides offline trajectory datasets with different qualities, which we use for pretraining skill discovery methods. The navigate 

dataset consists of trajectories collected from a noisy expert, the stitch dataset is composed of shorter trajectories that must be concatenated to reach distant goals, and the explore dataset contains extremely low-quality but high-coverage trajectories. To evaluate the generalization capabilities of the methods, we extended OGBench with a new feature that generates random layouts and their corresponding tasks for each environment. The generated layout with seed 0 matches the default layout and its corresponding tasks provided by OGBench, which we use to assess task-generalization performance (Appendix B.2). To evaluate the transferability of learned skills across different layouts, we use the generated layouts with seeds {1, 2, 3, 4, 5} for the test-time planning evaluation (Section 5.3) and {1, 2, 3} for hierarchical evaluation (Section 5.2). These layouts, along with their tasks, are shown in Figure 5.

Evaluations are conducted at 300K, 400K, and 500K steps for the medium layout, and at 600K, 700K, and 800K steps for the large layout. For each evaluation step, results are averaged over 50 rollouts, and we report the mean performance across these evaluation steps. For a fair evaluation, the high-level policy is updated every 8 environment steps in each method to keep the total number of gradient steps identical for all. 

Test-time planning. To evaluate the performance of the methods on unseen layouts using test-time planning, we generated a dataset for each layout and randomly sampled N = 50 ,000 states from each dataset, which were made available to the methods at test time. For USB+ATR, we then computed the corresponding embeddings of these states in the ϕ space. We constructed a planning graph using a simple K-nearest-neighbor approach: for each state, we identified its K nearest neighbors and connected them with edges weighted by their Euclidean distance. We tuned K over {4, 8, 16 } and found that K = 4 performed best. We then applied Dijkstra’s algorithm to compute the shortest-path distance from each sampled state to the goal. With this preprocessing, we can dynamically identify the shortest path to the goal during execution without running Dijkstra’s algorithm over the entire graph at every time step. We then select the L-th node along the resulting path as the subgoal, where 

L denotes the number of lookahead steps (e.g., L = 1 corresponds to the immediate next node), and perform the task toward this subgoal.
