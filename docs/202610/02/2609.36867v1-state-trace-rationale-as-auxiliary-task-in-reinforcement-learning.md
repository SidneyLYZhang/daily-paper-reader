## 摘要
我们提出 STRAT，一种辅助任务，训练深度强化学习（RL）智能体预测其自身状态的简短文本轨迹。受人类空间导航启发，该描述结合了地标、路线和全局勘察知识，跟踪智能体的位置、物品栏、目标和即时进展。环境规则在线生成该文本，无需人工标注。我们的方法在标准策略上添加一个辅助头。在 60 个稀疏奖励 XLand-MiniGrid 任务中，STRAT 解决了标准 RL 完全失败的复杂环境，同时压缩状态表示并防止秩崩溃。除了性能提升之外，预测的轨迹无需额外成本即可在每一步提供智能体信念的可读说明。

## Abstract
We propose STRAT, an auxiliary task that trains deep reinforcement learning (RL) agents to predict a short textual trace of their own state. Inspired by human spatial navigation, the description combines landmark, route, and survey knowledge, tracking the agent's position, inventory, goals, and immediate progress. Environment rules generate this text online without human labelling. Our method adds a single auxiliary head to a standard policy. Across 60 sparse-reward XLand-MiniGrid tasks, STRAT solves complex environments where standard RL fails outright, while compacting state representations and preventing rank collapse. Beyond performance gains, the predicted trace provides a readable account of agent beliefs at every step for no extra cost.

- **研究动机**：深度强化学习（RL）在稀疏或终端奖励下很难学习；奖励信号只告诉智能体最终是否成功，导致学到的表示可能只捕获“与回报相关”的少量信息，甚至表示退化。
- **背景问题**：辅助任务可以给表示提供额外学习信号，但“预测什么”并不清楚。早期工作预测像素、下一观测、未来潜在状态等；近期工作使用语言，但较少讨论语言描述应包含哪些内容、哪些部分最重要。
- **论文核心含义**：作者受人类空间导航中的三类知识启发——地标知识（landmark）、路线知识（route）、全局勘察知识（survey）——提出让 RL 智能体预测自身状态的简短文本轨迹，作为辅助任务，从而提升稀疏奖励下的样本效率、表示质量和可解释性。
- **论文提出方法**：STRAT（State-Trace Rationale as Auxiliary Task），在标准 PPO 策略上增加一个辅助头，在线预测由环境规则自动生成的模板化状态文本，无需人工标注。

## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：
  - 在标准 actor-critic 策略上增加一个辅助预测头。
  - 该头不控制动作，只用于训练，让共享表示学会预测智能体当前状态的结构化文本描述。
  - 文本描述结合地标、路线和勘察知识，跟踪位置、朝向、目标、子目标、上一步动作效果、物品栏等。
  - 标签由模拟器状态和任务规则在线生成，不输入给策略，避免信息泄漏。

- **文本轨迹设计**：
  - 固定长度序列：90 个 token，其中 24 个为变化的内容槽，其余为模板 token。
  - 五类行：
    - 位置行：如“I am at position ⟨pos_y⟩ ⟨pos_x⟩ facing ⟨direction⟩.”
    - 目标行：如“The goal is ⟨goal⟩.”
    - 子目标行：如“The subgoal is to ⟨subgoal⟩.”
    - 动作行：描述上一步动作及其效果，如“My previous action was a. It made me closer/farther/same.”
    - 物品栏行：如“Inventory holds ⟨colour⟩ ⟨object⟩.” 或 “Inventory is empty.”
  - 对应人类空间导航：
    - 目标/子目标 ≈ 地标知识。
    - 位置/动作/进度 ≈ 路线知识。
    - 物品栏/子目标等 ≈ 勘察知识。

- **标签生成方式**：
  - 位置和朝向：直接读取环境状态。
  - 目标：由采样规则集的目标编码渲染成 token。
  - 子目标：通过从目标反向链式推导预计算因果计划；在线检测规则是否触发，跟踪当前阶段。
  - 动作：执行的动作。
  - 进度：由 critic 的价值估计差分 \(\Delta V_t = V(s_{t+1}) - V(s_t)\) 的符号，并用阈值 \(\tau\) 判断“closer / farther / same”。
  - 物品栏：动作后读取智能体 pocket。

- **损失函数**：
  - 对监督位置集合 \(P\) 计算 token 级交叉熵：
    \[
    CE_{t,\ell} = -\log p_\theta(y_{t,\ell}\mid h_t)
    \]
  - 轨迹损失：
    \[
    L_{ST}(\theta)=\mathbb{E}_t\left[\frac{1}{L}\sum_{\ell\in P} CE_{t,\ell}\right]
    \]
  - 总目标：
    \[
    L = L_{PG} + c_v L_V - c_e H + \lambda_{st} L_{ST}
    \]
  - 其中 \(L_{PG}\) 为 PPO 裁剪策略损失，\(L_V\) 为价值回归损失，\(H\) 为熵奖励，\(\lambda_{st}\) 控制辅助损失权重。

- **训练架构**：
  - 使用 Transformer-XL actor-critic 作为主模型，记忆缓存覆盖整条 episode。
  - 观测为符号化 5×5 自我中心窗口，包含 tile、颜色和朝向。
  - 策略头、价值头和状态轨迹头共享 Transformer 主干特征。
  - 状态轨迹头对每个监督位置加入位置嵌入，再通过共享线性层映射到 token 词表。
  - 所有条件均用 PPO + GAE 训练，唯一差异是是否加入辅助损失项。

## 3. 实验设计：场景、Benchmark 与对比方法

- **环境**：
  - 使用 XLand-MiniGrid，JAX 原生、程序化生成的网格世界任务。
  - 具体环境为 `XLand-MiniGrid-R1-9x9`，9×9 网格。
  - 观测：5×5 自我中心符号窗口 `(tile, colour)` 加朝向。
  - 动作空间：6 个离散动作，如前进、左转、右转、拾取、放下、切换。
  - Episode 长度：243 步。
  - 奖励稀疏：成功时终端奖励为 \(1 - 0.9^{t/T_{\max}}\)，否则为 0。

- **Benchmark 与任务**：
  - 三个 benchmark：`small-1m`、`medium-1m`、`high-1m`。
  - 每个 benchmark 选 20 个环境，共 60 个任务。
  - 任务按规则集结构分为四类难度：
    - **Placed（Easy）**：目标 tile 已存在，只需到达或持有。
    - **Go-hold（Medium）**：目标 tile 需制作，且需按顺序执行步行/拾取等步骤。
    - **Beside（Hard）**：目标为“将 A 放在 B 旁边”，目标 tile 需制作。
    - **Align（Hardest）**：需要先对齐两个物体以产生目标 tile，再完成目标。
  - 每个 benchmark 的每个 family 采样 5 个任务，因此每 family 15 个、总共 60 个。

- **对比方法**：
  - 主要对比：STRAT vs 相同 PPO baseline。
  - 消融：
    - `STRAT-gs`：仅目标与子目标。
    - `STRAT-pa`：仅位置与动作描述。
    - `STRAT-wa`：去掉动作描述。
    - 去掉目标/子目标、去掉位置/动作等变体。
    - 动作进度标签替换：价值 bootstrap vs BFS vs 欧氏距离。
    - 记忆骨干替换：Transformer-XL vs GRU。
    - 超参数扫描：辅助损失权重 \(\lambda_{st}\)、进度阈值 \(\tau\)。
  - 表示分析：
    - 冻结训练过程中 40 个均匀间隔 checkpoint。
    - 每个配置 10 个随机种子。
    - 使用 MDL 探针衡量表示中压缩了哪些变量，如 target visibility、subgoal phase、action、direction、position、inventory 等。
    - 使用 effective rank、srank、participation ratio、dormant units 衡量表示容量与是否秩崩溃。
