## 摘要
元强化学习通过从相关任务中提取共享结构实现快速适应，但现有的端到端方法通常将任务推断与具体形态控制耦合在一起。这种耦合可能模糊非参数任务语义、降低样本效率并限制跨智能体重用。我们提出了一种元知识重用框架，该框架在动力学简化智能体上学习任务级知识，并将其迁移到异构智能体。该框架使用贝叶斯非参数先验来组织潜在任务模式，并使用高层策略生成任务级幅度指导。为了桥接可复用的任务知识与不同形态，我们引入了一个语义-幅度接口和一个轻量级时间适配器，将冻结的元知识转换为时间对齐的子目标，供具体形态的低层控制器使用。在多个运动智能体上的实验表明，与近期最先进的基线相比，我们的框架将最终步长跟踪误差降低了94.75%–99.79%，并且仅使用约23.8%的交互数据即可达到相当的部署性能。

## Abstract
Meta-reinforcement learning enables fast adaptation by extracting shared structure from related tasks, but existing end-to-end methods often couple task inference with embodiment-specific control. This coupling can obscure non-parametric task semantics, reduce sample efficiency, and limit cross-agent reuse. We propose a meta-knowledge reutilization framework that learns task-level knowledge on a dynamics-simplified agent and transfers it to heterogeneous agents. The framework uses a Bayesian non-parametric prior to organize latent task modes and a high-level policy to generate task-level magnitude guidance. To bridge reusable task knowledge with different embodiments, we introduce a semantic-magnitude interface and a lightweight temporal adaptor, which convert frozen meta-knowledge into temporally aligned subgoals for embodiment-specific low-level controllers. Experiments on multiple locomotion agents show that our framework reduces final-step tracking error by 94.75% -- 99.79% compared with recent state-of-the-art baselines and achieves comparable deployment performance with about 23.8% of their interaction data.

- **研究动机**：现有元强化学习（Meta-RL）方法通常采用端到端框架，将任务推理（task inference）与具体智能体形态（embodiment）的控制耦合在一起。这种耦合导致三个关键问题：

  - **Q3.** 学到的元知识往往被具体形态的动态特性污染，难以跨异构智能体重用。
- **整体含义**：本文旨在设计一种框架，将任务级元知识的学习与具体形态的执行解耦，使得同一套元知识能够在不同形态的机器人（如 Hopper、Walker、Half-Cheetah、Ant）之间高效复用，从而大幅提升样本效率和跨智能体迁移能力。

## 2. 方法论

### 2.1 核心思想
- 提出 **ReMAP**（Reusable Meta-knowledge for Adaptive Policy Transfer）框架。
- 在**动力学简化智能体**（dynamics-simplified agent，例如质点-阻尼模型）上学习任务推理模块和高层策略，获得可复用的元知识。
- 通过**语义-幅度对齐接口（SMAI）** 和**轻量级步长预测器**，将冻结的元知识转化为时序对齐的子目标，供不同形态的低层控制器执行。
- 低层策略通过**幅度引导的课程学习**独立训练，只关注形态特定的运动生成，不涉及任务推理。

### 2.2 关键技术细节

#### 元知识获取（Meta-knowledge Acquisition）
- **简化智能体建模**：采用质量-阻尼模型（式15），保留任务相关变量（位置、速度），去除高维驱动、接触动态等形态复杂性。
- **任务推理模块**：变分自编码器（VAE）结构，编码器为GRU，将上下文窗口 \(c_t = \{(s_{t-\tau}, r_{t-\tau}, s_{t-\tau+1})\}_{\tau=0}^{H-1}\)（\(H=48\)）映射到潜在变量 \(z_t\)。
- **潜在先验**：使用**狄利克雷过程混合模型（DPMM）**作为非参数贝叶斯先验，自动推断任务模式数量。采用截断变分推断和Memoized VB更新，包含birth和merge移动动态调整组件。
- **解码器**：联合预测下一状态、奖励和任务置信度（\(L_{rec} = \lambda_s L_{state} + \lambda_r L_{reward} + \lambda_y L_{task}\)）。
- **总体推理目标**：\(L_I = L_{rec} + \beta_{KL} \sum_k \rho_{tk} D_{KL}(q_\phi(z_t|c_t) \| p_{\theta_k}(z_t))\)，其中\(\rho_{tk}\)是责任权重。
- **高层策略**：基于状态和停止梯度的潜在变量 \(\bar{z}_t = sg(z_t)\)，输出抽象动作 \(a_t^{\text{high}}\)，通过残差更新（式37-38）生成幅度信号。训练采用SAC和clipped double-Q。

#### 解耦低层学习（Disentangled Low-level Learning）
- 每个目标智能体独立训练低层策略 \(\pi_{\text{low}}^{(i)}(a_t^{(i)} | s_t^{(i)}, g_t)\)，其中 \(g_t = m_t b_t\)（SMAI信号）。
- 通过课程学习逐步增加：
  - 目标幅度（速度任务最初减半）
  - 任务切换频率（\(\Delta(e) = \lfloor H(e)/C(e) \rfloor\)）
  - 轨迹长度（\(H(e)\)逐步增大）
  - 初始状态多样性（\(s_0 \sim p_{\text{rand}}\)）
- 低层奖励：\(r_{\text{low}}^{(i)} = -\|\Phi_{u_t}^{(i)}(s_t^{(i)}) - m_t\|_2^2 - \lambda_a \|a_t^{(i)}\|_2^2\)，仅鼓励跟踪幅度，不涉及任务语义。

#### 元知识重用（Meta-knowledge Reutilization）
- 冻结推理模块和高层策略，通过以下步骤生成子目标：
  - 将目标智能体原始状态映射到抽象空间：\(\bar{s}_t^{(i)} = R^{(i)}(s_t^{(i)})\)。
  - 构造上下文 \(\bar{c}_t^{(i)}\)，推理得到 \(z_t^{(i)}\)。
  - 高层策略生成幅度 \(m_t^{(i)}\)，由任务预测 \(\hat{y}_t^{(i)}\) 选择语义通道。
  - 形成SMAI子目标 \(g_t^{(i)}\)。
- **步长预测器** \(P_\zeta^{(i)}\)：估计当前子目标应保持执行的步数 \(k_t^{(i)}\)，通过最小化执行后状态与幅度目标的误差来在线更新（式40）。这补偿了不同形态的响应延迟。
- 低层策略在 \(k_t^{(i)}\) 步内固定执行同一子目标。

## 6. 主要结论与发现

1. **元知识可复用**：在简化智能体上训练的DPMM任务推理模块可冻结并直接用于指导异构智能体，潜在空间保持清晰的语义聚类（图8）。
2. **跟踪精度显著提升**：在最终步，ReMAP将目标跟踪MSE降低至0.005，相比最佳基线MELTS（2.79）减少99.81%；速度跟踪MSE为0.157，优于MELTS（0.301）和CEMRL（0.190）。
3. **样本效率极高**：仅需约38M环境步（四个智能体总和）达到部署性能，是MELTS的23.8%，远低于其他基线（RL² 180M, PEARL 444M, CEMRL 241M）。
4. **解耦有效**：任务推理与低层控制分离，避免了端到端Meta-RL的探索困境，低层策略通过课程学习快速获得运动能力。
5. **步长预测器提升了时序对齐**：轻量级在线适应使子目标在不同形态的执行时间上得到协调。

## 7. 优点

- **创新设计**：首次系统地将元知识学习与具体形态执行解耦，提出SMAI接口实现任务语义与幅度的统一表示，以及步长预测器实现时间对齐。
