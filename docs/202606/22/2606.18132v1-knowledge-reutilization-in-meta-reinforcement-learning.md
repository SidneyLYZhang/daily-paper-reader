## 摘要
元强化学习通过从相关任务中提取共享结构实现快速适应，但现有的端到端方法通常将任务推理与具体实施例的控制耦合在一起。这种耦合可能掩盖非参数任务语义，降低样本效率，并限制跨智能体的重用。我们提出了一种元知识重用框架，该框架在一个动力学简化的智能体上学习任务级知识，并将其迁移到异构智能体。该框架使用贝叶斯非参数先验来组织潜在任务模式，并使用高层策略生成任务级幅度指导。为了桥接可重用的任务知识与不同的实施例，我们引入了语义-幅度接口和一个轻量级时间适配器，将冻结的元知识转换为针对特定实施例的低层控制器的时间对齐子目标。在多个运动智能体上的实验表明，与最近的最先进基线相比，我们的框架将最终步跟踪误差降低了94.75%–99.79%，并且在使用约23.8%的交互数据的情况下达到了可比的部署性能。

## Abstract
Meta-reinforcement learning enables fast adaptation by extracting shared structure from related tasks, but existing end-to-end methods often couple task inference with embodiment-specific control. This coupling can obscure non-parametric task semantics, reduce sample efficiency, and limit cross-agent reuse. We propose a meta-knowledge reutilization framework that learns task-level knowledge on a dynamics-simplified agent and transfers it to heterogeneous agents. The framework uses a Bayesian non-parametric prior to organize latent task modes and a high-level policy to generate task-level magnitude guidance. To bridge reusable task knowledge with different embodiments, we introduce a semantic-magnitude interface and a lightweight temporal adaptor, which convert frozen meta-knowledge into temporally aligned subgoals for embodiment-specific low-level controllers. Experiments on multiple locomotion agents show that our framework reduces final-step tracking error by 94.75% -- 99.79% compared with recent state-of-the-art baselines and achieves comparable deployment performance with about 23.8% of their interaction data.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：现有元强化学习（Meta-RL）方法（如 PEARL、RL²）通常采用端到端框架，将任务推理与具体智能体的动力学控制耦合在一起。这种耦合导致三个关键问题：  
  - (a) 使用固定高斯先验无法表示非参数的、多模态的任务结构；  
  - (b) 任务推理与低层控制相互依赖，造成“鸡生蛋”困境——需要有意义探索才能进行任务推断，而探索又依赖于已推断的任务，导致样本效率低下；  
  - (c) 学到的元知识会纠缠智能体特定的动力学特征，难以跨异构智能体重用。  
- **核心问题**：如何学习可迁移的任务级元知识，使其既能捕获非参数任务语义，又能解耦任务推理与具身控制，并在不同形态的智能体间有效重用？  
- **整体含义**：提出 ReMAP 框架，通过先在一个动力学简化的智能体上学习可重用的元知识（贝叶斯非参数先验 + 高层策略），再通过语义-幅度接口（SMAI）和轻量时间适配器将冻结的元知识迁移到异构智能体，实现高效跨智能体知识迁移。

## 2. 方法论：核心思想与关键技术细节

- **核心思想**：将任务级元知识的学习与低层控制解耦，在简化的抽象智能体上学习可泛化的任务推断和幅度生成能力，然后将其冻结并作为子目标指导不同形态低层策略的执行。
- **框架组成**：
  1. **元知识获取（Meta-knowledge Acquisition）**：
     - 动力学简化智能体：用质点-阻尼模型（式 15）等抽象，保留位置、速度等任务相关变量，去除高维控制复杂性。
     - 任务推断模块：变分自编码器（VAE），编码器将最近 H=48 步上下文映射为潜在变量 \(z_t\)，解码器同时预测下一状态、奖励和任务类别。
     - 贝叶斯非参数先验：采用 Dirichlet 过程混合模型（DPMM），通过 stick-breaking 构造自动推断任务模式数量，使用 Memoized Variational Bayes（MemoVB）进行在线更新，包含 birth 和 merge 操作调整组件数。
     - 损失函数：包含重构损失（状态、奖励、任务分类）和软加权 KL 正则化项（式 20）。

  2. **解耦的低层策略学习（Disentangled Low-level Learning）**：

     - 语义-幅度对齐接口（SMAI）：将任务语义通道（如速度跟踪、目标追逐）与标量幅度结合为向量子目标 \(g_t\)（式 25）。
     - 课程学习：逐步增加目标幅度、切换频率、轨迹长度和初始状态多样性，使低层策略掌握稳定运动和子目标跟随能力。
  3. **元知识重用（Meta-knowledge Reutilization）**：
     - 部署时冻结任务推断模块和高层策略。
     - 观测映射：将目标智能体原始状态通过 \(R^{(i)}\) 映射为共享抽象状态。
     - 子目标生成：高层策略输出幅度 \(m_t^{(i)}\)，通过任务预测置信度选择语义通道，构造 SMAI 子目标。
     - 时间对齐：轻量级步幅预测器 \(P_\zeta^{(i)}\) 估计当前子目标需执行的低层步数，通过在线更新（式 40）适应不同智能体的动力学响应延迟。
