## 摘要
我们分析了在双边相对光滑性条件下Bregman ADMM用于非凸线性约束问题，该条件用相对于Bregman核的Hessian比较替代了标准Lipschitz梯度假设。该设置涵盖了矩阵和张量模型中出现的多项式目标函数，这些函数不一定存在全局Lipschitz梯度常数。我们证明，在不变的开状态空间域上，Bregman ADMM的一次迭代定义了一个光滑的原对偶不动点映射，其严格鞍点KKT点是不稳定不动点；因此，从随机初始化开始，迭代以概率零收敛到严格鞍点。结合现有的一阶收敛结果，这得到了极限KKT点几乎必然的二阶平稳性。我们将分析扩展到分布式优化的多块星型共识形式。技术新颖之处在于，在两块谱论证中引入了具有Bregman特定对称化和缩放步骤的行列式约减，以及利用共识情况下的星图结构的零空间消除。在分布式矩阵分解上的数值实验验证了理论，而对称张量分解示例展示了超出可分离共识设置的更广泛的Bregman近端分裂思想。

## Abstract
We analyze Bregman ADMM for nonconvex linearly constrained problems under two-sided relative smoothness, a condition that replaces the standard Lipschitz gradient assumption with a Hessian comparison relative to a Bregman kernel. This setting covers polynomial objectives arising in matrix and tensor models for which a global Lipschitz-gradient constant need not exist. We show that on an invariant open state-space domain, one iteration of Bregman ADMM defines a smooth primal--dual fixed-point map whose strict-saddle KKT points are unstable fixed points; consequently, from random initialization the iterates converge to a strict saddle with probability zero. Combined with existing first-order convergence results, this yields almost-sure second-order stationarity of limiting KKT points. We extend the analysis to a multi-block star consensus formulation for distributed optimization. The technical novelty lies in a determinant reduction with a Bregman-specific symmetrization and scaling step in the two block spectral argument, together with a null space cancellation exploiting the star graph structure in the consensus case. Numerical experiments on distributed matrix factorization illustrate the theory, and a symmetric tensor factorization example demonstrates the broader Bregman proximal splitting idea beyond the separable consensus setting.

### 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**: 标准ADMM（交替方向乘子法）及其变体在处理非凸优化问题时，通常只提供**一阶收敛**（收敛到稳定点）的保证。然而，对于许多实际问题（如低秩矩阵/张量恢复），一阶稳定点可能包含鞍点，导致算法性能不佳。现有二阶收敛保证的工作，如线性化ADMM，通常依赖于全局**Lipschitz梯度**假设，而许多实际目标函数（如多项式函数）不满足此条件。
- **研究背景**: 
    - 现有非凸ADMM的收敛分析主要集中在**一阶**平稳性上。
    - 部分方法（如Dynamical systems viewpoint）已证明，在Lipschitz光滑条件下，一些算法可以**避免严格鞍点**，从而几乎必然收敛到二阶稳定点。
    - **Bregman方法** 通过引入**相对光滑性**（Relative smoothness）概念，允许用目标函数的Hessian阵与一个凸的Bregman核进行比较，从而绕过全局Lipschitz梯度假设。这为处理多项式目标函数提供了理论基础。
- **整体意义**: 本文首次为**Bregman ADMM** (在双边相对光滑性条件下) 提供了**二阶KKT保证**，即证明在非凸、非Lipschitz问题中，算法几乎必然不会收敛到严格鞍点。这填补了Bregman ADMM在二阶收敛理论上的空白，对于处理矩阵/张量分解等实际应用具有重要理论价值。

---

### 2. 方法论：核心思想与关键技术细节

- **核心思想**: 
    1. **构造光滑固定点映射**: 将Bregman ADMM的一次迭代视为一个从原始-对偶状态空间到自身的**光滑映射 `g`**。
    2. **证明严格鞍点是不稳定固定点**: 在严格鞍点KKT点处，该映射的雅可比矩阵 `Dg` 具有模大于1的特征值，使得这些点是映射的**不稳定固定点**。
    3. **应用稳定流形定理**: 根据Lee等人的理论 [31]，从一个光滑局部微分同胚的非稳定固定点出发的迭代几乎必然逃离该点。因此，从随机初始化出发，迭代收敛到严格鞍点的概率为零。
    4. **结合一阶结果**: 结合现有（如 [9, 22]）在Kurdyka-Łojasiewicz (KŁ) 条件下的**一阶收敛**结果，可以得出结论：极限KKT点**几乎必然是二阶稳定点**。

- **关键技术细节**:
    1. **双边相对光滑性**: 本文使用**双边**的Hessian比较条件 (`Lf ∇²h(x) ± ∇²f(x) ⪰ 0`)，这保证了Bregman近端子问题的强凸性。
    2. **行列式简化与对称化 (两块情况)**: 在计算雅可比矩阵 `Dg = I - Φ` 后，为证明 `Φ` 有负实特征值，需要证明存在 `μ > 0` 使得 `det(Φ + μI) = 0`。经过Schur补消去对偶变量块后，得到一个非对称的2x2块矩阵。**关键技术**是通过一个对角相似变换 `D = diag(I_n, α(μ)I_m)` 将其**对称化**为 `J(μ)`，使得特征值分析可行。
    3. **零空间消除 (共识情况)**: 在星型共识网络中，一个可行的严格鞍点方向具有所有节点的 `x` 变量相等的特性（即 `dx₁ = dx₂ = ... = dx_J`）。这个方向位于**星型拉普拉斯矩阵的零空间**中。因此，在分析中，共识惩罚项和Schur补修正项对这个方向的作用**完全抵消**，仅留下黑色的Hessian项，从而成功孤立出负曲率方向。
    4. **算法流程**:
        - **Algorithm 2 (Bregman ADMM)**: 适用于两块可分离问题。迭代过程为：
            1. `x` 更新：`x_k = argmin_x L(x, y_{k-1}, λ_{k-1}) + (1/η) D_{h1}(x, x_{k-1})`
            2. `y` 更新：`y_k = argmin_y L(x_k, y, λ_{k-1}) + (1/η) D_{h2}(y, y_{k-1})`
            3. `λ` 更新：`λ_k = λ_{k-1} + ρ(A x_k + B y_k - b)`
        - **Algorithm 3 (Consensus Bregman ADMM)**: 适用于分布式共识问题。为每个agent的局部变量 `(x_j, y_j)` 并行或顺序执行上述Bregman近端更新，然后更新与中心节点1相关的乘子 `λ_j` 以强制实现 `x_j = x_1`。

### 6. 论文的主要结论与发现

- **核心理论结论**: 在**双边相对光滑性**条件下，Bregman ADMM（Algorithm 2）和共识Bregman ADMM（Algorithm 3）的不动点映射是光滑的。严格鞍点是该映射的**不稳定固定点**。因此，从**随机初始化**出发，算法以**概率零**收敛到严格鞍点。
