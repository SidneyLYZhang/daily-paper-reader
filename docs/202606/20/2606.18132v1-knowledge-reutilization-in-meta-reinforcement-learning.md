## 摘要
元强化学习通过从相关任务中提取共享结构实现快速适应，但现有的端到端方法通常将任务推断与具体具身控制耦合在一起。这种耦合会模糊非参数任务语义，降低样本效率，并限制跨智能体的重用。我们提出了一个元知识重用框架，该框架在动力学简化的智能体上学习任务级知识，并将其迁移到异构智能体。该框架使用贝叶斯非参数先验来组织潜在任务模式，并使用高层策略生成任务级量级引导。为了桥接可重用的任务知识与不同的具身，我们引入了一个语义-量级接口和一个轻量级时间适配器，将冻结的元知识转换为时间对齐的子目标，供具体具身的底层控制器使用。在多个运动智能体上的实验表明，与最近的最先进基线相比，我们的框架将最终步跟踪误差降低了94.75%至99.79%，并且仅使用其约23.8%的交互数据即可达到相当的部署性能。

## Abstract
Meta-reinforcement learning enables fast adaptation by extracting shared structure from related tasks, but existing end-to-end methods often couple task inference with embodiment-specific control. This coupling can obscure non-parametric task semantics, reduce sample efficiency, and limit cross-agent reuse. We propose a meta-knowledge reutilization framework that learns task-level knowledge on a dynamics-simplified agent and transfers it to heterogeneous agents. The framework uses a Bayesian non-parametric prior to organize latent task modes and a high-level policy to generate task-level magnitude guidance. To bridge reusable task knowledge with different embodiments, we introduce a semantic-magnitude interface and a lightweight temporal adaptor, which convert frozen meta-knowledge into temporally aligned subgoals for embodiment-specific low-level controllers. Experiments on multiple locomotion agents show that our framework reduces final-step tracking error by 94.75% -- 99.79% compared with recent state-of-the-art baselines and achieves comparable deployment performance with about 23.8% of their interaction data.

  - **Q1**：如何学习能捕捉非参数任务语义的表达性元知识，而不局限于固定高斯先验？
  - **Q2**：如何将任务推断与智能体具体动力学及低层控制解耦？
  - **Q3**：如何将学到的元知识有效重用于不同具身的智能体？

## 2. 方法论

- **核心思想**：在动力学简化的智能体上学习可重用的任务级元知识（任务推断模块+高层策略），然后通过语义-幅度对齐接口（SMAI）和轻量级时间适配器，将冻结的元知识转化为时间对齐的子目标，供不同具身的低层控制器执行。
- **关键技术细节**：
  - **动力学简化智能体**：用一个质量-阻尼模型或质点模型作为抽象，只保留任务相关变量（位置、速度），去除高维关节力矩、接触动力学等复杂性。
  - **元知识获取分支**：
    - 变分自编码器（VAE）结构，编码器将历史上下文映射到潜在任务变量 \(z_t\)，解码器重建下一状态、奖励和任务置信度。
    - 潜在变量 \(z_t\) 被施加**Dirichlet 过程混合模型（DPMM）** 非参数先验，利用 stick-breaking 表示，自动推断任务模式的数量，无需预设。
    - 使用记忆化变分贝叶斯（MemoVB）在线更新 DPMM，包含 birth 和 merge 操作以动态调整组件数量。
    - 高层策略（基于 SAC）以 \((s_t, \bar{z}_t)\) 为输入，输出抽象动作 \(a^{\text{high}}_t\)，并通过残差更新生成幅度信号 \(m_t\)。
  - **解耦的低层学习分支**：
    - 为每个目标智能体独立训练低层策略（SAC），输入为状态和 SMAI 信号 \(g_t = m_t b_t\)，其中 \(b_t\) 是语义通道选择器。
    - 引入**课程学习调度**：逐步增加目标幅度、任务切换频率、轨迹长度、初始状态多样性，使智能体先稳定运动，再学会跟踪变化子目标。
  - **元知识重用阶段**：
    - 冻结任务推断模块和高层策略。
    - 目标智能体通过状态重映射 \(R^{(i)}\) 将自身状态投影到抽象空间，重建上下文。
    - 冻结模块生成潜在表示 \(z_t^{(i)}\) 和幅度 \(m_t^{(i)}\)，通过任务置信度选择语义通道，形成 SMAI 子目标。
    - **步幅预测器**：自适应估计当前子目标应被保持多少步（\(k_t^{(i)}\)），更新损失基于执行后的跟踪误差。
- **算法流程**：分为训练阶段（元知识获取 + 低层策略预热）和部署阶段（冻结元知识 + 步幅预测在线适应），具体步骤见论文附录。
