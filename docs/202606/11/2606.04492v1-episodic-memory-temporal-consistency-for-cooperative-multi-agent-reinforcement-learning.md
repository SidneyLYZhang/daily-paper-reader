## 摘要
合作多智能体强化学习常面临严重的奖励稀疏性和探索瓶颈。虽然情景记忆机制通过重用高回报轨迹缓解了这些问题，但由于不受约束的激励分配和语义表示坍塌，它们往往使智能体陷入局部最优。为此，我们提出情景记忆时间一致性（EMTC）框架，该框架鲁棒地构建并选择性利用历史经验。EMTC引入两个协同组件：（1）时间一致性语义嵌入器，该嵌入器将对比学习与时态条件状态重建相结合，防止表示坍塌并实现精确的记忆检索；（2）时间一致性门控机制，该机制根据时间一致性误差动态调节情景激励。该自适应门控过滤伪成功轨迹中的误导信号，有效缓解Q值过估计。我们提供了理论保证，建立了严格的误差界，将可观测的时间一致性误差直接与底层轨迹最优性和表示质量联系起来。在SMAC和GRF基准上的大量评估表明，EMTC持续优于最先进的基线方法。值得注意的是，与最强的情景基线相比，EMTC在超困难SMAC场景中实现了高达24%的绝对胜率提升，在GRF任务上平均提升28%。

## Abstract
Cooperative Multi-Agent Reinforcement Learning (MARL) frequently suffers from severe reward sparsity and exploration bottlenecks. While episodic memory mechanisms mitigate these issues by reusing high-return trajectories, they often trap agents in local optima due to unconstrained incentive distribution and semantic representation collapse. To address this, we propose Episodic Memory Temporal Consistency (EMTC), a framework that robustly constructs and selectively leverages historical experiences. EMTC introduces two synergistic components: (1) a Temporally Consistent Semantic Embedder that integrates contrastive learning with time-conditioned state reconstruction, preventing representation collapse and enabling precise memory retrieval; and (2) a Temporal Consistency Gating Mechanism that dynamically modulates episodic incentives based on temporal consistency error. This adaptive gate filters misleading signals from pseudo-successful trajectories, effectively mitigating Q-value overestimation. We provide theoretical guarantees, establishing a strict error bound that directly links the observable temporal consistency error to the underlying trajectory optimality and representation quality. Extensive evaluations on the SMAC and GRF benchmarks demonstrate that EMTC consistently outperforms state-of-the-art baselines. Notably, compared to the strongest episodic baseline, EMTC achieves absolute win-rate improvements of up to 24% in super-hard SMAC scenarios and an average improvement of 28% across GRF tasks.

## 1. 论文的核心问题与整体含义（研究动机和背景）

合作多智能体强化学习（MARL）在机器人、自动驾驶、通信网络等复杂领域取得显著成功，但面临两大基本挑战：**部分可观测性**和**大规模的联合动作空间**，导致严重的**奖励稀疏性**和**探索瓶颈**。传统价值分解方法（如QMIX、QPLEX）依赖密集的逐步奖励，在稀疏奖励环境中容易陷入次优策略。

情景记忆（Episodic Memory）机制通过缓存历史高回报轨迹来产生内在激励，已用于MARL（如EMC、EMU），能够打破初始探索死锁并加速收敛。然而，现有情景记忆方法存在一个**耦合的架构缺陷**：标准编码器在状态嵌入中过分强调时间序列特征，削弱了空间语义判别力，进而引发两个关键问题：
- **表示坍塌（Representation Collapse）**：有害状态与成功状态在潜在空间重叠，导致基于距离的记忆检索失效。
- **价值过估计（Value Overestimation）**：检索到伪成功记忆时，盲目注入未校准的奖励，人为抬高Q值，使智能体陷入局部最优。

本文旨在解决这两个耦合问题，提出了**情景记忆时间一致性（EMTC）框架**，通过鲁棒的语义记忆构建和时态约束的激励分配，提高记忆检索精度并避免过估计。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
EMTC是一个统一框架，包含两个协同组件：
1. **时间一致性语义嵌入器（TCSE）**：通过对比学习+时间条件重构，构建语义可区分的潜在空间，防止表示坍塌，实现精确记忆检索。
2. **时间一致性门控机制（TCGM）**：基于Bellman最优性准则，利用时间一致性误差动态缩放情景激励，过滤误导信号，缓解过估计。

### 关键技术细节

#### （1）时间一致性语义嵌入器（TCSE）
- 维护结构化情景缓冲区 `D_E`，每个条目包含原始状态 `s`、潜在嵌入 `x = f_phi(s)`、最高经验回报 `H`、成功指标 `xi`、后继索引 `idx_next`（保留轨迹因果顺序）。
- **双目标学习**：损失函数 `L_total = L_dCAE + lambda_cl * L_cl`。
  - `L_dCAE`：时间条件自编码器，重构状态和最高回报，损失包括回报预测误差和状态重建误差（带权重 `lambda_rcon`）。
  - `L_cl`：对比损失（InfoNCE），对同一时刻同一状态的不同增强视图作为正对，其他不同时间或不同状态的嵌入作为负样本，增强语义判别性。
- 通过t-SNE可视化验证：TCSE比标准dCAE生成更紧凑、分离的语义簇，消除检索模糊性。

#### （2）时间一致性门控机制（TCGM）
- **理论保证**（命题1）：可观测的时间一致性误差 `Delta_mem = |r + gamma H(s') - H(s)|` 被严格界限为 `Delta_mem <= Delta_opt + alpha`，其中 `alpha` 由表示误差和记忆陈旧性组成。TCSE将 `alpha` 保持很小，使得大 `Delta_mem` 严格意味着大 `Delta_opt`（真实最优性差距），从而保证门控安全。
- **工作流程**：
  1. 对每个转移 `(s,a,r,s')`，通过 `idx_next` 检索后继存储值 `H(s')`，计算 `Delta_mem`。
  2. 利用高斯调制函数计算一致性系数：`beta = exp(-Delta_mem^2 / (2 tau^2))`，`tau` 采用线性退火策略（初始1.2→终值0.6）。
  3. 生成门控情景奖励：`tilde_r_p = beta * r_p`，其中 `r_p` 为基线情景奖励（来自EMU）。
  4. 将 `tilde_r_p` 集成到TD损失：`L_beta = (r + tilde_r_p + gamma max Q_target - Q_tot)^2`。
- **梯度分析**（命题2）：策略和记忆趋于最优时，门控梯度恢复无偏的最优梯度，证明门控是安全的正则化器。
- **双阶段特性**：早期采用高tau鼓励探索，后期低tau严格过滤伪记忆，自然退化为无偏引导。

#### 整体训练流程
- 智能体与环境交互→线性退火tau→调用记忆构建子程序（算法2）更新`D_E`→评估时间一致性并存储beta→从回放缓冲区采样→计算门控损失更新策略网络→周期性地优化TCSE嵌入器（算法1）。
