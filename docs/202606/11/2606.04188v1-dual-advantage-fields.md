## 摘要
离线目标条件强化学习需要同时具备长程可达性估计和局部动作比较。对偶目标表示提供捕获全局目标可达性的值场，但它们并未直接指定在给定状态下应优先选择哪个动作。我们提出双重优势场（DAF），这是一种将双线性对偶值模型转化为局部优势信号的策略提取方法。在双线性对偶参数化下，目标嵌入是值场关于状态表示的梯度。DAF学习一个动作效应模型，该模型预测动作引起的折扣特征位移，并通过该位移与目标方向的对齐程度对动作进行评分。在可实现的情况下，该分数等于目标条件贝尔曼优势，从而提供了标准的局部策略改进保证。在OGBench的移动、操作和拼图任务中，DAF改善了聚合的RLiable指标，并在局部正确动作与直接朝向最终目标的移动不同的设置中表现出色。

## Abstract
Offline goal-conditioned reinforcement learning requires both long-horizon reachability estimates and local action comparisons. Dual goal representations provide value fields that capture global goal reachability, but they do not directly specify which action should be preferred at a given state. We propose Dual Advantage Fields, a policy-extraction method that turns a bilinear dual value model into a local advantage signal. Under bilinear dual parameterization, the goal embedding is the gradient of the value field with respect to the state representation. DAF learns an action-effect model that predicts the discounted feature displacement induced by an action and scores actions by the alignment between this displacement and the goal direction. In the realizable case, this score equals the goal-conditioned Bellman advantage, yielding a standard local policy-improvement guarantee. On OGBench locomotion, manipulation, and puzzle tasks, DAF improves aggregate RLiable metrics and performs strongly in settings where locally correct actions differ from direct movement toward the final goal.

- **核心问题**：离线目标条件强化学习（Offline Goal-Conditioned RL, GCRL）需要在固定数据集上学习能够到达任意目标的策略。这要求模型同时具备**全局长期可达性推理**（推断状态间的远距离连接）和**局部动作比较**（在当前状态选择最有利于接近目标的动作）。现有“双重目标表示”（Dual Goal Representations）通过双线性值函数（\(V(s,g)=\psi(s)^\top \phi(g)\)）提供了全局值场，但无法直接给出当前状态下不同动作的优劣，即缺乏局部优势信号。
- **整体含义**：论文指出，在双线性参数化下，目标嵌入\(\phi(g)\)实际上是值场相对于状态嵌入\(\psi(s)\)的梯度方向。因此，可以用动作引起的状态嵌入位移与该梯度方向的对齐程度来构造局部优势信号，从而将全局值场转化为局部动作比较工具。核心观点是：**全局值场应与局部优势场配对使用**。

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：利用双线性值函数的几何性质，将目标嵌入视为值场的“梯度方向”，通过学习一个动作效应模型（action-effect model）预测动作引起的折扣特征位移\(\gamma \psi(s') - \psi(s)\)，然后计算该位移与目标嵌入\(\phi(g)\)的内积作为优势分数，用于策略提取。
- **关键技术细节**：
  1. **双线性值函数**：\(V_\theta(s,g) = \psi_\theta(s)^\top \phi_\theta(g)\)，其中\(\psi_\theta: S \to \mathbb{R}^d\)，\(\phi_\theta: G \to \mathbb{R}^d\)。
  2. **梯度方向**：\(\nabla_\psi V_\theta(s,g) = \phi_\theta(g)\)（命题3.1）。
  3. **DAF优势分数**：对于转移\((s,a,s')\)和给定目标\(g\)，样本级优势为\(\hat{A}_\theta(s,a,s',g) = r(s,a,g) + \phi_\theta(g)^\top [\gamma \psi_\theta(s') - \psi_\theta(s)]\)（式10）。在可实现条件下，此分数等于真实贝尔曼优势。
  4. **动作效应模型**：\(u_\xi(s,a)\)通过辅助损失\(\mathcal{L}_{\text{ae}} = \mathbb{E}[ \| u_\xi(s,a) - \text{sg}(\gamma \psi_\theta(s') - \psi_\theta(s))\|_2^2 ]\)学习，近似预测特征位移。
  5. **策略提取**：使用优势加权回归（AWR），权重\(w_\theta(s,a,g) = \min\{\exp(\alpha \cdot z_\theta(s,a,g)), W_{\max}\}\)，其中\(z_\theta = u_\xi(s,a)^\top \phi_\theta(g)\)。通过最小化\(-\mathbb{E}_D [w_\theta \log \pi_\omega(a|s,c)]\)训练策略（\(\omega\)为策略参数）。
  6. **训练流程**：采用双Q网络和AFU耦合（Actor-Free Coupling）稳定训练，参考附录E。整体算法见Algorithm 1。

### 8. 不足与局限

- **依赖表示质量**：DAF的有效性高度依赖于双线性值场\(\psi\)、\(\phi\)的质量和动作效应模型\(u_\xi\)的准确性。在数据覆盖差或随机性强的区域，\(u_\xi\)可能不准确。
- **未测试图像输入**：实验仅限于状态空间（state-based），未在图像输入（视觉）场景下验证，限制了泛化性。
- **层次化扩展有限**：虽然可以结合层次化策略（如高、低层），但论文主要展示无层次版本，在长程任务中（如humanoidmaze large navigate）性能略逊于OTA。
- **超参数敏感**：\(\alpha\)（温度）需要在不同环境手动调整（表5），增加使用复杂度。
- **与某些基线对比差距不明显**：在部分maze navigate任务中，DAF与OTA、HIQL差距不大，甚至稍弱（如humanoidmaze large navigate OTA 0.83 vs DAF 0.66）。
- **缺乏在线适应实验**：虽标题提及“离线数据集到在线适应”，但实验仅为纯离线评估，未展示在线微调能力。
- **算力消耗较高**：总计407天GPU时间，复现成本较高。
