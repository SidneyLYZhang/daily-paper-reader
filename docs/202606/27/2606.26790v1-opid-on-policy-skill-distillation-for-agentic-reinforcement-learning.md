## 摘要
基于结果的强化学习为语言智能体提供了稳定的优化基础，但其稀疏的轨迹级奖励对于哪些中间决策应被强化或抑制几乎未提供指导。在策略自蒸馏提供了密集的令牌级监督，然而现有的技能条件变体通常依赖于外部技能记忆或检索到的特权上下文，这些维护成本高昂，并且可能与多轮交互中当前策略引发的状态分布不匹配。我们提出OPID（在策略技能蒸馏），这是一个直接从完成的在策略轨迹中提取技能监督的框架。OPID将轨迹后见知识表示为分层技能：片段级技能捕捉全局工作流程或避免失败的规则，而步骤级技能在关键时间步捕捉局部决策知识。一种关键优先的路由机制在识别出关键决策时使用步骤级技能，否则回退到片段级技能作为默认指导。选定的技能被注入交互历史中，允许旧策略在原始和技能增强的上下文下对相同采样响应重新评分。由此产生的对数概率偏移提供了令牌级自蒸馏优势，该优势与结果优势相结合用于策略优化。因此，OPID保留了强化学习作为主要训练目标，同时引入了密集的、分布匹配的后见监督。在ALFWorld、WebShop和基于搜索的问答上的实验表明，OPID在智能体性能、样本效率和鲁棒性方面普遍优于仅基于结果的强化学习和现有的技能蒸馏基线。我们的代码可在https://github.com/jinyangwu/OPID/tree/main获取。

## Abstract
Outcome-based reinforcement learning provides a stable optimization backbone for language agents, but its sparse trajectory-level rewards provide little guidance on which intermediate decisions should be reinforced or suppressed. On-policy self-distillation offers dense token-level supervision, yet existing skill-conditioned variants often rely on external skill memories or retrieved privileged context, which are costly to maintain and can be mismatched with the state distribution induced by the current policy in multi-turn interaction. We propose \textbf{OPID} (\textbf{O}n-\textbf{P}olicy Sk\textbf{i}ll \textbf{D}istillation), a framework that extracts skill supervision directly from completed on-policy trajectories. OPID represents trajectory hindsight as hierarchical skills: episode-level skills capture global workflows or failure-avoidance rules, while step-level skills capture local decision knowledge at critical timesteps. A critical-first routing mechanism uses step-level skills when critical decisions are identified and falls back to episode-level skills as default guidance otherwise. The selected skill is injected into the interaction history, allowing the old policy to re-score the same sampled response under both original and skill-augmented contexts. The resulting log-probability shift yields a token-level self-distillation advantage, which is combined with the outcome advantage for policy optimization. OPID thus preserves RL as the primary training objective while introducing dense, distribution-matched hindsight supervision. Experiments on ALFWorld, WebShop and Search-based QA demonstrate that OPID generally improves agent performance, sample efficiency, and robustness over outcome-only RL and existing skill-distillation baselines. Our code is available at https://github.com/jinyangwu/OPID/tree/main.

# 论文总结：OPID（On-Policy Skill Distillation for Agentic Reinforcement Learning）

## 1. 核心问题与研究动机

- **背景**：大语言模型（LLM）作为智能体在多步交互任务中需要进行顺序决策，而基于结果的强化学习（如 GRPO）提供了稳定的优化基础，但仅提供稀疏的轨迹级奖励，无法甄别哪些中间决策导致了成功或失败。这种粗粒度的信用分配在长程任务中尤为严重（例如，一次早期失误可能毁掉整个回合；重复无效动作累积等）。
- **现有方法的不足**：技能蒸馏（skill-conditioned distillation）可以提供密集的令牌级监督，但现有方法依赖外部技能库、检索或维护记忆，存在维护成本高、检索技能与当前策略状态分布不匹配的问题，尤其在多轮交互中状态漂移时更为突出。
- **本文目标**：提出一种无需外部技能库、无需推理时特权上下文的在策略技能蒸馏框架，从当前策略自身完成的轨迹中提取后见技能，并将其转化为密集的令牌级学习信号，以补充结果型RL的稀疏奖励。

## 2. 提出的方法：OPID

- **核心思想**：将完成的在策略轨迹视为分布匹配的后见监督源，从中提取分层技能（情节级与步骤级），并通过关键优先路由选择最合适的技能注入交互历史，然后让旧策略在原始上下文和技能增强上下文下对同一个采样响应重新评分，将产生的对数概率偏移作为令牌级自蒸馏优势，与结果优势结合用于策略优化。
- **关键技术细节**：
  - **问题形式化**：将智能体任务建模为部分可观测马尔可夫决策过程（POMDP），每个回合由轨迹 \(\tau\) 表示，结果奖励 \(R(\tau)\) 是稀疏的。采用 GRPO 风格，对每个提示采样 N 条轨迹形成组 \(G_q\)，计算组内标准化的结果优势 \(A^\text{ep}_\tau\)。
  - **在策略技能提取**：使用一个 LLM 分析器 \(A\) 将完成的轨迹映射为两个层次的技能：
    - 情节级技能 \(s^\text{ep}_\tau\)：总结全局工作流程（成功轨迹）或失败规避规则（失败轨迹），适用于大多数步骤。
    - 步骤级技能 \(s^\text{step}_{\tau,t}\)：在关键时间步捕捉局部决策知识，适用于决定性状态。
  - **关键优先路由**：对于轨迹 \(\tau\) 和时间步 \(t\)，若该步被分析器标记为关键步（\(t \in C_\tau\)），则使用步骤级技能；否则使用情节级技能。两者不叠加，避免冗余。
  - **技能条件化自蒸馏**：定义技能注入函数 \(H\) 将路由技能追加或前置到交互历史中，得到增强历史 \(\tilde{h}_{\tau,t}\)。使用旧策略 \(\pi_{\theta_{\text{old}}}\) 分别在原始历史和增强历史下对同一响应 \(y_{\tau,t}\) 的每个令牌计算对数概率，并得到技能优势：
    \[
    A^\text{skill}_{\tau,t,\ell} = (\log \pi_{\theta_{\text{old}}}(y_{\tau,t,\ell}|\tilde{h}_{\tau,t},y_{<\ell}) - \log \pi_{\theta_{\text{old}}}(y_{\tau,t,\ell}|h_{\tau,t},y_{<\ell})) \cdot m_{\tau,t,\ell}
    \]
    正值表示技能使令牌更可能，负值则不匹配。
  - **策略优化目标**：最终优势为结果优势与技能优势的加权和：
    \[
    A^\text{OPID}_{\tau,t,\ell} = A^\text{ep}_{\tau,t,\ell} + \lambda_{\text{skill}} A^\text{skill}_{\tau,t,\ell}
    \]
    使用带裁剪的 PPO 目标更新策略，并添加 KL 正则项。推理时不需要分析器、技能检索或特权上下文。

## 6. 主要结论与发现

- OPID 显著提升仅结果型 RL 的性能：在 Qwen2.5-3B 上，ALFWorld 平均成功率从 75.0% 提高到 84.3%（+9.3），Search-based QA 准确率从 36.4% 提高到 45.0%（+8.6），WebShop 成功率从 63.3% 提高到 74.2%（+10.9）。7B 和 1.7B 模型上也有类似增益。
- 与强混合基线相比，OPID 总体上匹配或超越，尤其是无需推理时技能即可取得最好或次好结果。
- 技能被内化到策略参数中：训练时使用技能，但推理时不依赖，仍能大幅优于那些在推理时没有技能提示的 Skill-GRPO 变体（例如在 ALFWorld Qwen2.5-3B 上，OPID 84.3 vs Skill-GRPO 60.2）。
- 样本效率更高：仅用 60% 训练数据即可接近 GRPO 用 100% 数据的性能；80% 数据即可超越 GRPO 全数据表现。
- 跨域泛化：在 ALFWorld Unseen 上，OPID 平均成功率 78.6%，比 GRPO 高 7.7 个百分点。
- 消融实验证明分层技能和关键优先路由均不可或缺。
- 训练动态显示 OPID 在保持更高成功率的同时，平均回合长度更短，表明策略更直接高效。

## 8. 不足与局限
