## 摘要
在线强化学习广泛用于将大语言模型（LLM）与奖励信号对齐，但在噪声或错误指定的奖励下训练可能不稳定。我们识别出一种称为方向不一致的失败模式：在一个批次内，一小部分高奖励的 rollout 会在表示空间中产生与批次多数强烈不一致的偏好方向，从而导致高方差和不稳定的更新。我们提出 GEOALIGN，一种用于迭代策略优化中 rollout 筛选的轻量级插件。GEOALIGN (i) 形成提示内的偏好对，(ii) 学习基于每个 rollout 隐藏状态的在线投影器以集中奖励排序的位移方向，以及 (iii) 通过角度偏离批次共识原型来检测方向不一致的 rollout，并用提示内稳定的替代方案进行修正。GEOALIGN 仅需前向传播，且开销可忽略。在基于学习奖励模型进行对话对齐和基于二元验证奖励进行数学推理的实验中，GEOALIGN 提升了最终性能并减少了训练震荡，优于 PF-PPO、PAR、PODS 和 Seed-GRPO。这些结果表明，潜在的方向共识可作为在线 LLM RL 的有效可靠性信号。

## Abstract
Online reinforcement learning is widely used to align large language models (LLMs) with reward signals, yet training can be unstable under noisy or misspecified rewards. We identify a failure mode we call directional inconsistency: within a batch, a small set of high-reward rollouts induces representation-space preference directions that sharply disagree with the batch majority, resulting in high-variance and destabilizing updates. We propose geoalign, a lightweight plug-in for rollout curation in iterative policy optimization. Geoalign (i) forms within-prompt preference pairs, (ii) learns an online projector on per-rollout hidden states to concentrate reward-ordered displacement directions, and (iii) detects directionally inconsistent rollouts via their angular deviation from a batch consensus prototype and rectifies them with within-prompt stable alternatives. Geoalign is forward-pass only and adds negligible overhead. Across dialogue alignment with a learned reward model and mathematical reasoning with binary verified rewards, Geoalign improves final performance and reduces training oscillation, outperforming PF-PPO, PAR, PODS, and Seed-GRPO. These results suggest latent directional consensus as an effective reliability signal for online LLM RL.

### 1. 核心问题与整体含义

- **研究动机**：在线强化学习（RL）广泛用于对齐大语言模型（LLM），但在奖励信号存在噪声或误设定时，训练极易不稳定——学习曲线震荡、性能早停甚至回退。现有方法只关注标量奖励的可靠性（如裁剪、重加权），却忽略了**更新方向的一致性**。
- **核心问题**：本文识别出一种名为“方向不一致”的失败模式：在一个批次内，少数高奖励的 rollout（例如由奖励模型伪迹或 reward hacking 产生）会在表示空间中诱导出与批次多数方向严重冲突的更新方向，从而放大梯度方差、破坏稳定。
- **整体含义**：提出将**潜在表示空间中的方向一致性**作为一种全新的可靠性信号，以轻量级方式稳定 LLM 的在线 RL 训练。

### 2. 提出的方法论

- **核心思想**：在每轮迭代中，利用 rollout 的（已分离）隐藏状态，通过在线学习的投影器提取“奖励有序位移方向”，构建批次共识原型，检测并替换方向极不一致的 rollout。
- **关键技术细节**：
    1. **形成提示内偏好对**：对每个 prompt 内同一 prompt 的 rollout 严格按奖励排序，构造高奖→低奖的位移向量 \( \delta = h(y_w) - h(y_l) \)。
    2. **在线方向投影器**：训练一个 3 层 MLP \( M_\psi \)（50 步，余弦 LR，初始 LR 1e-3），将原始单位位移方向映射到低维空间，使奖励有序的方向更加集中。训练目标为正交方向二元分类损失 \( \mathcal{L}_{\text{map}} \)。
    3. **构建批次共识原型**：计算奖励-边际加权的归一化中心方向 \( v_{\text{proto}} \)。
    4. **异常检测**：定义每对方向偏离度为 \( 1 - \langle v_{i,k,\ell}, v_{\text{proto}} \rangle \)，对每个 rollout 累积其参与的所有对偏离度得到 GDI（几何偏离指标）。利用核密度估计（KDE）设定自适应阈值（密度低于峰值乘以 α 倍则视为异常）。
    5. **经验修正**：仅对同一 prompt 内的异常 rollout，用方向一致的稳定 rollout 替换（“最佳-随机”策略），保持每 prompt rollout 数量不变。
- **算法流程**：每次迭代收集 rollout → 提取隐藏状态 → 运行 GEOALIGN（构造对、训练投影器、计算 GDI、检测异常、替换）→ 用修正后的经验缓冲区进行标准策略更新（如 GRPO）。仅前向传播，无额外反向传播。

### 6. 主要结论与发现

1. **方向不一致确实存在**：高奖励 rollout 中少数方向与批次共识尖锐冲突，导致长尾分布。
2. **GEOALIGN 显著提升最终性能**：在两个任务、两个模型上，平均得分均优于所有基线（数学 1.7B: 40.44 vs. Base 39.81; 4B: 55.94 vs. Base 54.78；对话 1.7B: 0.8885 vs. Base 0.8354；4B: 0.8894 vs. Base 0.8672）。
3. **显著降低训练震荡**：学习曲线更平滑，KL 散度和裁剪率更低，多种子下运行稳定。
4. **更强的抗噪性**：在 5%/10% 奖励注入噪声下，GEOALIGN 性能下降最小，保持最高绝对得分。
5. **投影器至关重要**：投影后方向高度集中（近 90% 向量与原型余弦相似度 > 0.8），而未投影时方向分散。
6. **替换策略优于零权重或丢弃**：保持 rollout 数量对梯度密度有益。

### 7. 优点

- **轻量插件，即插即用**：仅需前向传播获取隐藏状态，无额外反向传播，与现有任何策略优化算法（如 GRPO）兼容。
- **保持梯度密度**：通过提示内替换而非丢弃，不改变每个 prompt 的 rollout 数量，避免打乱组归一化。
- **仅针对极端异常干预**：基于密度阈值的 KDE 检测，保守地只替换最严重的异常，保留合理多样性（已通过 Pass@k 验证）。
- **跨任务通用**：在数学（二元奖励）和对话（连续奖励）两种场景下均有效。
- **理论启发**：提出“潜在方向一致性”作为新的可靠性信号，为后续研究提供了新视角。

### 8. 不足与局限

- **对阈值 α 较为敏感**：不同任务最优 α 不同（数学 0.05，对话 0.12），且需要手动调整，可能依赖先验知识。论文也提及未来可自适应调整。
- **理论连接尚浅**：方向不一致与梯度方差之间的形式化推导未深入，仅给出直观解释和实验验证。
- **模型规模限制**：仅验证到 4B 模型，未在更大规模的 7B/14B/70B 上测试，泛化性有待考证。
- **计算开销与扩展性**：虽然文中提到开销可忽略，但当 K 很大（如 >50）时，成对构造复杂度 O(N K²) 可能成为瓶颈，需考虑子采样策略。
- **未探索与更多 RL 算法结合**：仅基于 GRPO 实现，是否适用于 PPO、A2C 等尚未验证。
- **奖励噪声类型有限**：仅测试了随机翻转和极端值替换，未覆盖更复杂的 reward hacking 或对抗噪声场景。
- **数据集单一**：数学仅为 DAPO-Math，对话仅为 HH-RLHF，未在更多其他领域（如代码、百科）测试。
