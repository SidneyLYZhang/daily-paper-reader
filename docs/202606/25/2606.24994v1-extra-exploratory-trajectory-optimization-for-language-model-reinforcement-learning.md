## 摘要
基于可验证奖励的强化学习（RLVR）用于语言模型推理时，可能在任务难度的两个极端上失败：简单提示往往会产生全正确、低多样性的轨迹组，梯度信号微弱；而困难提示则可能产生全错误的轨迹组，没有正奖励。我们提出了ExTra（探索性轨迹优化），一种兼容GRPO的框架，从模型自身的轨迹中提取探索信号。ExTra结合了两种机制：（i）新颖性奖励，在GRPO归一化后添加基于嵌入的多样性奖励，奖励多样化的正确解；（ii）熵引导的前缀重生成，利用熵信号对部分轨迹进行评分，并从有希望的中间步骤继续探索。在六个数学推理基准上，ExTra在Qwen3-1.7B上相对于GRPO在pass@1上平均提升约5个百分点，在pass@16上提升约7个百分点，表明轨迹级别的探索信号可以同时改善单样本准确率和推理时覆盖范围。

## Abstract
Reinforcement Learning with Verifiable Rewards (RLVR) for language-model reasoning can fail at both extremes of task difficulty: easy prompts often produce all-correct, low-diversity rollout groups with little gradient signal, while hard prompts can produce all-incorrect groups with no positive reward. We introduce ExTra (Exploratory Trajectory Optimization), a GRPO-compatible framework that extracts exploration signals from the model's own rollouts. ExTra combines two mechanisms: (i) a novelty reward that adds embedding-based diversity bonuses after GRPO normalization, rewarding diverse correct solutions; and (ii) entropy-guided prefix regeneration, which scores partial trajectories using entropy signals and continues exploration from promising intermediate steps. Across six mathematical reasoning benchmarks, ExTra improves Qwen3-1.7B over GRPO by about +5 points on pass@1 and +7 points on pass@16, showing that trajectory-level exploration signals can improve both single-sample accuracy and inference-time coverage.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题**：基于可验证奖励的语言模型强化学习（RLVR）在任务难度两个极端失效：  
  - **简单提示**：模型生成全正确但低多样性的轨迹组，组内奖励方差接近零，梯度信号微弱，导致 policy 快速坍塌到单一推理模式，损害 `pass@k`（k>1）的推理时扩展能力。  
  - **困难提示**：组内无正确答案，所有优势为零，policy 完全得不到正梯度。  
- **现有局限**：DAPO 等方法通过过滤困难样本或重采样来解决，但代价是丢弃蕴含前沿推理信号的困难问题，且重采样从零开始，忽略已有轨迹中可能的有用中间结构。  
- **核心洞察**：模型自身 rollout 过程已包含两种未利用的探索信号：  
  1. **轨迹多样性**（正确轨迹间的语义新颖性）；  
  2. **失败轨迹的结构**（中间步骤的置信度/熵）。  
- **整体含义**：通过显式利用这两种信号，可在不增加额外奖励模型或监督的情况下，同时提升单样本准确率和推理时覆盖范围。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想
提出 **ExTra（Exploratory Trajectory Optimization）**，在标准 GRPO 框架内增加两个互补机制：
- **新颖性奖励**（Novelty Reward）：仅在正确轨迹上，根据嵌入空间中的语义新颖性给予额外奖励，促进多样化正确解。
- **熵引导前缀重生成**（Entropy-Guided Prefix Regeneration）：对全错误组，用平均 token 熵（MTE）挑选最有希望的中间前缀作为引导提示，继续采样后缀，从而有效缩窄探索空间。

### 2.2 关键技术细节

#### 新颖性奖励
- 对每个提示 x，维护一个正确轨迹嵌入记忆 Φ(x)（包含最近正确响应的 MiniLM-L6 嵌入）。
- 新响应 y 的原始新颖性奖励（Equation 1）：  
  `r_int(y) = 1[R(x,y)>0] * (1 - max_{z'∈Φ(x)} cos(h(y), z'))`  
  - **正确性门控**：只有正确轨迹才获得非零奖励。
- **后归一化应用**：在 GRPO 组归一化之后添加，而非之前，避免扭曲任务奖励的归一化统计量（Equation 2）：  
  `A_i_final = A_i_GRPO + γ * r_int(i)`  
  - γ 控制新颖性权重（默认 1.0）。

#### 熵引导前缀重生成
- **平均 token 熵（MTE）**（Equation 3）：  
  `H_mean(y≤t) = (1/t) Σ_{s=1}^t H(πθ(·|x, y<s))`  
  - 从 rollout logits 零成本计算，衡量生成前缀时的平均不确定性。
- **前缀选择**：对每个全错误组中的所有前缀，计算 MTE 并经过**语义相似性平滑**（加权平均，权重基于前缀嵌入余弦相似度），选出最低熵前缀作为引导提示。
- **优化范围**：固定前缀，仅对新生成的后缀计算 policy gradient loss，验证时检查完整轨迹正确性。
- **触发条件**：仅在训练步数 > 30 且组通过率 = 0 时激活。

### 2.3 算法流程（文字说明）
1. 每个训练步：采样一批提示，若引导队列非空则替换尾部。
2. 用当前 policy πθ 为每个提示生成 G 个响应，计算正确性奖励和 token 级熵。
3. **新颖性计算**：对每个正确响应，计算其嵌入与记忆库中最相似嵌入的余弦距离，得到新颖性奖励。
4. GRPO 组归一化后，将新颖性奖励乘 γ 加到每个样本的优势值上。
5. 用裁剪后的 GRPO 目标更新 policy（仅对正确轨迹有梯度贡献）。
6. **前缀重生成**（仅当组通过率为 0 且超过 warmup）：从全错误组中提取所有前缀，计算 MTE 并平滑，选择最低熵前缀，构造引导提示加入 FIFO 队列，用于后续批次。

## 6. 主要结论与发现

1. **ExTra 显著提升性能**：在 Qwen3-1.7B 上，平均 pass@1 从 47.1% 提升至 52.0%（+4.9 点），pass@16 从 66.4% 提升至 73.2%（+6.8 点）。在 Nemotron-1.5B 上同样有效。
2. **两种机制协同**：ExTra-N 单独提升 pass@1 和 pass@16，ExTra-R 单独仅轻微提升 pass@1 但略微降低 pass@16；完整方法实现超加性增益，表明新颖性拓宽前缀池，重生成从中选择低熵路径。
3. **样本效率优于 DAPO**：ExTra 以接近 GRPO 的生成预算（约 13.6 万提示）达到 73.2% pass@16，而 DAPO 用约 39.2 万提示仅达 63.6%。
4. **MTE 是无监督有效前缀信号**：在 600 个前缀上的 Monte Carlo 验证显示，MTE 是预测前缀价值的最高相关指标（ρ_within = -0.229），且优于使用真实答案的有监督指标。
5. **新颖性奖励改善多样性**：ExTra 在 LogDet 和 Self-BLEU 上显著优于 GRPO 和 DAPO，证明其扩展了推理空间。
